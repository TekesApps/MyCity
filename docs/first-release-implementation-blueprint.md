# 首版技术实施方案 T47

设计修订v0.4.47。整合现有[Root](root-component-contract.md)、[字段字典](capability-field-dictionary.md)、[运行阶段](institutions-and-labor-execution.md)、[CG39](cpu-gpu-compute-contract.md)及[BC43保存](city-baseline-completion-contract.md)。是可开工的非代码方案，不代表已创建Rust工程。AgentKit仅公开适配需求，不设计其内部实现。

## 1. 模块、依赖与所有权

冻结八个逻辑模块，允许初期同crate实现，但不得跨域直接写权威数据；不为了目录拆分复制业务表。首版数据存储采用有界稀疏表／结构化数组和typed generational handle，不引入每对象完整ECS组件副本或每格agent。冷正文与可重建索引分页，事实状态不可因缓存淘汰丢失。

| 模块 | 输入→输出 | 唯一职责与失败 | 预算域 |
| --- | --- | --- | --- |
| city-core | schema／规则／ID→验证过的单位与typed来源 | S00身份／目录；范围／溢出／世代错误拒事务；不含GPU／网络 | 原模拟／模板页／索引 |
| city-map | 地形／几何／端口／规则→canonical几何、拓扑／空间验证 | 连续空间与索引；不写钱／人口；不确定几何返回明确歧义 | 几何0.25GiB＋原索引 |
| city-sim | 已验证命令／原源与阶段→新权威／事件／完整观察快照 | S01—S13领域writer、同钟区域、资金／实物／占用提交器 | 模拟0.35GiB含区域及专用包 |
| city-storage | 提交源／根与依赖→持久回执／恢复 | 单世界写者锁、WAL／检查点／校验、文件预算；失败保留旧完整代 | 运行余量／磁盘／有界I/O页 |
| city-tools | 查询／草案／授权→只读页／预演／可信提交命令 | MyCity工具协议／幂等／权限；不能直接修改模块私有数组 | 工具UI0.35GiB、求解0.20GiB |
| city-render | 不可变快照／资产→图像／非权威动画 | wgpu绘图／拾取ID投影；不反向生成出行／钱／生活结果 | 资产0.85GiB、渲染0.25GiB |
| city-app | 原生事件／用户输入→命令／导航／时钟意图 | 主线程窗口／IME／可访问投影／通知；编辑草案非正式状态 | UI／工具域及运行余量 |
| city-team-adapter | 公开会话／工具调用→结构化消息与MyCity工具请求 | 现实费用／取消／连接恢复／单活动模型请求；不持有世界真值 | UI／知识热页内原额度 |

依赖方向：core无上层依赖；map→core；sim→core/map的纯数据契约；storage→core及持久schema；render→core/map的只读快照；tools→core/map/sim的命令接口；team-adapter→tools；app组装这些模块。sim不依赖app/render/team-adapter，headless可推进同一世界。存储schema由core拥有版本，storage不以反向调用app决定如何修账。

## 3. 时钟、工作队列与事务协议

权威时间i64整数游戏秒，公历／固定种子／规则版本在世界根；现实时间只决定希望推进量。推进区间为[t0,t1)，最多1游戏小时且在最早班次、到期、耗尽、数值／阈值、权利或工程边界截断。空气原数值格最多1游戏分钟，不能拿一小时公式代算；时钟倍率不足时显示实际倍率。

沿IL43的P0封旧事实→P1已定法律生效→P2旧权利到期→P3合法身份／任期交接→P4完整观察／程序快照→P5新动作。8192就绪窗口分批装填，到期源持久游标不常驻全量；同刻必要阶段未排空不前进T之后。纯监测／画面可降频，既有工资、库存、占用与安全不跳过。

主线程拥有窗口／原生事件与显示快照。模拟协调线程唯一持有世界可写提交权；CPU worker池做纯快照计算、几何与候选寻路，返回读集／策略／误差／工作覆盖；存储worker串行持久写；GPU队列专供渲染和准入计算。线程数量由可用CPU选择，候选最多min(4,可用逻辑核−2)、至少1；不因8图／32任务启动8套全世界。必要可用单线程获得同策略同结果。

命令信封必含world/branch、actor/权限来源、operation_id、expected_revision／读集、payload_schema／payload_hash、冻结plan及授权上限。阶段安全边界重查→算全部资金／物理／权利预留→按稳定源序验证→持久化commit意图与覆盖→发布不可变新快照→返回同一回执。任何依赖变化导致拒绝或重评，非半扣钱半放楼。外部operation_id与内部稳定积分覆盖分开；相同ID不同payload报冲突，相同ID同payload返回旧结果。

随机流按(world_seed、domain、稳定source、发生窗)寻址，显示／查询／线程顺序不抽新随机。同构建／同策略／同命令日志要求权威hash一致；跨CPU/GPU浮点策略采用冻结误差与保守区间，不承诺跨实现逐位一致。任何数值溢出／NaN／断源停事务并报告，不截断金额或用0补字段。

## 4. 快照、渲染、拾取与macOS实现边界

模拟发布最近完整提交快照及局部处理中标签，渲染／UI只读；一个显示快照＋有限增量／一个预演租约，不为每帧／每图复制所有表。采用SoA实例、分块地形、脏块更新／视锥与距离裁剪；建筑占位网格按模板尺寸构造、门位来自同一canonical几何，视觉LOD不改路径或地价。

首版首选winit窗口事件、wgpu图形及WGSL着色器，macOS启用Metal后端；UI采用同一app中的保留语义树＋wgpu绘制投影，可访问树必须桥接系统AX，不能把全部界面烘成一张纹理后声称键盘／VoiceOver完成。字体排版／IME组合／焦点有独立语义状态；第三方库选择需在工程初始化锁定并核许可证／macOS行为，不成为设计待决项。

逻辑点／物理像素／世界米三种空间显式转换；窗口resize和scale-factor更新表面物理尺寸、投影／拾取矩阵及UI排版，0尺寸或最小化暂停提交新surface图像。拾取先用同帧ID／深度或CPU canonical几何复查，给对象稳定ID＋revision，不能读旧帧像素修改新世界。全屏／外屏切换不重建模拟世界。

设备丢失／表面失效只使渲染暂停恢复；CPU世界继续或按用户偏好暂停。所有GPU作业附世界快照、规则、数值策略、job/device generation，旧回调拒绝；重建GPU资源从CPU已提交真值上传。错误scope／设备丢失回调转结构化通知，不吞掉成“黑屏但正在建设”。wgpu的[Metal后端枚举](https://docs.rs/wgpu/latest/wgpu/struct.Backends.html)、[设备丢失接口](https://docs.rs/wgpu/latest/wgpu/struct.Device.html)与winit的[窗口／全屏／缩放接口](https://docs.rs/winit/latest/winit/window/struct.Window.html)提供能力入口；具体版本在首个工程提交锁Cargo.lock并记录，不能把此链接当已验证组合。

## 5. CPU／GPU分工与预算

CPU保留身份／产权／规则、幂等事务、工资／税／账／股份、稀疏OD状态／最终路径许可、自然需要、生活行为与安全责任。GPU默认承担绘图；空气扩散／非权威热图等有界密集场仅按CG39通过误差、回读、吞吐及总收益门后启用。无GPU计算仍有CPU参考路径；GPU不决定裁判、金额或最终交通许可。

| 应用域 | GiB目标 | 计费规则 |
| --- | ---: | --- |
| 模拟 | 0.35 | 31项区域载荷43.8828125／44MiB，模板0.25、组合预留0.125、ME40 3.375、LS42 9.5、IL43 1，其余300.15MiB |
| 几何 | 0.25 | 地形、道路／地下／门包络、空间索引所属，不与资产重复挂账 |
| 资产 | 0.85 | 原创占位／实例纹理／网格及可淘汰缓存 |
| 渲染 | 0.25 | surface相关资源、深度、ID、阴影／图层、可视实例与临时上传 |
| UI／工具／团队 | 0.35 | 文本／语义树／查询／模型上下文、知识热页、任务及协议有界页 |
| 求解／唯一预演 | 0.20 | CG39计算包16MiB含CPU/GPU完整副本／readback/scratch，其余188.8MiB共享 |
| 运行／快照余量 | 0.40 | 分配器、线程、检查点／加载高水位和系统胶水；不是每新功能可再借0.40 |

预演、保存、加载、切图同时发生时依租约互斥／背压，先结束或取消预测，流式检查点页，不可同时持有第二份整世界。压力顺序：降低非权威动画／纹理／渲染比例→取消预测／缓存→减少软重算／实际日历倍率；达到4GiB警戒拒新重任务并保旧事实，不能删家庭／债务来达标。

计算门分别测模拟区间p95≤20ms（不是整游戏日完成时间）、UI主线程非阻塞、60Hz显示下帧预算16.7ms；1日/秒与原生4K60是目标／配置选择而非必要全部同时达到。正常质量在Retina默认60fps目标、低功耗可30fps、4K允许渲染比例50—100%；实测仍不足必须公开实际倍率／质量与硬件，不偷换16GB机器为32GB限额。

磁盘每世界10GiB、8GiB告警、保留至少1GiB工作安全余量；两完整检查点＋必要WAL／被引用旧规则／源几何都入限额。日志必须按源事件与压缩阶段覆盖，不每F每分钟落112B；满盘保旧完整根和回执，停止新变更。长期增长检验同一负载30日／2年及故障重放，不只测空城保存文件。

## 6. 保存、兼容与诊断

候选持久格式city-v1：根manifest携world/branch/time/phase/sequence、版本依赖／长度／内容摘要、数值策略／随机流与各表页；压缩分块二进制运行页＋可读manifest／迁移说明。开发文档CSV／构造规则先转经验证中间表，再序列化；不要求运行时直接把所有CSV当正式schema。

写新页／依赖临时代→校验并同步必要文件／日志commit→原子发布同文件系统根→同步目录及确认持久性→才回成功。默认2个自动恢复点各固定根／提交sequence／重放截止，所需日志和资产依赖在该引用释放前不得回收；两个完整根代按原回收规则保留；单文件rename不等于世界事务，File::sync_all／rename的语义参考[Rust文件同步](https://doc.rust-lang.org/std/fs/struct.File.html)与[重命名](https://doc.rust-lang.org/std/fs/fn.rename.html)，macOS目录同步及断电保证需故障注入实证。保存失败不能发成功回执。

加载先校计数／长度／hash／schema／资源预计峰值和必需功能，再流式恢复暂存世界；全部引用／成对钱／库存／占用／阶段游标校验通过才替换当前世界。缺schema／较新规则／损坏已提交源只读诊断或拒载，不随意“修复”欠款；尾部未提交日志截掉不算丢已成功操作。实际自动迁移仅实现明确批准的版本对，不用首次开发自行猜兼容；首版不承诺任意历史设计CSV可加载。

检查点可在同刻处理中的一致微边界，必须保存processing_phase及游标，UI仍标处理中；恢复先排空必要同刻阶段，不先给玩家一张“日终完成”账。恢复作废旧设备／预测／网络作业代际，不自动重发未知建设；先查原operation回执。世界分支须新branch与原来源引用，不可同联动世界只回滚一图。

## 8. 不变量与测试标准

| 编号 | 测试域／输入 | 必须观测到的判据 |
| --- | --- | --- |
| INV-01 | 成对现金／资本／净薪税／退款／股息 | 转移前后总现金守恒，新增仅有明确初始化／外部真实来源；保护非新钱，欠债非已收 |
