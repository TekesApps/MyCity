# v0.4.16 建筑出入口与交通接入

日期：2026-10-19。按用户要求，门朝向、合理进出方向和道路连接成为交通基础状态，而非建筑旁有路即算接入。只补设计，未写游戏代码或完成真实交通／性能验收。

[接入专题](building-access-and-traffic.md) 定义局部门位、朝向／接近范围、角色／模式、开放及进出、净空／容量和权利；旋转／允许镜像同步变换。入口通过实际门前／院内或共享通道连接正确道路侧／高程及有向锚点，不能穿墙、隔离带、高架投影或无合法节点的车道。住宅、员工、顾客、装卸和维护／应急分别验证，水电接头不算人的入口。

多门选择复用同一需求和共享瓶颈，不复制居民、岗位、货物或通道容量。入口默认只作相关出行的起终点，不能免费穿楼／掉头；公共可穿行通道须独立合法声明。封门停止新通行，既有聚合在途按位置等待／退出／合法改道；雇佣、居民、交付、债务和安全状态不能凭门关闭删除。

咨询advisor后落实每口一个物理外接锚点、真实路段位置／方向／距离、连接走廊共用瓶颈、动态在途处理及全世界容量联合准入。不把虚拟接入当整条路任意可达；临时求解展开也计入既有工作预算。

新增全世界65536端口×32 B＝2 MiB，一建筑／独立设施最多8个，按实际模板端口数分配；住宅单元／经营者共用真实外部门，不每户建8口。旧详细建筑与摘要只引用同一端口权威，不重复存储。8000建筑各8口已64000条，不能同时承诺所有邻图最大负载；与512跨图边界端口是不同类别，不混用额度或重复发布道路容量。

区域载荷36.5078125＋2＝38.5078125 MiB，40 MiB内余1.4921875 MiB，原0.35 GiB模拟域／应用2.65 GiB目标不增。32 B是待验证的紧凑引用／运行状态目标，不是完整门几何、权限文书或无穷队列；几何、共享容量、在途、索引、路径和临时状态仍需实际字节复核，不能据此确认最坏负载可跑。
