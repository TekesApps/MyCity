## 持续运行方法

```sh
cargo run --release --locked --offline -p mycity-headless -- continuity-probe NEW_DIR 1800
```

真实工作计时从准备完成后开始，不能因准备较慢让短测零循环。每个循环实际写入地图激活、占满／拒绝超配／占用／释放共享容量、断链／恢复、交互推进，同时执行当前状态恢复校验和七类分页查询。每25个循环重开，每50个循环用子进程在轮转的11个持久窗口真实退出，再从已确认旧／新根精确重试。只在完整工作时间达到1800秒后产生`wall_duration_gate=true`。

这里的四笔真实运输和五笔外部费用发生在准备阶段；持续阶段循环验证控制、存档增长及恢复，保留未偿责任。有限八报价目录不会在后台无限签新合同；这不是30分钟稳态商业交通、全行业经济平衡或真实大城性能。CPU／存储循环包含同步落盘、查询、额外校验及定期恢复，不能当作渲染帧耗时。

长跑helper中常量名`Responded`表示`execute`返回后退出，并未输出业务回执；真实stdout响应窗口由storage-worker的独立进程测试另验。对外来源确认则以producer pending删除并同步为边界，World提交／来源确认之间的退出已独立实测。

`/usr/bin/time -l`记录整条命令的实际墙钟及命令报告峰值RSS；另按秒采样父进程与观察到的子进程。采样开始于持续运行中段，可能错过短子进程，不能把采样进程树数值当作精确同时峰值。owned是Rust表容量口径，不含全部暂存／分配器／OS页；持久化元数据的少量字符串也不应由这个计数代替RSS。

## 独立验算

完成后，以与运行同一冻结Release库编译的只读检查程序分页扫描全部已提交回执，保存World、七类查询样例、财务／移交轨迹和未发生写入的hash／sequence证明。再运行标准库验证脚本，核对源码／锁文件指纹、真实工作时长、退出次数、日志增长、资金／责任及实物，而不只读取探针的通过布尔值。

有限案例的独立现金桥：买方初始200000分，支付4笔货价共8000分、运费80分，得到周期义务付款3000分、Incident补偿100分，支付处理费20分，剩195000分用于外部责任。五笔各700000分责任总3500000分，付款195000分后仍欠3305000分。全World现金仍3000000分；应计责任3500120分＝累计实付195120分＋未付3305000分。

泵故障另付服务费200分，由公司3转供应商4。最终四账户现金应为1000000／0／596800／1403200分。四笔1Q原料各有2020分购入成本，源剩1Q；泵耗100Wh进100Wh热，600L源水进600L废水；物、费用与债不因重开消失。本地年龄增量总和只能等于实际交互推进，不能按地图打开次数补跑。

## 边界

验收只覆盖本轮有限三城／四主体／八报价及一个受信来源的M0原语。来源真实性、永久断链的实物处置、破产／减记、全行业损益与工资税日历联合仍在完整产品目标中，未在这里签收。硬满保留状态并停止，不承诺无新增存储条件的无限运行。

运行机器为Apple M4、32GiB、macOS 26.6.2，Rust 1.85.1。没有UI、GPU工作或真实大中小满规模城市联合负载；当前机器结果始终不能算作16GB实际机器验收。

[只读检查](evidence/m0-t09-continuity/inspection.txt)完整分页扫描48895条回执，选出35条跨城事实／付款／移交轨迹；[原始轨迹](evidence/m0-t09-continuity/trace-receipts.json)能直接连接13个创建事实与9次实际付款。读查询前后hash和sequence不变。最终[World](evidence/m0-t09-continuity/world.json)、[全部容量行](evidence/m0-t09-continuity/capacity-rows.json)、[七类查询样例](evidence/m0-t09-continuity/query-examples.json)及[存档文件清单](evidence/m0-t09-continuity/world-file-manifest.json)共同对应同一最终根。

独立验算确认四账户为1000000／0／596800／1403200分，总额3000000分；应计3500120分＝已付195120分＋未付3305000分。五条未偿来源责任保留在追收池，政府管理移交没有变成财政兜底。四笔原料、源库存、热／废水终点及全部六个资源池对齐，最终无悬挂租约；各城只增加自己的实际活动时间。

重新只读开库后`reconciled=false`符合显式来源握手契约，不是数据丢失：pending为空、next_event为6，继续模拟前仍须上游确认6。检查程序不擅自代替上游确认，也不推进城市。

本轮只签收上述六个M0有限工作包。完整T09／M0、全行业稳态经济、真实大中小城市规模、UI／GPU以及16GB机器验收均未因此通过。
