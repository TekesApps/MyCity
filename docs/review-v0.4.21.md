## 本轮形成的模型

[复合设施与实物—经济模型](composition-and-cost-model.md) 将三件事分开：可配置的真实空间／设备清单、规则与市场共同决定的投入／可行性、真实需求与履约形成的收益。预定义资产和受限自定义接受同一套校验，不让玩家／agent任意覆盖必要成本、资源或收入。

| 环节 | 核心规则 |
| --- | --- |
| 实物到资源 | 聚合设备类别×数量×工况／时段，额定W、同时峰值、实际kWh、流率与m³各有单位；覆盖原负荷对应部分，不重复计耗能 |
| 复合与共享 | 宿主＋展开后≤4功能单元＋真实公共支撑，总8子区／8口；面积／时段／typed容量、支撑依赖与责任分别核算，不套娃领新额度 |
| 成本 | 专属与公共工程量、接口／隔离、实际取得权利与运行／维护／退出；共享节省可追到少建的真实部分，无任意叠加折扣 |
| 地点与经营 | 地价估值／成本影响报价和开发压力，真实需求、适配／资金与替代选择决定进入和支付；不从造价保证租金／满租 |
| 收益与账务 | 实收、采购、工资／租金／水电等实际收支分开，预测不是现金，营业额不等于利润；内部转移不创造世界财富 |
| 摊位 | 有限合法宿主／设施、真实经营者、时段使用许可、空间／接入、计费／退款和清场责任；不是凭坐标免费营业 |
| 公共服务／纪念物 | 允许合法财政支持负现金流；地标有真实投入维护，未支持旅游模型不产保底钱，重复吸引不得创造无限需求 |

自定义规则不是全自由经济参数编辑；修改场景规则要保留独立版本，不假称同一规则下的资产。高成本可能无人承租，低成本也可能有合理高收益；模型防无真实来源／责任的套利，不用统一评分或强制亏盈抹去合理选择。

## Advisor审查与范围一致性

按已有授权咨询advisor，先审机制边界，再复核完整稿，确认无阻断项。复核重点是设备／公共电表双计、建设与运行费用时点、摊位身份和许可、同需求池纪念物效果、现金示例及有界版本／单元／设备／门配额。

普通零售＋成人培训＋庭院用于探索组合，但多用途绑定／计量／权利等仍须定义和验收，未把CAT-R-06混合楼从后续B升为首版。实体政务办公、轨道／车站、旅游吸引、商业租赁和真实土地市场保持原缺口；首版已有制度、共享空间及住宅租约不取消。普通一般商品摊位拟复用O03，烹饪、食品／冷链或多商户许可不是换外观就获得。

README、Root、对象、双向表、目录、行业、工具、准备总览、路线图和性能预算同步入口与约束，历史review保持原样。90条目录、13基础样例、12经营profile、34属性／14逻辑系统／26指标族不变。
