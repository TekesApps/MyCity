# v0.4.8 行业就业承载、影响与产业链

日期：2026-10-18。按玩家要求补各行业容纳就业人数、效果和相互关系；纯设计文档，未写游戏代码或完成经济校准。

## 本轮补全

[行业专题](industries-employment-and-effects.md) 参考官方就业用地评估、HCA2015就业密度、BLS工时生产率和ONS投入产出方法，将现实参考与MyCity示例参数分开。工作位、FTE、招聘名额、雇佣、到岗工时及实际交付分别记录，不靠格子数或建筑等级推导全部结果。

首版8类活动覆盖煤电、供水、一般制造、零售、物流、卫生、公共服务和施工，具体最多16行业模板。每个经营地点有自己的岗位／资格、班次、有限投入／交付、维护、资金和外部性；办公室等扩展没有供需与能力时不能假运行。

同一劳动力不重复填多个雇主／时段，必要工种不能平均抵消；本地／跨城就业按居住地与工作地分开。工资资金先落实，实际付款进入可消费家庭账户，群体拆并不重分财富。消费、补货、制造、运输和垃圾有真实去向，不用乘数复制间接就业、产值或税收。

设备、劳动、材料、水电、库存／订单共同约束产出；公共服务和管网仍沿既有交付权威，行业层不重复算电、床位、工资、消耗和运输。行业外部性按实际作业及交通计算，不以理论满编推算满负荷污染。制度／法案、选举、摘要、真实账户与原有16 GB边界保持。

## 算术

| 项目 | 结果 |
| --- | --- |
| 20同时工作位，24小时×7日 | 3360工时／周＝84 FTE，40工时制下84名员工 |
| 工厂三类到岗18／9／3，对满配24／12／4 | 各0.75，额定10产品／小时对应劳动上限7.5 |
| 设备10、劳动7.5、原料6、水电8、出货／库存5 | 实际5产品／小时，8小时40产品 |
| 每10产品耗11原料、产生1废料 | 当班耗44、产40＋废料4，统一物料当量守恒 |
| 5万人×0.55资格×0.8参与率 | 2.2万劳动力；1.8万本地就业＋2000出城就业＋2000失业 |
| 本城1.8万本地员工＋3000入城员工 | 本城雇佣2.1万；2.3万招聘名额有2000空缺 |
| 4096运营单位×128 B | 0.5 MiB，计区域域 |
| 32768匹配边×32 B | 1 MiB，从旧4 MiB索引路径配额内划出 |
| 区域小计与32 MiB余量 | 30.1953125 MiB与1.8046875 MiB |

128 B是紧凑描述而非完整运营对象；配方共享，动态项分域计费，停业未清算也占槽。单位、账户、库存、合同、计量、匹配／路径等联合准入，不承诺各城同时达到全部上限。
