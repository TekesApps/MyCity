# v0.4.7 定期选举与议员投票

日期：2026-10-18。玩家明确要求定期选出代表，再由代表对提案投票。本版把正式选举纳入首版，替代v0.4.6暂缓选举的决定；仅文档设计，未写游戏代码。

## 规则

[选举专题](periodic-elections.md) 默认每2游戏年按公历周年举行常规选举；空城有限过渡，达到100名模型合资格居民后启动30日首次程序。合资格人数以常住人口的配置比例估计，默认0.6，不以就业或财富决定，也不宣称逐人核验年龄。

默认全城9席、最多3候选名单，各含9名有冻结顺序的候选；群体批量投票，按最大余数比例分席并确定具体当选人。0有效票进入延期，不以平票产生赢家；席位产生后仍每席一票，普通法案至少5票赞成。

名册、政纲、投票参数、观测窗口、种子和计票结果固定保存；截止后迁居不改变同轮归属。不同登记日期是不同轮次，迁居后合法参与不同城市任期不算同轮重复投票。模型只解释结果，不写选票／赢家。

候选递补、无票重选、提前改选与有限留任有预置规则，每城最多一个有效组建程序，程序／目标任期／现任版本共同校验原子交接。旧会已完成表决及待生效法案保留，未投票事项交新会；法律、拨款、合同、工程、司法及行政授权不因换届清零。
