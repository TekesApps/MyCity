# 首版游戏策划与玩家体验 G47

设计修订v0.4.47。首版定位为macOS单人、交通优先的区域城市治理游戏：玩家以市长身份给City Team目标、约束与授权，体验“看见因果—权衡取舍—推进工程—承担持续后果”。不是逐人生活模拟、自动生成繁荣城市或原作内容复刻。下列为冻结候选规则，数值可在有记录的试玩校准中修订，不能靠纸面称好玩。

## 1. 核心体验与一轮治理

主入口冻结为Agent文本治理，未来语音复用，不以玩家手工拖道路／放房屋为必要步骤。三项支柱：交通具有真实空间／时间／容量后果；任何建设都有权利、资源、成本和维护；团队建议可追问、可预演、可拒绝，市民与市场独立运行。成功体验是理解瓶颈并选择代价，而不是找到万能低成本建筑。建筑细节聚合到现有模板／能力与真实责任，不加逐设备／房间／个人日程。

市长不直接控制居民／业主或替他们批准变更；所有受理需求在统一事项工作台可追踪，状态来自程序、合同、工程和观察的真实回执。协商、补偿、拨款与施工各有条件，加速只推进同一游戏日历。

典型循环为：读城市摘要→下达目标与硬限制→调查来源与候选→比较交通／现金／环境及权益→批准范围和累计上限→分期工程／制度流程→按游戏日历运营→观察相同窗口实际结果／偏差→保留、改约或新提案。真实生活／贸易／议会与司法在团队无新命令时仍运行，已经批准的程序不会等待LLM闲聊才发生。

| 阶段 | 玩家得到什么／能做什么 | 成功与失败不混用 |
| --- | --- | --- |
| 提问／目标 | 可只输入文字，选择当前城市、目标对象、预算和时间；缺核心对象仅问一次自包含问题并保留已有工作 | 聊天回复不等于已接受施工；同一目标追加与新目标明确分开 |
| 调查 | 读真实快照／覆盖／来源年龄；团队列问题、现状及最多3个易比较方案，深层最多8选址候选沿原额度 | 预算足够不等于法源／产权／交通可行；unknown不能自动当0 |
| 方案 | 一页展示施工范围、出入口、阶段、总支出／未来维护、受影响者、授权／法案、预测误差与必要停供／安置 | 无法满足硬约束即不可提交；可提替代约束，须玩家接受 |
| 授权 | 批准具体方案版本、用途／城市／地理范围、累计支出与可调整边界；高影响拆除／征收另明确确认 | 市长授权、议会／司法许可、资金和资源分别通过；不得代私人签约 |
| 推进 | 显示筹备、施工、养护、待验收、投运和达标分离；可暂停／改目标／停止未提交步骤 | 已施工／应计／污染／债务不可编辑撤销；取消不瞬间还原 |
| 观察 | 报告基准窗、预期、实际、样本／未满足／误差、钱／实物去向；可定位楼、门、路段、公司、家庭住所 | 先完成投运，再按真实观察窗验目标；没有样本不显示100% |

City Team按[编制契约](team-staffing-and-knowledge.md)兼任与专业化，2／4／6人为三图默认而非锁定；富裕小城可到16席，工资／工时与现实模型费分别显示。基础查询／告警不靠专家付费解锁；更大团队提供可验证的分析工时与方法，不增加规则正确率乘数或模型并发。

## 2. 模式、开局与成长

首版提供“引导小镇”“自由治理”“联合负载验收”三种入口。前两者是玩法，联合负载只供开发／诊断且明确不是平衡完成的关卡。引导可随时关闭，不重新初始化钱、人口、供方或进度。新建自由世界选择64／128／256格地图、合成地形或本地灰度图；大图标记待实测目标，系统准入不足则说明原因，不静默缩图。

首选引导采用合成小镇的当前统一输入；选择“空地建市”仍须同一初始有偿外部工程／启动供给与过渡制度，不能让用户在无工人水电时免费点出设施。中图是正式联合验收规模；小镇证明可理解／连接，中图证明同一机制可扩展，二者不互相替代。

| 发展阶段 | 进入／可见目标 | 新引导与完成证据 |
| --- | --- | --- |
| 建市准备 | 任意人口；看见初始资产、财政、外界期限和初始责任 | 找到本地／跨图雇主、住户、道路／管线和实际现金，完成一次只读追问 |
| 连通运营 | 原小镇48人；修一处可解释瓶颈／补给关系 | 至少连续7完整游戏日无未记录的基础短缺，实际通勤／交付和费用可追溯；不是要求满意度全100 |
| 稳定市镇 | 首次达到100模型合资格居民按原30日检查触发议会选举 | 理解程序／预算／法案，处理有分歧提案；不跳过首次选举或把人口100误当100张选票 |
| 区域中心 | 至少两个真实相连经济／行政分区，连续30日同源观察 | 比较就业／物流／服务共享、资本更新与现金缺口；独立城市账本／议会不因同一玩家合并 |
| 长期治理 | 满足一次两游戏年议会周期或达到玩家自定城市目标 | 以跨届、更新储备／未资金化责任、环境分布及交通改善评估，不以人口堆高单一总分 |

阶段是引导与报告的组织方式，不凭空产生人口、奖金、额度或研究点。23类首版目录在自由模式均可查询／规划；投运依真实许可、技能、资源、预算、需求及技术模板。高级设施只在前置得到后高亮建议，不用“人口升级”免费解锁电力／人才。禁止用专家知识解锁尚延期的铁路／燃气／自由3D。

长期目标由市长选择：通勤可靠、财政与全生命周期资金、低暴露与公服公平、就业／企业多样、合规治理。年度报告各维并列，分布／底线可见；没有将污染换人口就万能加分的隐藏评分。城市可继续经营，没有强制“通关后关服”。

## 3. 难度、挑战、选举与危机

所有模式共用守恒、法律与生活底线；难度只改公开的初始条件、报价／外界期限、需求压力与提示。标准用冻结合成输入；宽松初始可支配财政×1.5并以显式一次性开局分录列出、任务提示开；挑战初始可支配财政×0.75、商品零售价不变、外部采购成本×1.10且报价版本不同、任务提示可关。受保护义务／已有资产不随难度打折；若调整后的开局资金不足必要保护，则选项拒载或先缩合法未接受承诺，不造负现金。难度不暗改投票、命中率、通勤容量或家庭钱。

可选挑战使用固定种子与已列情境：交通瓶颈、供应合约到期、维护落后、紧财政。只重用已有机制，不添加地震、火势、疾病或真实刑案。挑战目标／截止／初始差异在开始前可见，必须同时列资金／权利与未满足指标；完成给予报告／个人记录，无模拟现金奖励。

选举沿[两年议会选举](periodic-elections.md)，首版不做市长竞选或驱逐玩家。压力来自代表政纲、公开表决、预算受拒、选民生活后果与司法限制；玩家可改方案、缩项目、延后／重走程序，不能购买票数或指定结果。失败提案不回滚旧法／债务；名义财政充裕也不能越过反对票。

危机时分开显示实际安全、未满足、现金、债务与程序：先停不相容新增、保留在途／现场与旧权利，再用真实备用、移交、有限采购或依法援助。资金不足不是清零城市的按钮。首版不新增完整破产金融／无限救援；真实能力不足可进入受限治理，玩家仍可查询、暂停、降速、提整改或另存分支。仅必要状态无法安全继续时暂停权威时钟，并显示具体阻断及可执行恢复步骤。

挑战失败条件：在开始时约定的期限内目标未达，或连续14完整游戏日有已证未资金化关键安全义务；这是挑战判定，不是免债／法律死亡。玩家可退出挑战继续自由治理、恢复整个世界的旧存档或选择退休归档。退休不称本世界债务已清；不提供只回滚富裕地图、保留其他城市收款的作弊路径。普通自由模式无强制游戏结束，债务／受限权限本身构成后果。

## 4. 新手引导：先读懂，再批准

首入可跳过说明；默认暂停，所有待确认动作不耗游戏日历。可在没有外部模型时先完成基础查询／地图教学，不假装已接入agent。引导分六步，每步检查真实状态，不硬编码“第3次点击必成功”：

1. 点住宅与公司名册，查看住户／雇主、公共／私人钱、住所和通勤来源，解释现金与应收不同。
2. 打开交通／水电图层，选真实门和路线，问“哪些人受这处瓶颈影响？”显示未满足、方向及已知／未知。
3. 给团队一个有明确上限的目标，比较保守修复／扩容／不建设三个选择，检查维护与制度程序。
4. 批准小型合规项目，观察工程日历／实际投入、暂停与速度档，演示停止未提交动作而非撤销已建设。
5. 观察至少一个完整工作日与付款节点，对比预测／实际，追问未改善原因；自然服务不是教学时强行完成。
6. 查看首期合约续期／更新缺口与议会日历，建立下一目标或继续自由治理。

预期首轮理解与首次有意义决策约20—40现实分钟（可快进工程），此为试玩假设；不为达时长缩90游戏日工程为90秒“瞬建”。若一次教程存在阻断，提供定位／修正任务，可跳过教学而保留世界状态，不发钱让脚本强制通过。

## 5. 信息架构与最小交互规格

常驻三部分：地图中央、左侧城市／图层与名册、右侧目标／团队／方案／对象检查器；底部时间／通知与快照年龄。侧栏可收起、宽度可调；较小窗口改为单侧检查器分页，不遮住批准按钮。首版语言为简体中文，文本／单位采用可本地化键与格式；其他语言不作为首发验收承诺。

| 页面／对象 | 必须看见的字段 | 可执行动作 |
| --- | --- | --- |
| 城市摘要 | 日期／目标及实际倍率、现金／保护／到期／更新缺口、人口就业、交通未满足、环境覆盖、公服需要、制度日历 | 提问、定位、选择城市／图层、暂停、跳下一安全节点 |
| 名册／对象 | 稳定ID与快照、实际所在／产权／O→公司、资源／容量／接入／维护／费用、来源与年龄 | 查询关联、显示门／路线／受影响者、发起新目标；私人钱包只读 |
| 事项工作台 | 请求／事项／对象、责任人、当前程序门、协商／补偿、缺项／下一步、游戏日历／工程实际进度、资金及原始回执 | 查待办、定位阻断、追加条件／授权、请求暂停可控步骤／安全快进；依[W50](civic-project-workflow.md#9-事项工作台与程序性推进-w50)，不代参与方同意 |
| 目标／团队 | 原话／范围／硬限制／预算、参与成员／工时、当前状态、请求及真实模型费用 | 追加说明、暂停未来任务、重分配职责、批准具体修订 |
| 规划／预演 | 建前／建后、出入口／地层／占地、工程阶段、资源／资金／法律门、误差／未满足、一次预演的租约 | 切换候选、修改草案、接受有限授权、放弃预演；不能把预演写回正式账 |
| 预算／议会 | 各城市分账、经常／一次／应收／资本、拨款／现金／保护、议程／票与理由／生效日、案件限制 | 提交提案／改约／合法采购；不直接点“通过” |
| 观察报告 | 前后同窗指标、反事实预测标记、变化源、缺覆盖、长期成本、下一合法选择 | 定位原因链／导出报告／新目标，不自动重复扩容 |
| 存档／设置 | 世界／分支／版本、保存日期／恢复游戏时、依赖／兼容状态、画质／输入／通知／模型连接 | 整世界保存／加载／复制分支；不在恢复后重发期初资源 |

信息查询默认64行、最多128行，按同快照分页；输入搜索可找公司、道路、建筑与具有权限的家庭／股东住所，不要求居民每人一个3D小人。地图悬停简短卡，点击固定检查器；未知、处理中、陈旧、未支持和真实0分别有文字／图标，不仅靠颜色。

首版主操作是给Agent文本命令，未来语音转写走同一目标／计划／回执流程。地图点／框／多选精确绑定每栋建筑、道路桩号或区域，作为命令上下文；拖拽只标注意图，不是传统手工建造主入口。全部精确求解／改造由团队形成可预览方案。纯文字用户可用“列出候选→选择编号→预览→批准版本”完成核心操作，无需像素级点位；具体选择、区域调整、门改造与道路加宽见[E49](agent-command-targeting-and-editing.md)。

## 6. 时间、通知、错误与反馈

目标速度档冻结为观察1日/10分钟、经营1日/分钟、快速1日/10秒、高速1日/秒及暂停；默认经营，首次载入暂停。界面同时显示实际倍率／积压，达不到目标自动降实际速度，不跳工资、交通、污染、程序或工程。推进到下一节点受重要决定／硬失效／资金或数据边界截断。

通知分三类：阻断（安全、未知必要状态、预算／权利变更）默认自动暂停并可逐类设置；需决定（方案、续期、程序）默认停下一安全边界并入收件箱；信息（阶段／指标）按游戏日或同源合并，保留原票可追查。合法紧急限制立即阻新，不等弹窗确认。通知静音不关闭模拟责任，重复告警按同源合并但不吞掉恢复／再次失效。

忙碌、工具超时、模型断线、存档失败分别明确：结果未知先查operation_id，不自动再扣款；草案过期显示差异后重评；输入无法解析保留用户原文与已知对象；不支持机制给明确边界与可验证替代；没有可行方案需有限域完整证据，预算耗尽搜索只能说未解。

网络／模型慢时地图和被动模拟仍可用；玩家可暂停防止错过决策。退出／系统睡眠默认先在一致边界暂停并保存，唤醒保持暂停，现实离线时间不推进。无存储空间保留旧完整代、停止新修改并给清理／导出／只读选项，不能宣告已保存。

## 7. 地图、视听与macOS原则

首版采用有真实米制尺寸的低面数3D地形／建筑与正交等距2.5D相机，固定四向旋转、平移、连续缩放；自由透视、真实天气／昼夜照明模拟延后。外观采用原创清晰色块，住宅／商业／工业／市政有轮廓区别，施工与未投运不伪装成熟建筑。动画数量由视口预算抽样，车流方向／密度受真实量约束；画面关闭不改世界。

至少有交通方向／容量／队列、岗位／通勤、空气／噪声覆盖、地价／住房负担、实际水电、产权／出入口、工程阶段、公服与跨图交换图层。地下U1/U2/U3与空域A1/A2为过滤，不建六份格；未支持的航空／地铁数据仅规划，不能显示已运营。隐藏地表可看管线及真实端口，不能让显示层改连通。

声音仅环境氛围、完成／受阻提示与可静音背景音乐；没有必须听见才知道的事故／对话。所有语音／声音信息有可读等价，音乐／效果／提示独立音量，首次默认温和。市民声与UI提示不进入模拟NI，模拟噪声也不随系统音量改变。无强制配音，原声／图像版权独立制作。

窗口支持原生全屏、Retina、多显示器缩放、可调文本与UI尺寸；Control-Command-F全屏、Command-S保存、Command-O打开、Command-Z只撤草案、Escape关闭浮层／退草案、空格暂停（文本输入框不截获），提供完整可重映射快捷键表。IME组合文本不提交命令，Return提交须在组合结束后；多行输入Command-Return提交。菜单保留标准macOS键位，保存／加载不与规划快捷键冲突。

键盘可遍历城市摘要、通知、名册、方案与批准；可访问名称／值／状态、焦点顺序及VoiceOver文本投影与地图对象列表是开发验收要求，不声称wgpu画面天然可访问。字体缩放100—200%，色觉不依颜色单独编码，支持减少动态效果／自动镜头移动、暂停闪烁、字幕和对比度。平移／缩放中心保持稳定，不用自动镜头追车打断编辑。

这些交互选择参考[Apple macOS设计](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos/)、[游戏设计](https://developer.apple.com/design/human-interface-guidelines/designing-for-games/)与[辅助功能](https://developer.apple.com/design/human-interface-guidelines/accessibility/)；本项目具体布局和数值是自己的产品决定。

## 8. 存档、设置与AgentKit产品边界

自动保存每5现实分钟的下一个一致微提交边界及重要授权后；保持最新2个一致检查点和必要日志、默认2个自动保存恢复点，各固定自己的根／sequence及重放截止点，引用仍存续时不得回收其日志／依赖，不复制两个世界常驻；手动命名存档／世界分支仍受磁盘预算。覆盖／删除有明确世界名和版本确认；退出失败不得悄悄丢未保存修改，提供重试／导出／取消退出。游戏保存含真实城市／规则／目标／回执／团队合同，API密钥存在系统凭据存储而非世界文件。

设置包含分辨率／渲染比例、帧率30/60、图层／动画密度、文字大小／语言键、键鼠与轨迹手势、声道音量、通知停靠、自动保存、模型连接／现实费用上限、隐私日志导出。默认不上传完整存档／个人凭据；仅按一次任务必要范围发模型上下文，发送范围可检查。城市模拟不依模型云端时间。

AgentKit只需满足会话／流式消息、公开工具注册／调用、取消与恢复、operation查询和结构化状态投影；MyCity持有世界、权限、工具契约和模拟权威。仅一个活动模型请求、全世界最多32分析任务、一个完整预演，成员增加不复制模型。端点选择为公开适配器接口，不冻结AgentKit内部架构或依赖私有源码。连接不可用时显示只读／结构化基本操作和被动模拟；完整自然语言规划验收必须使用实际AgentKit与真实模型，不以脚本替代。

## 9. 试玩与体验验收

5名未读设计文档的测试者，各从引导小镇开始完成“查原因—比较方案—批准—快进—看结果”；至少4人无需开发控制台完成，至少4人能正确区分现金／应收、计划／投运和预测／实际中的两组差别。首次有效决策中位数目标≤30分钟，错误授权可恢复为合法新方案且不回滚已发生事实。失败必须记录具体阻碍，修交互／引导而非削守恒规则。

键盘／IME／VoiceOver／减少动态效果各走一次完整核心流程；全屏／外屏／不同缩放下相同选区与拾取不漂移。30分钟正常游戏＋真实模型完整循环，再用跨届／更新与供应续约长跑确认无需持续手动救火或无限补款。上述都是待实现／试玩的验收标准，不是本轮通过结果。
