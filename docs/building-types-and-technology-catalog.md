# 建筑类型、规格与技术路线目录

设计补充：v0.4.20，2026-10-19。本文是住宅、工业、商业、市政设施及关联空间设施的内容分类与范围目录，覆盖主要用途和技术路线，不穷举现实行业、地域风格或每件美术资产。[13个基础样例](first-release-object-templates.md) 用于验证属性结构，不是全游戏建筑目录，也不是只有13栋可建。

v0.4.25现行粒度与预算以 [整体分配审查](granularity-allocation-audit.md) 为准：34属性／14系统／27物件逐项区分保留、聚合、延后；新增基础本地供应计费绑定使用原区域余量4 MiB，现为27项43.0078125／44 MiB、余0.9921875 MiB，应用目标不增。下文39.0078125／26项是此前基线，不作本版准入；未验证布局／索引与16 GB实机性能。

v0.4.24的 [覆盖矩阵](object-definition-coverage.md) 逐项保留本文90类范围／就绪轴，补上所复用契约、参数／表示缺项和独立机制门。共享基础OBJ或有字段字典不代表后续类型已开放；按 [粒度收敛](model-granularity-and-convergence.md) 先尝试共享profile或有界分组，再批准新增状态／算法。

所有条目当前都是**文档设计候选，没有已实现并验证的游戏内容**。下文“首版”只表示计划支持相应有界机制；参数／几何／资产未配置，仍不得在工具中当作可施工、可投运模板。

## 1. 分类规则与双轴状态

内容从四个维度组成：建筑／空间形态＋业务／技术机制＋规格profile＋权属／经营安排。实际asset_ref绑定冻结模板和所需profile，实例另有自己的状态与身份，不按目录行直接生成对象或经营者。

| 标记 | 含义 | 例子 |
| --- | --- | --- |
| V 规格变体 | 相同输入种类、约束及交付规则，改变有界尺寸、单元数、容量、效率、班次或外观；几何仍逐资产验证 | 同类泵站小／中／大，单一制造配方不同产能 |
| M 机制类型 | 需要新的输入类别、权威状态、交付／需求、时间／环境／制度规则；可复用组件和部分算法，不能仅调数值冒充支持 | 风况出力、化工危险物、酒店住宿、储能SOC |
| V＋M | 某路线本身需要机制，路线内再有规格变体 | 核裂变不同功率机组、污水厂不同处理规模 |
| Q 权属／运营维度 | 与形态及技术正交；只按真实权利、合同和适用运营主体形成组合 | 独栋也可出租，高层也可自住；私营电厂同样须合法供电 |

**范围轴**：首版＝纳入既有首版有限闭环；后续＝明确候选、当前不承诺开放；远期＝需要独立玩法／技术假设的候选。不存在用“高等级”把后续机制自动升级进首版。

**就绪轴**：A＝沿用已定义的有限机制，仍缺最终profile／资产和实现验收；B＝还缺新机制契约／状态预算，不能只补参数启用；C＝设想，连玩法或技术假设也待定义。A不代表代码已存在；运行时仍区分template_unconfigured、unsupported、unknown及真实零。范围与就绪分别查询，不用单一“已支持”布尔值。

目录ID（CAT-R／I／C／E／W／P／T）只用于分类，不等同于P属性、C能力、O经营profile或asset ID。同一路线可有多资产；同一资产可承载多个合法用途，但真实面积／权利／入口／占用不能复制。

## 2. 住宅：形态、单元与权利分别组合

所有住宅复用C11及住房／家庭权威，分开记录建筑楼面、可交付单元、每单元人数上界和实际入住。户型、楼层、装修或售价不直接生成高收入人群、满意度或人口。收入与生活反馈仍沿劳动、真实工资、消费、费用、环境和迁居链。

| CAT-R-02 联排／院落住宅 | V：联数、单元、共用庭院／通道 | 首版／A | R-H1及共享空间规则；每栋／单元／使用权按真实实体分配，不凭外观免费增户 |
| CAT-R-03 低层多户住宅 | V：楼层、户数、单元面积和公用面积 | 首版／A | R-H1为基础样例，实际可配置多种资产 |
| CAT-R-04 中层集合住宅 | V：楼层、户型、公共区域、规模 | 首版／A | R-H2为基础样例；不自动满住、不按楼层重复生成土地 |

| CAT-R-10 乡村／农住混合地块 | V＋M：居住与生产用地分配 | 后续／B | 住宅部分复用；农作／养殖独立机制，院子不能自动产粮 |

| 权属／运营组合Q | 首版范围 | 新增限制／后续 |
| --- | --- | --- |
| 自有自住、普通租赁、受限全款买卖 | 沿现有单元锁、产权／租约、押金、欠租救济和原子结算 | 不提供按揭／证券化／无限房东信用 |

## 3. 工业与生产空间：通用厂房不等于通用产业

O01一般制造、O02物流、O10施工、O11园林供方是首版经营profile；厂房大小／布局不直接决定技术、产出和岗位。每个经营地点引用P18.common，交付由唯一adapter产生。下列后续行未获新的商品、资格或运营单位额度。

后续类型开放前，逐项完成：真实玩法／需求→类型化输入／输出与状态→唯一writer／delivery_adapter→当前与摘要同钟推进→规格及全部必要profile→所有权／容量／账务守恒→法规／工程／维护／退出→新增P／S／M对照→实例／曲线／队列／历史／视觉预算→保存恢复与16 GB负载验收。不能先把B改A、或把目录改“首版”，就当作这些门已通过。

## 11. 参考边界

分类用于游戏设计，具体参数、等级、地形适用和工程安全不引用为现实规范。以下官方资料只帮助核对技术大类及明显机制差异；本文的首版取舍与简化为MyCity设计决定。
