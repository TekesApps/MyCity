# 首版数值、23类配置与最小资产 C48

设计修订v0.4.48。将[DP34](first-release-type-definition-pack.md)、[LC38](first-release-lifecycle-inputs-and-exit.md)、[RUN36](minimum-operating-parameters.md)、[字段字典](capability-field-dictionary.md)及[属性—系统—指标](property-system-metric-matrix.md)合成一套可直接开发的非代码配置。明确是原创游戏合成候选，不是现实工程、医疗或法律标准；不以性能／试玩缺证据阻止选定必要参数。

交付[23类catalog.csv](inputs/baseline-v1/catalog.csv)与[numeric-v1.json](inputs/baseline-v1/numeric-v1.json)。每行CAT与90目录首版集合严格一一对应。已有13结构样例、27物件族是复用契约，不增23套系统。后续66类型／远期1类型按原目录延期，组合扩展、天然气、铁路／航空等不因配置表存在而启用。

## 1. 文档输入完成与实际验收分离

D＝规则／参数／数据语义已定义；A_doc＝已有明确合成记录或可唯一构造的有界规则，必要来源／数量／版本／权利／责任均可指认；I＝实现／加载／布局／表示验证；V＝运行／试玩／实机验收。本次完整目标的设计冻结须D与A_doc齐，I/V列验证方法即可。A_doc不是可加载存档、结构体可装入或经济稳定。

旧AS44/SP45/FP46的B/M/A是历史装配过程记号：其中加载器、sizeof、真实运行观察与美术最终品质移到I/V，不能继续写作“首版设计待定”；真正缺数值／几何／法源／接收责任的项由最终统一输入显式补齐，不能仅改名A_doc通过。合成数据与确定算法同等有效，不要求手写数万户或事先具备Rust导入器。

## 2. 数值协议 numeric-v1

| 量／范围 | 现行表示／尺度 | 积分、精度及失败 |
| --- | --- | --- |
| 钱／账户／债务／资本／成本 | i64分，100分＝1游戏币；单账户绝对值≤10^15分，现金不得为负，债务为独立非负原票 | 单价用i128有理数，乘除检溢出；未来钱不入现金，保护取不重叠并集 |
| 商品Q／固废Qw／m³／kWh | 各自i64微单位，每基准单位10^6；不同类型不可相加，单源绝对量≤10^15微单位 | 相同源累计函数F(X)=floor(精确累计有理量)，提交本次差F(X新)−F(X旧)，保留余数／原覆盖，不能逐步取整丢小量 |

| 评分／EI／NI与误差 | CPU参考f64；LS42既定f32锚点上下界向外包络，仅分数为0—100，EI／NI为非负游戏指数、不截为100；评分认证最大数值误差0.001分 | 保存／恢复保留策略／覆盖；UI一位小数只显示，不反向参与门。未知维仍[0,100]，阈值区间不明则不可证明，不把round到35当达标 |
| 标识／版本 | typed ID＋generation／revision，持久source与world/branch／operation／phase | 文本名称非身份；计数／句柄超范围拒新，代际不回绕复用旧事实 |

退款／退货／分红冲正沿原票累计差和合法区间，不把负数独立floor变退款套利。所有债权／商品会计中间乘积用i128；范围内算不出就停事务，不饱和截断。每日工资、每周／公历月付款、30日住房租期相互独立。Qw是本游戏容量当量，不当现实吨／立方米。

工资例：20币/h工作1秒应计2000/3600分，连续3600秒合计2000分；拆成任意区间只改变余数路径、不多付少付。消费0.5Q／人／日为500000微Q；1.1G02→1G03＋0.1G04在整数微单位可精确表示。网络存留0.99^(L/100)计算f64参考与保守误差后累计到原物理线路来源，不因重命名／切边返还损耗。

8个资格位固定driver／electric／water／medical／nursing／police／fire／teaching；基础／技术／专业是技能3层，普通维修／行政／园林是工作能力profile，不再占第9资格位。教育背景general/vocational/higher与资格、技能、工资不直接等同。FP46的ordinary_maintenance文本按能力解释，原资格证据仍由统一合成宪章／记录提供。

## 4. 默认可构造空间、口与单元

所有静态矩形profile以site西南为局部(0,0)，默认朝向0°，楼体x偏移(site_w−body_w)/2、前退界6m；本表所有建筑均可放入site。地基仅覆盖基底、深0.60m，无地下室／桩／悬挑。地形平平台；用户其他地形须实际土方／坡度门，不以profile免费平整。旋转整个site／楼体／门／管线／接近包络，禁止镜像变更功能。室外基底无楼壳，工具／储位包络仅在自身site内，视觉高度不产生额外楼面。

默认P口在楼体南墙中点，宽2m、高2.4m、步行／授权便携服务双向；到临路边界为6m净走廊，接正确侧人行道，门／内部通道共享120人次/h。R与训练3口＝P＋E＋W；P07仅公共人行1口；C/I/普通P为4口增加东墙中点人员／手推车服务口；P04的第5口为西侧车辆调度口，其独立场地／机动沿统一场景几何，不能混成第二份消防队。线性边2个真实网络端点，T03一个装卸接入口、T10一个配对边界引用，不套普通门坐标。

W01单列四口：南边人行、北边电、西边进水（仅进入）、东边出水（仅流出），进／出是同一源→泵→网络流，不能变两份供水；位置分别为楼体南／北／西／东边中点，水口位于z=0设备接口，经受支持管线／套管接入，电口不得作为进水口。

I03／I04／P05无楼墙，按site边界中点生成南人行、东作业／搬运、北电（x=site_w/2−2）、北水（x=site_w/2＋2）；P07为site南边中点人行口，T03为site南边中点装卸接入口，均不从body=0推导墙面。室外电水接口有既有设备箱／立管包络，设备箱不增加楼面或O；线性设施与边界另依端点。

E/W入口位于北墙中点左右各2m，z=0的受保护设备接头。主干在沿街路权北侧y方向固定深度E0.8m／W1.4m，外包络半径0.05/0.10m、异资源净距至少0.30m；支线绕site西／北至E、东／北至W，不穿楼体。最后上升至z=0的立管经预定义边界套管：套管半径0.15m、贯入／检修授权是楼体整包的一部分；基础仅在此明示小范围相容，不因管线全处U1就自动允许任意穿基础。

单元组不逐房间：R01一H；R02两H；R03四H按上部楼层稳定槽；R04第0层公共、四上层各4H。每H套内面积沿catalog，余楼面为结构／公共不出租。全部居民RG1到P，粗时长20＋10×楼层号秒（地面20秒）；公服从获准P或真实东服务口接公共工作范围，不能凭组用任何门。商业P入口内部15秒、服务口内部15秒，仓库装卸依真实泊位0.5h另计。

内部电水用已安装整套配电／配水profile，整栋真实入量按H／O／公共实际分配，内部线损／压力在首版profile中显式取0作为聚合排除，外部线路损耗照计；这不是创造能量。楼内系统共享故障域，每H引用同一根／隔离依赖，不自动每户一份阀／电表。内部容量至少等于已声明建筑峰与批准现场余量，受上游实际源限制；报价／维护／退出覆盖该整套，不能用此获得燃气或额外动力。

供方与服务车辆默认在有权且会阻真实路段的路边泊位停靠，人员／手推车经受控过街进入服务口；粗驾驶机动是冻结的整车扫掠／占用macro，不逐车物理但须包络合法。没有实际车辆口／可返回macro的地块不能投运依赖车行服务。最终统一输入提供具体macro，不再以“以后选车辆算法”代替初始路线决定。

## 5. 班次、报价与可逆参数的首版取值

普通业务默认周一至五08:30—17，含30min不计薪轮休；零售可明示07—15／15—23的双8h班并按人数轮休、最低2/3人受限工况；24h设施用三8h班、每人≤40h/周并留可验证休息／替补。招聘／班次规模取实际场景，不用参考FTE自动造人；仓库／煤机／公服关键工种必须同时完整。排班约束算法：按资格槽、班次开始时间、稳定人员ID轮转分配，只在本周≤40h且不与原工作／课程／休息冲突者中选择；不能分配则该班真实缺岗，不能加人直到可行。统一合成场景另给足额名册／排班规则。

普通报价profile默认基本岗位16币/h、技术20、专业28，电气／管网24、医疗36、护理26、警务／消防24、教学28、驾驶20；这是岗位公开价，不是居民学历直接给工资。小镇已签20币/h及FP46的8/10外部合同为显式场景覆盖，不追改；同一人同段保障／工作／通知只一次毛薪。日结18:00、周结周日18:00、月结次月1日18:00；未配置雇主按周结，新旧周期不可重付。

普通合成场景商品成本参考G01煤8币/Q、G02原料12、G03批发24／零售32、G08种植10；一般固废接收2币/Qw、G09为3，现场运送另按实际报价。小镇沿原一般品批发12／零售48和现行2/单位运费；不是擅自热改旧店利润。电用户0.2币/kWh、水2币/m³，成本与源端上游价须场景有对手，网络产权不自动产生转售收入。

住宅初始租金默认每户20币/游戏日，30游戏日租期应计600币，普通无租约空房全款挂牌价＝该H按套内份额分摊的冻结楼体K，不含整地／道路所有权；卖方产权范围／维护义务明确，成交不保证有买家。地价显示基于现有合法房源／维护／通勤成本和冻结供需报价，不直接生成现金。动态地价／商租／股票二级市场及无边界玩家自定义复合楼仍延期。

课程固定120实际授课h且最低90日、每天2h、10席、授课资格1、每人全课程1200币按实际完成授课比例应计／月结；允许已资助退出结已授课与退款，不能免费刷资格。入学需基础背景／技术课程所需前置技能及工作学习日合计≤8h；资格课程只授electric或water，医疗／护理／警务／消防等初始资格来自合成登记，不用90日万能课程取得所有资格。考核为已完成课程及≥90%出席与合法实际工时／版本证据，阈值确定无随机抽签；缺教师／资源延后。

所有普通价格／排班为可逆合成初值，首次校准范围0.5—2倍；生活／容量／费用守恒和权限不随校准改。需改范围的参数在原型记录问题与版本，不因纸面未能证明均衡无限拖延。

## 6. 23类最低原创表现资产

首版不等待正式美术：按catalog的真实基底／层／包络构造原创低面数占位网格。住宅用屋顶／窗带区分1/2/3/5层，工业灰棚／设备箱、商业连续招牌条、市政加原创几何徽标；煤机有受包络限的烟囱／设备、泵有水口／电口标记、废物有封闭区／剩余量、公园100硬质＋100植被、培训有教室图标。只增辨认，不凭外观扩大有效容量。

P口标地面短箭头／选中开口，服务口不同形状，电／水接口独立图标及连线；默认占位碰撞只取本模板保守包络，不用窗口／屋顶装饰当可穿行路径。道路8m实物横断面、曲线／端口与实际方向一致；地层图水电有真实深度／上升段，遮挡透明只改显示。

每类至少1套可构造mesh／material规范、4个朝向、规划半透明／施工阶段／停用／受阻／选中状态。实例着色与轮廓、文本标签三者可分辨，不只靠红绿。LOD只减少装饰／纹理，不把门移到另一面；门／管线及受影响范围可在低LOD检查器明确显示。

音频最低4类可合成原创短提示（接纳、完成、需决定、受阻）与可关闭环境声，无必需背景音乐／配音；字幕／文字永远有等价信息。资源占原0.85GiB资产域及0.25GiB渲染域，贴图先用调色板／小图集，不因23类型各预留整套高分辨率纹理。声音开关、动画密度和视觉实例不进入模拟NI／OD。

## 7. 责任、退出与完成条件

每CAT必须有对象/产权／operator、公共/私人款项、实际资源／同一容量键、门／管线／内部组、维护与环境profile，及LC38的停止新增→旧占用／在途→合法移交／清废→纯金钱债转原表→释放实体条件；这是一行CAT引用组成的完整定义，不必把23行生命周期再复制一次。未定义新效果不能沿“根组件支持”暗开。

新建／拆除工程资源选定为原有界承包工料包而非新钢水泥商品，最终G06需真实接收。燃煤灰、停机保护／余料、泵测试水、留观患者、旧住户、已派出队伍、旧工资和住房权均沿原唯一权威，不因数量小或画面不显示免去。具体正常／失效验收按T47的INV族及LC38，不追加单个事故故事。

本篇冻结数值类型／23类字段与规则引用、默认门组／内部配套／最小资产／可逆价格。实际sizeof／索引装配、几何稳健算法／车辆扫掠验证、代码／美术音频生成、GPU误差与经济平衡属于I/V；下一输入包须给两世界的具体覆盖，不能以本篇又写“参数未来再配”退回缺项。
