# 环境、公服与家庭满意度闭环 LS42

设计修订：v0.4.42，2026-10-19。接续[City清单CD-03](city-design-closure-checklist.md)、[RUN36](minimum-operating-parameters.md)、[LC38](first-release-lifecycle-inputs-and-exit.md)与[FB37](household-business-feedback.md)。本篇定义有限正常需求、真实人时暴露、8维目标／平滑和自愿迁居；参数是游戏候选，不是医学、声学、治安或现实居民行为预测。只补City文档，无实现和16GB运行证据。

LS42为START36后继策略，不追改既有冻结案例的请求、费用或心情。原工程、工资、产权、司法、容量／服务交付、财政和[ME41](market-entities-and-equity.md)的唯一权威不变；情绪不能代替任何许可、资源、治疗或实际搬迁。

## 1. 有限自然服务需求，不依赖预算／空位生成

首版正常发生的是**基础服务需要代理**，不称真实疾病、罪案或火灾。对已接纳且n>0的每户F，按下面周期产生一个单位的家庭服务需要；医疗只要求现有非侵入基础评估，警务只基础安全检查，消防只已有有限用水检查／演练。医院既有支持性留观、床位／护理与安全退出仍按LC38接受明确类型化需求；本包不新增疾病驱动入院、药物、伤亡、拘押或火势传播。

| 类型 | 候选正常周期P／发生与期限 | 唯一交付与能力边界 |
| --- | --- | --- |
| 医疗基础评估 | 每90游戏日一次／户，08:00发生，次日08:00期限 | RUN36现场评估，真实合格工时／水电／正确门和服务接受；不能一次算现场评估又算医院接诊两份 |
| 警务基础安全检查 | 每180游戏日一次／户，同一发生／期限规则 | RUN36／LC38基础检查；不据此宣布破案或降低一个未建模犯罪率 |
| 消防有限检查／演练 | 每180游戏日一次／户，同一发生／期限规则 | RUN36／LC38的0.5h任务及真实临时水电／工具；不据此宣布扑灭真实火灾 |

周期相位phi=(稳定家庭token＋world_seed＋31×类型序号) mod P，类型序号0／1／2；用固定整数运算且中间值检溢出，不由显示帧或线程顺序随机生成。发生日满足day mod P=phi，初次只接受家庭合法进入后的发生点，不补发入城前历史。token含原稳定身份／代际，迁居、群体拆并、换相机不重抽相位；换规则只从显式未来边界生效，已发生窗按原覆盖去重。

每F／类型最多一个未解决需要。若上一需要仍有派出／在场／返程责任，新的周期点只提醒**同一尚未完成的基础需要**，不再增加独立需要量或收费；这是上述单一周期评估机制的合并规则，不适用于独立患者／真实事故。预算不足、无合同、无队伍／道路时仍生成需要并记未满足，不可将“未受理派遣”当“没有需要”。默认关闭RUN36的验收注入；显式注入是独立测试来源并标记，不混入正常履约得分或重建已发生请求。

新增自然需要不扩大原S的28日供应／每类4次验收任务额度，不免费增加财政预算／资格／车辆。新正常合同须按原程序真实落实；不够就有未满足与相应满意度后果。无自然疾病／事故模型不表示城市没有健康或安全风险。

## 2. 需要、等待、派出、完成与期限分开

源键为(world, branch, F稳定代际, 类型, 发生日)，规则版本作为该源的冻结依据，不作为同一发生窗重领资格。需要记录先存在，再按原预算／优先级／同池容量与路线决定是否派遣；原[2048服务交付槽](performance-budget.md)只承载已接纳的真实占用／派遣，不同时充当无限等待队列。

状态为waiting→admitted／dispatched→on_site→work_complete→returning／reset→closed，另有expired_unmet／partial／cancelled。接纳前落实费用、现场资源与返程保护；不能替市民自动制造债务或让公服人员免费作业。等候时不占床位／队伍，接受原预留时才占；完整返回／整备前不释放任务占用。

到期限时将当时实际结果封闭一次：未派出可结为逾期未满足；已派出／现场／返程继续保留实际任务与原需要关联，不因期限删掉人员／车辆。晚完成可减少仍未完成工作，却不能改写“原期限未满足”或重收同一工作费。新需要槽只有原已发生结果持久化且任务责任依法结束／移交才可复用。原需要／部分交付／收费来源保留，重试须另有原授权／资金且不能再算一次自然需要，LS42不自动无限重试。

目标变更／迁居不能瞬移服务队或重开需要ID。未派出时可按合法新接入及原期限重验；已派出先处理原任务／安全收尾，后续交接有独立授权与真实交通。已完成原处检查不能算新住所又完成一次；家庭日得分只读取与实际受服务范围相符的来源，不能让旧地址交付虚增新住所服务。

## 3. 暴露按实际人时，位置未知就缺覆盖

每成员／劳动份额在任一游戏区间只有一个实际所在上下文：合法居住／临时停留、实际岗位／教学、已接受出行或其他已支持活动；计划在家不等于实际已返家。共同行为可按同一家庭中同上下文／时段的真实人数聚合，人数和不超过F实际n，工作、上课、路途与居住不能各算一份24h。无逐秒个人agent或新的人口全属性组合。

每个封闭游戏日累计实际总人秒P、休息机会窗人秒Pr及相应有效覆盖。休息窗取冻结作息profile：默认23:00—07:00，已支持夜班可显式用09:00—17:00，均8h；这只是休息机会，不判断是否真正入睡。窗内若还在路上，采实际路途噪声，不把人搬回家；Pr是P的子集，不另增加一天人时。未配置夜班／成员休息窗则该部分unknown，不能用全城22—07诊断窗代替所有人的作息。

读取RUN36／LC38同一EI与线性NI、源／场／数值锚点。空气按全日实际人时均值；噪声同时保留全日均值、休息窗均值和休息窗峰值区间。家庭空气均值不能宣称每个成员都达标；既有敏感住宅／峰值诊断独立展示。事件／换位置／源变化截断实际积分，噪声不写成dB，绿色外观不自动净化空气或治愈。

跨图工作／出行读取对应真实来源或有证据误差区间的摘要受体；只有代表时间而无环境范围时为unknown，不拿住宅值补B城工作暴露。统计保留已知人时与缺口；不足全覆盖时不按已知少数时段重新归一成好环境。数值误差按[CG39](cpu-gpu-compute-contract.md)门处理，不能把未准入GPU场或陈旧画面当本期观察。

## 5. 公服潜力、实际履约和无请求的中性值

A的比较分母固定为本有限任务策略的闭合日08—14这6个游戏小时的服务接受意图窗；分子只计其中有资格／资源／有效协议及合法接入、结构性响应路径，并能合法接纳及完成去返／收尾的时长。接纳截止必须遵守RUN36的min(合同到期,18:00)−4h或该已冻结profile更严格条件；值守未结束不等于仍可接新任务。A=该可支持时长/6h×100，合同不足造成的缺口仍进分母，不缩分母虚增覆盖。用真实设施有效能力与合法协议／路线覆盖，不仅看购买了容量；不把队伍当时忙于其他任务再次计为结构停运。A是可接近潜力，**不是已预约名额或保证可用队伍**，实际派遣仍从同一剩余池竞争；原30min响应目标和道路／边界时间不放松。多户读到同一供方不增加其容量。

D只统计原期限落在该闭合日且实际服务范围匹配的自然需要：每源完成比q=min(期限前已核工作/该源必要工作,1)；响应时间从原需要发生至实际正确入口到达，含排队／等预算／等受理／准备／行驶，不能改受理或派出时刻重置；到达≤30min时响应因子r=1，30—120min为(120−到达min)/90，≥120min或未到场为0；D=100×sum(q×r)/期限需要数。迟到仍可能收费／完成真实工作，不能因心情低就免除成本。部分／逾期不重算成新需要，注入请求不进入D。

该日确证无到期自然需要时D=50中性，另显示“无本日样本”；不是100，也不从无需要推断无风险。是否有需要／实际交付缺覆盖时D为unknown而不是50。T=0.4A＋0.6D使真实缺服务有后果；无请求且A=100时T=70，A=0时T=30。D仅给本日到期样本一次后果，此后由7日平滑衰减；未完成任务仍显示backlog／真实责任，不每天复制一个新失败或新需要。本日无样本的50中性不是证明旧问题已经解决。实际完美履约且A=100才可能100；家庭没有服务资金时需要仍进分母、未交付不被抹掉。

A及D从原服务／路网／法律／需要来源分页计算；不能用可淘汰监测桶作行为权威。服务费按原真实工作、准备／返程与保留条款结算，T不反向改账；服务100不代表已治愈／没有犯罪或火灾，也不直接加人口。

## 6. 平滑、未知与连续14日证据

8维各用同一tau=7游戏日，在冻结目标区间解析S_j(t)=U_j＋(S_j(t0)−U_j)×exp(−(t−t0)/tau)。保留上下界与目标版本，未知目标取[0,100]，已知值／数值误差用有覆盖区间；加权总分也给上下界。计算／存储必须保守包住误差，区间过宽时不声称一个精确心情。查询／显示帧不重设锚点，日目标换版／合法输入变化才封旧区间并建立新锚点；不按逐帧取整。

新场景／新家庭可显式给8维初始50作为候选开局状态，不称已观测历史；旧家庭恢复原锚点不重置50。输入滞后一天不允许跳过实际消费、租金、服务与暴露。对未知区间不冻结一个旧点值冒充新观察；即使平滑区间后来缩小，也不追认缺测日是连续低满意。

权重平均不能遮住严重短板：当前无合法稳定住房时有效总分上限20；上一完整日基本商品／必要电／水任一满足率<0.5时有效总分上限30，持续到有完整后继日证据解除。上一完整日空气或噪声目标分上界<20，或任一基础公服A的已证上界<20时，总分上限也取30，在后继日目标区间生效，使持续严重环境／结构缺服务能进入原14日调查，不被其他高分完全遮住。这是非补偿性的居住底线偏好，不是额外累加处罚；原因按无稳定住房／基本需求／空气／噪声／具体公服类型标记，各cap只取最小值。按真实来源去重取最小上限，不额外改8维、不扣第二次钱。上限不是驱逐／断供／强迁依据；紧急安置与安全保护按原法律立即走，不等待14日或满意度证明。
