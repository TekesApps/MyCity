实际Account／Stock Arena及索引、Claim／Payroll／资源／租约之外，26张typed stub表按64／128／256B记录和u32路径引用实现，包含全部冻结数量。22800家庭成员数合计57000人口，未增加57000个逐人actor。每秒扫描361272条native与1232426条stub／引用，共1593698条；所有压力页每4096B触页，每次实际改写1MiB。七域填充含192MiB预览和32MiB计算替身，均非渲染或真实交通求解。

常态128MiB COW占位页实际触页，写时先释放对应占位页再复制。恢复临时借用同池64MiB，固定native解码容量37488560B＋最大替换缓冲12582912B＋解析／栈余量6291456B＝56362928B。此为固定输入结构上界核算，不是allocator峰值测量或任意恶意JSON保证。文件逐项写入／fsync／完整读回及恢复校验，目录持久后发布，再回收旧恢复点。快照线程仅用于L1诊断，不更改权威Sim／独立worker架构。

冷开必须实际装载全部native、stub、压力页及工作占位页；单遍读取同时校验SHA256，候选通过前不返回。layout-v2包含明确变更计数；早期layout-v1仅在已有明确计数时读取，不猜测旧快照丢失的计数。工作占位文件是压力图像，不是实际业务COW对象序列化。

观察器以PID＋Mach出生身份追踪自身、模型及已观察孤儿，短命helper身份退休。每250ms目标采样、60秒CPU／I/O／系统详情，使用SDK实际proc_pid_rusage与Mach时基。各进程在窗口内依次读取，RSS／footprint是“采样窗口内求和观察峰”，非严格同时；窗口、漏采与短命helper峰不完整限制保留。热数据自限2MiB并计入4MiB元数据／I/O预留，与Rust Metrics合计不得超过8MiB。原始日志流式有界，原始9B计时由独立外部归并排序核对nearest-rank。
