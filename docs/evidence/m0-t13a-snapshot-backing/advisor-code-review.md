# Advisor代码审查与处理

既有boot_advisor只读检查Snapshot运行、join后回收、Reserve、借用I/O及完整冷恢复；未执行负载或修改文件。静态未发现新的COW竞争／虚假还款阻断，允许继续定向验证，不能据此认为第二次快照OOM已修复。

- 完成对象保存旧页，主线程join后回收时序成立；共享页仍归世界。
- decode债独立，逐页成功才减债；中途失败不能声明额度恢复。普通读回失败仍尝试还债，再返回失败。
- 正常I/O切片复用、EOF/长度/SHA保留；短写交给write_all。写错误必须立即弃用writer，不重试部分已写缓冲；当前调用均以?退出并保留pending。
- 指出完整冷恢复仍预建持久2MiB、每次另建临时1MiB：已修为Load::restore全部使用已有io背板，records-only独立兼容路径保留自己的局部缓冲，不与完整L1世界同时常驻。
- decode loan64仍释放/重新申请，可能碎片化，尚未消除。这是需原完整负载实际跨过第二及后续快照来判断的风险；阶段日志用于定位，不作为已修证明。

失败时保留最后申请前记录、申请页序号及未偿decode债。记录里的总free不证明存在连续1MiB可用块。
