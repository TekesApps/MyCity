## 独立核对与限制

[独立脚本](validate-employment.py)可直接在本证据目录运行；[18行核对结果](employment-independent-validation.json)涵盖三次各六组的家庭/两雇主现金、工资、原料、产品库存与retail收入方程。默认收入组另用逐日预算oracle独立算出87/43及对应现金。销量由实际需求、购买力、价格、可达性与库存计算，业务命令不写固定日销量。

固定自然参考需求为4件/日，共112件；参考未满足量是112减实际销量。资金充足换岗组缺12件，不能因 `unmet_market_demand=0` 说参考需求全部满足。收入组参考缺口25/69，需与原市场需求字段区分。只核对这些固定需求，不外推完整满意度/迁居系统。

[advisor聚焦意见](advisor-review.md)未发现本限定发布的具体阻断。完整同开局依据共用builder及Scenario继承的源码核对，汇总断言不等于完整字节身份。新雇主没有新增生产/服务配方，其工资由期初资本与可能的零售收入支持。没有实现全局雇佣授权、内生岗位/技能匹配、劳动法律流程、其他债权清偿或清算。本例仅在内存Engine中运行，不是Store持久恢复验收。全部期初资金/retail库存有明确资本来源，仍未证明持续自融资或完成经济平衡。
