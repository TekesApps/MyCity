## 1. 范围、完整度与实现分别标

范围／A-B-C就绪轴沿原目录，保持首版有限内容，当前无游戏实现。另用独立完整度维度：结构已定义（身份／能力／权威）；限定契约已登记（必需语义／守恒／更新／失败／退出）；参数待配（必要profile缺值则不投运）；表示待验（字段／索引／精度实际尺寸未验）；机制缺失（需新状态或运算）；实现／验收未有。几种标记可以同时存在，不用单一supported。

所有首版行仍共同欠具体资产几何、全部必要参数、表示／索引及真实运行验收，表中列各行特有门，不能因未重复列出而省略。后续行只可复用已有基础部分，OBJ引用不表示新技术／用途已经闭合；复合／摊位数字案例也是后续B验证，不自动变A。

| 完整度标签 | 可以说明什么 | 不得宣称什么 |
| --- | --- | --- |
| 限定契约已登记；参数待配／表示待验 | 可以追到字段、writer、计算与生命周期，生成待配置清单 | 不能投运缺参模板，不能当sizeof／经济／16GB通过 |
| 机制缺失；可复用基础 | 可以列复用原空间／主体／网络和需补字段 | 不能仅改名称／MW／容量启用新机制 |
| 远期设想 | 只定义方向／技术假设缺项 | 不能形成可执行工程或保底收益 |

## 4. 如何收束缺项

每种asset依次过：目录范围→注册OBJ/C/P→字段与唯一writer→粒度／误差与最小状态→几何／全部必要profile→表示／索引／历史与全世界联合准入→生命周期／交付／财务／故障验证→实际实现及硬件验收。禁止通过新增字段数、复制示例值或调高容量跳关。

首版23条目录含CAT-E-16／CAT-W-02的有限抽象分支；其细网分支仍B。其余66条是后续候选，聚变1条远期；这些是目录条目数，不是资产／行业／实例数。某行包含多个路线时逐子路线完成，不能以最成熟子路线覆盖全行。

本轮不新增全对象字段表、组件种类、P/S/M族或行业／商品／资格额度；矩阵为文档索引，运行时schema沿64热页及原绑定／索引准入。原区域39.0078125/44 MiB、后续扩展0.125 MiB、其他模拟用途314.025 MiB及应用2.65/3/4 GiB目标不变。字段落实／真实几何、模拟平衡／收敛和16 GB性能仍未验证。
