# v0.4.24：物件覆盖、字段契约与复杂度收敛审查

日期：2026-10-19。范围仅设计文档，不写游戏代码；本轮承接物件细化，并按玩家补充先建立收敛体系，避免将现实细节无限复制成实例状态。

## 1. 结论与改动

先审 [粒度收敛](model-granularity-and-convergence.md)，再看 [覆盖矩阵](object-definition-coverage.md)、[能力字段字典](capability-field-dictionary.md) 和 [常用物件契约](common-object-contracts.md)。定义字段、实例持久状态、更新频率和动画实例分开管理：共享profile能解释的数量不逐件建对象；从原事实可推导的量不另造权威。

- 原90条目录逐项映射，范围／就绪标签不变：23条包含首版有限部分、66条后续、1条远期。电网／水网两条仍同时保留细网后续门；议会／司法制度不因物理政府楼后续而取消。
- 27类OBJ契约覆盖13个基础样例及道路、节点、管线、水源、地形、场地、门、设备和边界等支持物件。OBJ是有限语义契约族，不是27套新增表／行业／能力。
- 字典登记143条不重复通用语义字段路径，列类型／单位、必需条件、来源／唯一writer、触发和原落点；类型专用字段在OBJ节登记，不能据此声称所有资产数值配置已经完成。
- 每类物件继承真实空间／权利、活动、资源／资金、工程／维护、影响／观察和表示包，补上短缺／停用／故障／清场／移交。关楼不删住户、货物、在途、合同或债务。

## 2. 收敛怎样成为执行约束

新增细节必须回答用途、最小充分状态、聚合键、时间／阈值、误差、最坏资源、升降级和验收八项。能共享参数或查询推导的，不增加实例状态；仅外观差异留在视觉。参数、单位／范围、状态落点或误差依据缺失时，不能作为可投运配置。

20盏同类15 W灯每天使用10小时，类别计数与逐灯能耗都为3 kWh；模型不需要20个调度器。60 kW持续5分钟与5 kW持续1小时同为5 kWh，但10 kW接入只能从后者的功率条件得到可行依据；日均／日总量不能证明峰值合规。噪声、服务并发和交通高峰同样不凭均值过硬门。

聚合不平均现金、库存权属、到期、资格、产权或真实占用，来源和责任必须可解析。按整数游戏秒推进，最多1游戏小时候选稳定区间，遇最早法律／班次／耗尽／容量／维护／工程事件截断。可组合积分针对同策略同轨迹；非线性须验证积分法，不同近似策略另披露结果差异，不能借近似少扣实际费用。

相机与动画不触发全城微观模拟。负载不足先降视觉／可丢缓存、预测和软重算，再降实际日历倍率／停止新增承诺；旧义务、安全退出和已发生变化不能丢。摘要转换保留来源／锚点／余数，不从随机数重建缺失历史。

## 3. advisor复核及修正

advisor只读复核四份新文档，确认聚合保留来源、时间／策略区分、硬门／峰值、后续范围、有界水源、节点／基地无免费能力和语义不等于内存分配的边界可接受。指出并修正：

1. 通用容量resolver补齐住房S02→H、教学S03→T、岗位S06→O／劳动S03→E、水电S05→D／K／M；物理道路／独立空间仍S04，库存S07、服务S09分别归原表。预留、实际和释放沿同一资源键，不新增万能容量总表。
2. 端口人货通行状态归S04，水电接入运行／隔离归S05；S01只写结构与锚点。电／水边运行开关明确S05，结构可用、法律限制与维护条件各有来源，不能多人写同一布尔值。
3. 教育背景／技能／资格按实际成员或相容劳动来源作用，不把整户平均成同资格；教学参与与独立空间容量分别校验，不增加逐人活动调度器。

同时将经营身份S00、地点绑定S07、经营状态S06拆为不同路径，避免“多个系统管理企业”变成同字段多写。

## 4. 16 GB预算和仍未完成的部分

不增原16能力、34属性组、14逻辑系统、26指标族或联合条数；26项区域载荷39.0078125 MiB／44 MiB、余4.9921875 MiB不变。原模拟域358.4 MiB扣44 MiB区域、0.25 MiB模板页和0.125 MiB候选复合预留，其他模拟用途仍314.025 MiB；应用常态2.65 GiB、软限3 GiB、峰值4 GiB目标不变。

这些是预算约束，不是字段已经装入定长记录的证明。引用正文、变长页、代际／对齐、反向索引、到期队列、峰值／误差摘要和旧版本都须计费；装不下先缩支持范围／重预算。当前未配置的具体几何、全部资源／维护／费用／影响参数、精度范围、布局及实际运行测试均为开放前缺项。后续复合楼／摊位等数字案例不因此升级首版；完整土地市场、细水网、逐车和新产业机制仍不支持。
