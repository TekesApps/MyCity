### 定义、校验、发布与版本

定义流程：选已登记壳体和功能包→分配实际面积／层位／对外接口→选择有限共享支撑→声明产权／分摊／责任→计算设计工况／设备／工程报价→几何／用途／容量／依赖／资金校验→发布带内容摘要的template_revision→实例经W50建设。模块库初始住宅、零售／餐饮、办公／政务、停车、交通站厅、公共庭院共7类；新模块不能只填一个产能数，必须补本矩阵九项与resource profile。

宿主最多8功能、32共享组／依赖边；这里的DAG只约束模板引用／支撑依赖，不禁止真实环状道路／管网或有启动来源的联合水电分配；禁止的是从尚未成立的未来产出自举初始投入。共享设备只生成一份实际负荷，功能分摊仅分费用／责任，不能再各生一份物理用量。不同电梯／楼梯／变压器能真实并联才加容量，纯引用不能加。最大可出租面积扣除结构及真实共享通行，不给复式／挑空重复按两层计；人工绿化占地可与合法屋顶／庭院共用，荷载／维护／通行权仍查。每功能接真实外部逻辑端口组（每宿主≤8口），多个实体门使用同一组时不能各有满吞吐；超出时必须拆真实宿主或重预算，不能隐藏无限内部连接。

设备包按使用人数／活动／面积生成需求：照明／通风按运行m²，电梯按真实批次／次数，厨房按有用烹饪量，算站厅通行和商铺到店分别引用同一人流来源。基准运行设备默认P待机＋(P峰值−P待机)×活动率，其中活动率∈[0,1]、0≤P待机≤P峰值；已合法停机的功率另按停机profile；运行工况改变不免费变大已装额定功率。profile列明基础含项，拆出炉具／风机后从原基础扣同一项，不双计。

发布校验拒绝低于全部已选包确定成本／最小资源、面积为负、共享支撑不足、权利／保全未分配。用户可改变包／几何与有来源的承包价，不能直接覆盖成“收入×100、耗电0”。自定义技术系数只允许库包声明的校准区间并同步成本／维护曲线；超区间属于新技术定义／sandbox，不能伪装成正常经济资产。已建实例固定原版本，升级生成真实改造计划，不热改模板给全城免费换设备。

餐饮配方的0.1Q食品不等于全部变成可称量的一份实体质量：9成食品计已食用，1成废物0.01Q，水和电是投入与排放／污水来源，污水默认水入量90%，余10%为蒸发／产品消耗。厨房与家庭同一顿饭的选择替代，不把在外吃饭和家庭必需烹饪都计满。办公服务需求来自企业真实合同／行政工时，不按办公楼坐满就产利润。

## 11. E04：旅游、商务、工业活动与访客闭环

| 九项契约 | 总体方案 |
| --- | --- |
| 需求来源 | 观光来自实际吸引物／活动和可支付潜在访客，商务来自真实企业会议／服务合同、工业出行来自采购／设备安装／培训等实际任务；不可同一人同窗分三份游客 |
| 设施与主体 | 访客来源家庭或有限外部cohort、目的企业／景点／活动、酒店／餐饮／零售／承运／机场公司，境外来源的资金／人口／返程有明示池 |
| 资源与容量 | 可旅行时间／预算、门到门交通／返程、活动席位、住宿床位／夜、真实消费；酒店基准40房×2人、入住15时／退房11时、清洁0.5工h/房／每夜水0.2m³电5kWh |
| 成本收益 | 住宿100币/房夜、景点20/人、访客默认每人可支出200/日含住宿但交通另从已冻结预算扣；实际成交才收入；纪念物K与1%年维护并不发保底旅游收益 |
| 交通环境 | 入境→落地／到站→目的门／酒店／活动→返程全链，床满不能凭机场降落生成虚拟酒店；机场旅客／夜宿／独立访客三口径不重复 |
| 法律流程 | 真实出差授权／企业费用、住宿／活动／旅游服务许可、隐私与有限外部来源；补助推广须拨款／来源，不能造无钱包客流 |
| 失败退出 | 失接／无床／活动取消时先替代／改期／退款，滞留保留预算与地址；预算耗尽不强制消费，合法接收／返回有真实资金及承运责任 |
| 玩家观察 | 需求目的／来源／未成行原因、可达路线／住宿、企业实际支出／本地消费／外流／返程、机场航司酒店商户分账 |
| 聚合／writer／预算 | 同目的／时窗／来源预算与权利的访客批，S02意图／S04旅程／S07服务／S08钱，M-visitors；不创建完整外部城市与每游客全生命史 |

需求种子：每一真实景点容量C日最多产生0.2C潜在询价／日、企业每100已到岗工日最多1个商务询价、每100Q跨区设备／工业订单最多1工业任务；这是候选，不是实际到达。候选必须从明确来源池取人口／预算／时间，按总效用≥不出行基准才订；多个景点对同一外部池联合竞争。初始外部访客池每30日最多1000人、总预算500000币、可用1000个返程席位采购额度（仍须实际班次／钱）；来源为有真实资产／资金初始分录的外部旅游／企业群体，day30不自动补满，续期需新外部交易来源：原外部公司可按已有真实工时／资本收益从自己现金支付工资／股息到此池，来源和双方分录可查；没有收入就按现款缩出行，不能按月重发500000。城市内部访客用原家庭现金、不再领一份“游客钱”。

酒店／活动预订保留有限席位与押金，跨越退房／取消／失接按同合同累计；酒店满时可以只接一日往返者，不能让其一夜隐形。商务费用是出差企业真实成本，观光是家庭自愿消费，工业任务归订单服务成本，返回后不得再把同一费用全列成目的城市新增现金。

长期资源来源：农林／矿体／取水权／天气能量与有限进口、资本／维护班组和劳动由其他能力提供，不能每个行业通过“外界摘要”自造廉价全部投入。原材料耗竭／终点库容和外单到期驱动更新与外贸，合同续期有新额度／现金／有限窗口；关邻图或存档恢复不重置。

## 13. 跨域不变量与原型验证

复合住宅底商＋站内商铺＋广场摊位必须联合竞争同一人群预算／门／设备；旅客未到达不能当店收入。教育产生可用技能但不自动工作；招聘必须可达有薪岗位，企业少订单不能从“行业效果”取得工资现金。每个家庭身份／住所／收入／持股／遗产只一来源，迁居／改名／转售不抹旧权利。

验证至少含：教师学生劳动时间不重叠、家庭分立／死亡遗产与股份清算、不同工资周期和失业恢复、租约／商租／摊位到期、企业缺料／缺客／市场价格延迟、游客无床／失接／返程资金、健康事件与LS42不双罚、共享设施一方欠费／拆除保护其他方。人口率、配方、价格与偏好均需原型校准；可解释与守恒由不变量验，盈利／好玩不能纸面宣布。
