# City本身设计缺口与完成条件

设计台账：v0.4.37，2026-10-19。接续[全局缺口台账](global-design-coverage-and-freeze.md)，本表是当前City设计工作的优先入口；本轮不展开AgentKit。编号CD只作审查索引，不新增模拟组件／指标。

## 1. 怎样判定完成

每项分别标记：D规则／参数定义，A资产与输入可装配，I实现，V联合验收。D完成不等于A／I／V通过；实际无法配置的必要参数不得用0补齐。当前尚无游戏实现，所有I／V都未完成。延期分两种：后续玩法明确不进首版；首版资产／实现证据仍欠交付，不能靠写“延期”取消首版需求。

不把87篇以上文档当完成率。首版City设计基线冻结必须满足：下表所有D缺口有明确规则，或有不改变首版承诺的有理由取舍；所有A缺项有具体清单和阻止启用条件；所有I／V要求有可复用输入和不变量。不要求在写代码前证明经济平衡或实际性能。

## 3. 本轮交付与未完成内容

v37已补CD-01的有限固定报价反馈定义及专用状态预算，见[新契约](household-business-feedback.md)。v38的[LC38](first-release-lifecycle-inputs-and-exit.md)补CD-02有限生命周期D定义，A仍依实际来源／几何／费用／状态表示验收；不声称CD-03至09完成；依赖不满足时CD-01部分动作也不得执行。尚未开始AgentKit扩展，不将它排在City核心缺口前。

每项关闭记录必须给：所依权威版本、最小范围、明确延期／依赖、正常与必要反例、不变量、状态／预算和剩余实现证据；默认一个正常与一个反例足够区分规则后即停止扩案例。D完成可以候选值冻结，不冒称经济稳定、全部90类可用或16GB运行通过。

本轮后的预算以[行为状态预算](household-business-feedback.md#8-行为状态预算与恢复)为准：31项43.8828125／44MiB、余0.1171875MiB；旧29项43.5703125为截至v36的历史基线。规则与资产引用仍有限，新增状态不能借“继续补文档”免费进入实现。
