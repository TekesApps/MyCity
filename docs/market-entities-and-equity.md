# 市场主体、独立核算与有限股份 ME40

设计修订：v0.4.41，2026-10-19；ME40初稿v0.4.40，交叉约束见第10—15节。落实“经济以真实市场主体为依据，可查看注册公司清单；公司独立经营核算；允许股东出资、分红与财政再使用”。与[行业](industries-employment-and-effects.md)、[实物经济](physical-economy-runtime-contract.md)、[财政](fiscal-recurring-budget-contract.md)、[家庭反馈](household-business-feedback.md)共同使用。本篇是虚构游戏规则，不宣称完整会计／公司法或经济稳定；尚无实现。旧冻结案例不追溯增加股东、税或现金。

## 1. 五层身份，不以建筑或统计行业代替公司

| 层 | 权威含义／关系 | 不能混用 |
| --- | --- | --- |
| 登记经济主体E | 稳定entity_id、登记／实际管辖、组织形式、状态、规则版本、原账户／章程来源 | 公司、公共事业法人、政府机构／财政可登记；个人可直接出资持股，不给每位股东建公司 |
| 股东与持股 | 真实出资方→股份发行公司；份额及依据单独保存 | 股东拥有股份，不直接拥有公司账户／设备；经营地点owner仍指真实财产权方 |
| 运营地点O | 每个O只有一个实际经营地点、行业profile、雇佣与活动来源，并绑定一个责任E | 同公司可以有多个O；分店／分厂不必各注册新法人；同楼不同商户可以是不同E |
| 建筑／设施／单元 | 物理容量、设备、接入、产权、维护责任 | 房东、公司、实际经营者可以不同；机场建筑不等于航空公司 |
| 账户／库存／合同／账本 | 原权威记录引用E或家庭等合法主体；付款、财产权与地点分别明确 | 不再给E复制一份现金；O是核算归属维度，不自动再开一个钱包 |

首版每个公司一个主经营现金账户，受限额是该现金的保护份额；原真实托管另有依据，不借“分店内部钱包”加钱。分店间资金调度只在同法人可用现金与原保护内，不解除工资／收尾限制。不同法人之间必须真实交易、出资或有依据的转移；同一股东不授权混钱。

登记形式有限：可发行本篇普通股的公司；不得发行本篇股份的财政／公共机构；依法登记的独资经营者。摊位也绑定实际经营者和许可，不强制变成有限公司；独资者与家庭的责任关联须有明确法律依据，不自动从全家账户扣款。国有企业仍是独立公司；公立部门若依法直接属财政，独立成本中心不伪造第二法人／收入。

S00维护登记身份与版本；S07按合法关联维护O→E；S08独写资本、股权金融状态与账务；实物、雇佣、服务及环境仍由原系统唯一产生。公司经营决策由原S06／S07有界规则执行，不为每家公司启动agent。这里的E登记不同于旧文档雇佣边等局部表字母，查询必须用typed entity_ref，不能凭字母解析身份。

## 2. 可查询名册、责任与连续性

可分页查看全部登记公司及公共经营主体，按城市、行业、状态筛选；列entity_id、名称、组织形式、股东、关联O／地点、实际雇佣与交付、现金／保护／债务、当期核算覆盖及暂停原因。名称不是身份，名称和正文分页，查询附完整快照时间／版本／覆盖／数据年龄。具体页默认64、上限128行；没有展开的分店数不能假作0，未核算不能假作亏损0。

同公司跨地图只登记一次，O保留实际地点和劳动税归属。不开图仍按同钟同账运行；总部收到收入不使实际生产／通勤／噪声迁到总部地图。居民／企业可以在列表找到实际供货／雇主／债务方，不把有限外部供方匿名成“市场自动付款”。外部供方也有登记依据、真实账户及有限交付来源，不要求为了显示名称加载一座外部城市。

设立先有合法申请／章程、真实出资／账户及记录配额；登记不自带赠款、订单、经营许可或最低客流。开店再核地点使用权、资金、投入／岗位／接入和安全收尾。更名、迁址、换股东不会重置债务、设备年龄或冷却。O停业与公司注销分开：有库存／劳动／未了经营责任的O继续占槽；公司有资产、股权、债权债务或维护责任时不能硬删。最终责任依法移交和可追溯归档后才释放可复用槽，历史ID代际不得复用到新公司。

首版没有完整破产和股权退出市场；有限责任公司股东不自动承担公司全部债务，未缴认购／已签保证也不能靠退股免除。需要未定义的破产、代偿、资产处置或强制划拨程序时标law_unconfigured，保留责任并停止相关新承诺，不自动财政兜底。

## 3. 每家公司算什么账

所有交易有原票、实际双方、O／地点或全公司归属、商品／服务及时间窗、应计／现金类型与版本；S08沿原账本成对记账，不新增平行资金真值。公司总账从所有O和公司层来源汇总；分店内部划拨／内部调货不创造销售利润。公共服务效果与财务收益分别报告，允许合法有限补贴支持负经营现金流。

| 项 | 有限核算契约 |
| --- | --- |
| 营业收入 | 真实交付并满足原合同接受条件后确认；未交预收为负债，报价／需求／未出票预测不是收入。应收与实际收款分列 |
| 货物成本 | 实际售出／耗用／报废才结转对应取得成本；采购先形成库存，不能当期全扣成本又在售出时再扣。计量单位及权属沿原I表 |
| 库存计价 | 同一法人／相容商品计价类别共享成本池，物理库存／位置仍各归原I表。按稳定原交易次序，以取得事件为epoch：锚点Q0为取得后总量、C0为总取得成本，X为之后累计实际出库量。累计结转F(X)=floor(C0×X/Q0)，本次只结转F(X新)−F(X旧)，最终出清恰为C0。新购已交付时用剩余量及C0−F(X)加真实新取得量／成本重设锚点；不得因拆单／跨期封账自行重设。内部同法人调货不改变该成本池或产生新购，不能通过搬仓／拆I条目重置余数。物理库存与成本池数量对齐，零量池先结清；数量／金额整数和中间乘积须检溢出，失败停事务不截断 |
| 制造成本边界 | 首版有限口径将真实原料成本结转到产成品成本池；工资／水电／日常维护作为当期费用，不再重复资本化到商品；废物处置沿真实费用／终点。固定模板须明确联产品成本分摊且总额守恒，缺规则就不能封利润／分红。此为保守游戏口径，不宣称完整吸收成本会计 |
| 人工／场地／资源／服务成本 | 已发生毛薪、实际租期、水电、维护、物流／清运及适用税费逐来源计一次；欠薪也是成本与应付，不是省下工资。按已支持真实服务计量，不按建筑可容纳人数自动支出 |
| 资本投入与设备成本 | 建设／购置／装修中依法资本化的实际成本进入自有资产取得基，不能既全额费用化又折旧。待验收工程按原项目成本来源为在建，不提前折旧／经营；支持资产投用后，按冻结寿命／残值作直线法时间应计，拆除／报废按剩余账面值及真实处置款结清 |
| 维护与折旧 | 日常维护是本期费用；折旧是非现金成本，不自动付给任何人，也不自动形成更新资金。真实更换／改造按原工程及资产范围更新，不靠记折旧恢复设备健康 |
| 利润／权益 | 本期已核营业收入减同窗成本、已支持资产折旧／损失及明确适用税＝有限核算净额；未配置资产／成本／损失或规则则不称完整利润，不允许分红。出资、借款本金、押金及估值上涨不进营业利润 |
| 现金流 | 原现金期初＋实际收款−实际付款＝期末，按经营、资本投入和出资／分配分列；应计净额与现金桥接，未知来源不强行配平 |

资产计价只支持历史实际成本、已登记权属、明确寿命／残值的有限资产；不开放重估增值、金融租赁、复杂减值／资产证券化。故障、灾损、拆除确已发生时必须保留原事实及待核损失，核算未闭合前禁止分红，不能通过“不支持减值”把坏设备照原值分掉利润。既有旧场景若没有可信取得基，经营现金仍可报告，股份／利润分配先不启用；不按今天报价制造过去的本金或可分利润。

退货／退款沿原票处理，收回实物按原已结转成本回入池，退票／退款不能另凭当前报价改取得基；无对应退回事实不恢复库存。有限核算的必要应计／成本更新与原交付同事务，不能因自主历史查询额度耗尽而丢账；月末覆盖不足只停止新分红并显示未封闭，已发生权利义务照常处理。

总账给现金／资产成本／债务／实缴资本／累计留存与本期来源的核对桥；同一债权在原65536义务表只一份。用权威来源证明余额式，不靠每帧扫描公司×全部订单。按原日常事件持续应计，按游戏公历月封闭核算；工资／租金／跨图结算周期仍各依原条款，不改成统一月付。

## 4. 有限股份：实缴、持股与公司治理

首版候选为非上市、单层直接持股、同权普通股：一个整数股份单位对应1游戏币实缴资本，不设溢价、优先股、可转换债、自动估值或股票交易。持股方包括自然人、有明确共同权属依据的家庭出资方、私人终极出资者或财政主体；个人不必通过家庭或另一家公司持股。首版公司不相互持股，禁止交叉／循环持股。每家公司最多8个直接股东，全世界8192条持股关联共享，不能乘公司上限；不是模拟每个人每天买股票。大规模公众持股与二级证券市场另行预算，不能把互不相同的个人权益强并为一户来绕过8股东上限。

只为实际个人投资者建立稳定person_ref及稀疏金融身份，引用真实居民成员或有限外部投资者来源。个人拥有真实自有账户，资金从原个人现金或有双方授权／明确权属的家庭转账取得，不能凭“家庭有钱”复制余额。个人股息先入个人账户；只有有依据的家庭共同收支／真实转账后才进入FB37家庭可用现金，不能个人与家庭各记一份收入。家庭统计拆并、婚姻或搬家不能平均或重置股份。

本地个人股东可通过person_ref→真实成员／当前家庭F→有效居住权H→楼体与独立单元查询住所，沿用该单元真实接入组。地址是关系查询，不是每帧位置模拟；财产所有的房屋不一定是实际住所。搬家后跟随已提交的合法入住变化，旧地址仅为历史；无房、临时安置或未知时保留相应状态，不凭金融身份生成一套住房。有限外部个人使用可核的外部住所／登记来源，不伪造本地图H。登记送达地址与实际住所分列，搬家不能清除原送达／债务来源。住所只在需要时查询，不为每个股东复制建筑坐标和完整生活档案。继承／监护等权利变动须有合法依据，机制缺失就保留权益并暂停相关转移，不随机重分。

设立出资由股东可用现金原子转给公司，同次增加实缴资本和股份；认缴意图不生份额／收益。股本总数＝全部股东整数份数，持股比例＝份数／总数派生，不单存容易漂移的百分比。后续现金增资须按有效章程和现有股东同意／优先认购条件明确批准，全额落实本次实缴才原子变更；首版没有未配置的强制稀释。股份及出资引用原receipt，重放不能再发一次股份。新资本增加现金与资本，不增加留存收益。

股份给予章程内股东表决和合法分红权，不是销售收入提成，也不等于直接取得机场旅客税。公司普通决议按已实缴股份严格过半，关联方交易、增资／稀释及分红规则变更须全体股东明确同意；投票、版本与授权证据分页入原制度／合同来源，缺法源不由市长一句话接管私人公司。依法有效的外部法院／安全限制仍优先。公司票与居民议会一席一票、居民选举权完全分开；40%市有不自动控制60%私人票。

首版不开放日常股票转售、股价撮合、回购／减资、非现金土地作价或公司并购。退出／死亡／注销涉及持股权时必须保留登记及原权益，按已定义合法继受处理；没有可执行依据则暂停相关转移，不能删股让剩余股东免费得份额，也不以改名洗掉旧债。后续二级转让的成交款应付卖方而非公司，不得冒充公司新增资本。

## 5. 从经营结果到分红，再到财政

每公历月封闭一次候选核算：先完成旧区间的交付／成本／损失／应付及既有效力，再冻结核算覆盖和股东名册；最早下一合法阶段提出分红。每期最多一项有效分配决议，按(company、period)唯一占用、决议版本条件更新与原提交覆盖去重；未决更正不形成第二份可分本金。

同时满足以下条件才可声明D：

1. 该公司全部O及公司层核算完整，有可信取得成本、实际交付／费用、损失和适用税配置；累计留存收益已抵完历史亏损，未实现估值、未交货预收与股东新出资不计可分收益。首版未开放利润税／股息税，适用范围显式为0，而非偷套工资税；未来税须独立法源和预算。
2. 公司没有逾期工资／税／到期债务、未落实的最低安全维护或禁止分配命令；争议／待核损失涉及分配基础时先暂停，不以暂时未付成本高估利润。出资不是政府担保，持续亏损可以没有分红。
3. D≤max(0,核对后的可分留存余额)。可分留存已经抵历史亏损、扣除旧声明并排除不可分配来源；声明时减留存并转应付，不再从此余额第二次扣已声明未付股息。补助等不可分配来源另列权益／负债与用途，不混进可分留存。新决议只用剩余可分基础。
4. 现金也足够：扣原工资／合同／托管保护，以及下一30游戏日有依据的必要经营、维护／安全退出资金后，D不超过剩余。相同来源硬保护与30日缓冲取不重叠并集；缺报价／资源／时间覆盖则unknown并停分红，不把所需钱设0。30日不是无限续营担保，不免除更长期已承诺义务。
5. 分配后资产−负债仍不少于实缴资本及其他依法不可分配权益；资产价值／负债覆盖不足则不能用现金多这一点绕过。股东有效决议、法院限制、财政出资授权、接收账户／债权与收尾条数均通过。

声明时原子冻结股东名册和D，按份额分配到股东应收／公司应付，减少留存收益并保护同额现金；这些沿原义务表，不另开现金。比例尾差用最大小数余数、稳定股东ID破同分，总份额恰等于D。接受声明前预留全部股东义务／付款／日志容量。声明后股东或政策变化不能改旧收款方；付款同一原票扣公司现金、加股东现金并清原债，不再计一遍费用／利润减少。

正常只在全额资金已落实时声明并立即执行；若声明后出现更优先司法／紧急安全限制，剩余款保持原债权并依法暂停，不继续支付致负现金，也不把余额当新可分利润。更正过去成本使已声明／已付分红违法时冻结新分配，记录原receipt及依法追偿／裁判；已付现金不瞬移回去，未知责任不重复签发本金。追偿／更正程序无规则时保留争议和停分红，不以重开游戏消失。

财政入股前，要有独立议会／有效预算的投资用途、实际现金、玩家授权、章程与真实出资方；采购预算不能直接改为投资预算，出资也不等于采购了免费服务。财政出资单列资本性支付并形成成本记录，不当成公司营业收入，也不把财政股权估值当财政可花余额。

## 11. ME41：封账不是持续有效的分红许可

分红唯一占用键是**(company_id, period_id)**，决议版本是其条件更新依据，不是额外一次分红资格。未声明草案可以改版本；一个时期已有有效声明后，更名、换版本、换map或重开分支不能再声明第二笔。更正、暂停、依法追回均引用原声明／原本金，不以取消旧行后重发规避限制。原提交覆盖与持久索引证明时期占用，不能只用可淘汰UI缓存记“发过”。

## 12. ME41：部分退货、折旧与成本连续性

普通出库仍用第3节成本池F(X)。可退原售出票必须同时可恢复其售出数量Qs、原已结转成本Cs及累计已接受退回数量Y。累计回入成本G(Y)=floor(Cs×Y/Qs)，本次只回入G(Y新)−G(Y旧)，0≤Y≤Qs；累计退款金额也按原价款／退款规则及已退款覆盖封顶，不能把同一件货多次退回。Qs=0的来源不能作为实物退货依据。买方退给供应商的数量按买方当前成本池F(X新)−F(X旧)移出账面成本B_out，退款金额V沿原采购票及有效退款条款；差额V−B_out作为本期退货调整进入R／损益，未收到的V仍是应收，不生成现金。卖方退回库存成本只按其原售出票G(Y)恢复，并按原收入／退款来源冲回；两方账面成本允许不同，不用退款额硬改成本或留下零量残余。数量退出、卖方恢复及双方价款／债权更正同事务。无实物退回不恢复库存；库存采购价款折让首版不新增未定义的承诺，已依法发生而尚缺成本调整规则的事实先保留并暂停相应封账／分红，不假装损益为0。

退回后进入当前成本池的是该次真实退回量及上述成本，不按当前售价或当前平均价重写原票。已消费、报废、再次转属或无法定位原来源的退货不能直接补库存，须按真实法律／交付事实处理；疑似重复先保全事实，不多退款。拆退货、跨期／跨图、换F／O或重开均不清Y，所有累计值与原receipt同提交。

## 13. ME41：共同股东与关联交易边界

禁止公司相互持股，仍不能阻止同一人设两家公司互售抬价。首版用更保守、可有界核对的判定：交易双方存在任一相同的直接实缴股东，或涉及发行公司与其直接股东，即标关联；最多8×8股东比较，含财政同一真实主体，不建全公司两两关系矩阵。家庭不同成员不自动是同一财产权人，但既有共同控制／代理依据须沿真实来源校验；缺失控制来源不能声明“已证明非关联”。

新增关联交易仅接受已有冻结、同条件公开条款的实际消耗型公共供应／服务（如水电）、真实资源／工时及付款来源，且不得将双方互开账单当资本化资产或循环收入。可转售存货、固定资产及仅凭双方同意的关联高价转让，首版不接受新合同，返回unsupported_related_transfer；需要这些业务时须另补公允计价／未实现关联利润消除及实现追踪预算，不借N或R临时藏一个无来源差额。

此限制不倒删存量合法交付、库存或债务；发现未核关联交易／异常循环会阻止新的分红并保留审核依据，不能把真实损失吞掉。新登记或增资使关联关系变化时，未接受意图重查；已接受合法合同照原来源履行，相关收益的可分资格须重新审查。新公司登记不免除出资／资金与真实控制来源检查，不能仅换名字刷新“非关联”状态。第三方实际销售、原需求去重与资金保护仍是必要条件；财政不能绕过此门向参股公司高价采购，再用分红宣称赚回公共收入。
