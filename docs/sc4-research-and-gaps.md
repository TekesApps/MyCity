## 2. 立即补入的基础区分

1. **需求、规划密度、物理容量与吸引力分开。** 允许建多高不代表有人入住；需求高也不能突破水电、岗位或地块容量。富裕程度、技能和居住密度分开，不规定高楼必然住高收入者。
2. **岗位需要真实目的地与容量占用。** 到城市边界不等于找到工作，中转不新增劳动者；跨区出行保留来源和目的关联。岗位模板可有多类技能需求，不把整家企业简单归为只雇一种人。
3. **交通查询解释来源。** 每条路可查询方向／时段、通勤和货运贡献、未完成量、容量分母、旅行时间、网络版本与数据年龄。City Team报告要区分“需求增长”“路线改变”“施工减容”和“结果尚未收敛”。
4. **空置与永久拆除分开。** 经营不佳先表现为入住率／利用率下降、停业与吸引力变化；迁出有慢周期，不直接删居民。建筑实体仍保留，恢复营业、翻修、改建和拆除分别走相应规则。
5. **跨界影响不照搬原作边界。** 原作手册甚至建议利用邻城放置污染设施，称污染倾向留在城市内；MyCity按用户要求保留跨界污染与相关后果，摘要也不能免除。边界是行政与结算边界，不是天然污染墙。

需求约束尽量可解释，不引入“放一座公园就凭隐藏点数解锁人口”的神秘上限。公园若影响吸引力，应有明确作用范围、维护费和有限效果，也不能直接创造岗位或入住者。

## 3. 公共服务与运营缺口的最小闭环

以下是新增设计要求，不声称来自某个原作精确公式。为控制首版规模，先采用有限状态，后续再加人口学和复杂设施种类。

### 生活垃圾与卫生

生活垃圾与拆除废料必须区分资源类型，但复用库存、货运、接收容量、交付计量和费用结算。人口／经营消费按版本化规则产生垃圾库存，随后是收集→运输→兼容设施接收／处理；未收走则积存并影响环境与吸引力，不能直接删除。

垃圾输出从来源库存扣除一次并转为在途，接收设施按兼容类型、存储余量和当期处理率准入，存储容量与处理吞吐分别计量；有接收费不等于凭空拥有处理能力。停运、断路、缺钱和邻城满载均保留未处理量。已发货者受阻保留在途／合法等待，退运需实际运输，不自动回填来源库存。跨城走现有合同和共享通道；派车不扩展成逐车社会模拟。

处理后的去向也要计量：最小模型可转入有限填埋存量，满后停止接纳；后续按模板转为回收料、残渣或排放并记录质量平衡。不得以处理吞吐名义无限删除废物，有限填埋存量也使用现有库存身份与额度。

库存条目、货运批次、服务池与合同均使用已有全世界额度，不额外创建一套无限垃圾系统；参与交换的卫生能力若作为服务池发布，计入现有64池。模型先用明确的游戏质量单位，不把未校准系数宣传为现实吨数预测。无此能力的原型必须明确显示卫生未模拟，不宣称完整宜居性已成立。

### 关键设施维护

供电、供水及公共服务的可交付能力还应受实际运行投入和状态影响。预算是允许花费的额度，实际支付和维护工作才产生效果；调高滑块不能瞬间修好设备。维护影响连续状态，翻修需要工程，已经停用的能力不继续对外出售。

关键设施保留稳定asset_id、所有者、状态、负荷与维护累计、最近更新时间和停用原因。条件变化可按稳定区间解析累计，到减容阈值时产生事件；邻城未打开也继续计费和减容。重开按同一设施对齐，不随机找一栋楼承担损失。

为这套最小状态预留全世界4096条×128 B＝0.5 MiB，含紧凑引用而不含无限历史；新增索引与事件仍受既有配额约束。此表在区域44 MiB内，v0.4.4加入时小计29.0078125 MiB；后续名册／制度增量后的当前合计见 [性能预算](performance-budget.md)，总应用目标不变。超出状态额度拒绝新增需此能力的设施或先调整设计，不按容量数字凭空补设施。

### 教育与健康

首版使用已有基础技能组匹配岗位，有限继续教育／职业培训现按 [市民生活](citizen-households-and-living.md) 纳入首版，有容量、预算、时间和资格要求，不能建学校当日把所有人升级；完整年龄、出生、死亡、退休和逐人病历暂缓。医疗先采用现有覆盖、响应、容量、交付和结算；健康后果可作用于群体劳动与吸引力，不需要给每个市民运行诊断。

不把住宅×年龄×技能×收入×健康×就业做成无限笛卡尔积；仍守群体数、OD与内存预算。污水管网、下游水质、地下水和复杂疾病传播是后续专项；当前工具对尚无模型支撑的“保证下游水质”目标返回unsupported／needs_model，不可拿空气污染图层证明水质达标。

## 4. 对象属性与关系

建筑、道路、铁路、管线共用稳定身份、模板版本、空间引用、所有者、生命周期与工程引用；按类型附加容量、运行投入、维护、排放和连接端口等能力。道路有方向／容量／限速，医院有服务容量，电厂有燃料配方；不要求每种对象硬塞同一套无意义字段。

模板定义额定能力与规则，实例保存位置、磨损、库存引用、当前阶段与实际负荷，结果快照保存这一时段的流量和影响。关系通过有类型的引用表达：道路接入、管线供给、岗位匹配、设施服务、合同与资产权属；不能只写“这栋建筑拥有水电”却没有供应来源、容量和费用。

实例只保存需要变化的紧凑状态，静态参数共享模板；详细资产和摘要投影引用同一权威状态，不能各维护一份钱包或能力。铁路能力未实现前标记不支持，不能因为通用对象结构已有字段就声称可运行铁路。

## 5. 首版与后续边界

| 层次 | 内容 |
| --- | --- |
| 核心首版 | 阶段交通求解、岗位与容量守恒、可解释需求／空置、施工拆除后果、跨图运行结算 |
| 最小运营补全 | 有限类型生活垃圾闭环，关键公用设施维护／减容；加入同一负载验收后才称支持 |
| 对照实验 | 逐人通勤记录＋共享寻路，与群体OD方案比较；未决定默认启用 |
| 后续专项 | 完整人口年龄、教育发展、污水水质、公交铁路、机场港口、灾害、复杂税收信贷与真实地产市场 |

首版不自动新增贷款或债务来弥补维护亏损。现有资金不足流程继续生效；未来金融产品须单独定义债权、利息、违约和账本守恒。有限住房租赁／负担与空置全款买卖按 [市民生活](citizen-households-and-living.md) 运行，土地价值指标仍不能代替成交价或宣称完整按揭／地产金融已经成立。

## 6. 必补验收

- 相同人口／岗位，关动画或改可视密度，交通与经济统计不变。
- 新居民挤满桥梁后，旧居民路线也可能调整；新路开通可被发现，断路立即停止正常通过。
- 跨3城出行不会循环创造就业、人口和通行收入；摘要重开不重置岗位／积压。
- 高层住宅仍可低收入，需求高但断水／缺岗位不能凭空入住；空置不自动释放土地。
- 邻城垃圾处理设施满载或运输中断时，来源积存且费用按实际履约结算。
- 邻城维护不足跨过阈值时按时减容，既有合同按短缺处理；重开相同资产状态与费用不变。
- 未实现水质模型时，City Team不能承诺或证明下游水质目标。
- 新增状态叠加工程、合同、预演及高速运行后仍按16 GB基线实际测量，文档算术不代替实现证据。
