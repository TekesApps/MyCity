## 1.1 BUDGET-2共同资源与承载资格

实验首先冻结[首要产品约束](city-scale-and-adaptive-budget.md#0-首要产品约束全游戏预算推进目标与业务承载)：全产品进程／GPU共同资源包络、所测目标档、响应／必要任务年龄门，以及S/D/A/H负载。C1先获得目标设备CPU核毫秒／现实秒、GPU忙时或明确不可观测情况下的全路径限定、稳态／峰内存及保存成本；随后冻结候选时间额度和响应界，再在独立验证输入／重复轮中判定支持范围，不能用同一校准结果自己定义通过。

C3/E3/E5增加三个对照：固定总额下无局部加额、固定总额下有局部转移、突发超过可转移额度。逐scope记录必要／可调／突发用途的grant、估计／实际核毫秒、GPU占用与排队、工作页、转入／转出及原因、持有和回收边界、最低工作保障及最老任务年龄。验证额度总和不超总窗，拥堵加额覆盖其配送／到岗等下游，稳定区域不饥饿，GPU在途和已固定页不被错误撤回；超额必须降实速／背压而非遗漏业务。

对相同P/F加入货运密度、到期集中、路网瓶颈、源变化与历史深度差异，证明人口不能单独代表负载。C6输出“具体硬件＋预算＋服务／误差目标下的可支持负载集合”，人口只附为示例；未实测的CPU/GPU时间额、响应界和城市承载上限均保持null/not_run。未来真实UI／渲染未测时只发布相应headless范围。

## 2. 固定精细参考与真实输入

参考是“保留所有因果切点的最小可信业务模型”，不是逐人／逐设备全城模拟。先实例化少量家庭、企业、独立账户、真实住房／劳动／通路、有限库存、公用供给、施工和已接受跨城责任，形成可手算／独立实现复算的源序列。未实现领域标blocked，不用填充槽假扮业务。

参考冻结：整数单位／舍入与余数、clock_kind、事件排序、稳定seed/domain/occurrence、源记录及硬约束；交通以完整候选或已证明无遗漏的小图结果，环境以固定数值切点和独立更高精度复算提供数值误差参照（高精度算法不是悄悄替代正式策略）。参考也可能有误差，应给空间／时间收敛与自身不确定性，不能拿单一粗CPU结果当真值。

同模型A/B：仅改变调度／分页／dispatch批量时保持相同数值切点、随机轨迹、排序和发布格式；比较逐权益、交付、游标及关键决策一致。不同近似策略：保存版本，逐指标报告误差／阈值分歧，不能要求全部位级相同，也不能隐藏为“只改倍速”。精确不变量的0误差指每次运行内部的守恒、权益和合法性；不同近似策略可产生不同合法交易／迁居及现金路径，只有同模型等价优化要求跨运行逐状态一致。分组随机过程若不是可分割一致过程，就不得称跨分组等价，须保持原occurrence结果或登记新近似策略。

配对反事实覆盖：开放／封路；正常／断供；有钱／耗尽；峰值同日均；集中到期／错开到期；同人口下不同职住／货运／历史；分别检查“输入改变→物理后果→经营／生活结果”的方向与来源，避免只比总现金和人口。

### 实验输入扫法

[plan-v1](inputs/simulation-budget/plan-v1.json) 15行是端点集合，先从能装配的小图子集逐级增长到目标，不能降低既有M0。规模扫每行25%/50%/100%的开发与业务（空间不变），另单独扫活跃率与历史深度。25%人口不自动等于25%道路／环境格／存档。每个生成场景发布显式计数、对象来源及关系清单，满足槽／字节／退出保留／工作额度四门才运行；超当前代码限额标blocked_capacity，不截断需求。

## 4. 必跑实验、指标和误差门

每个已支持scope先静态策略，再动态；CPU及GPU分别报告。固定 seed 至少3个，每个配置至少3次独立进程重复，顺序交错避免暖缓存偏置；冷／暖各记。基础正确性30游戏日；累计漂移365日，再选择至少一组3650日（可提前因不可控增长终止并记失败）。性能每行至少30游戏日且1800现实秒窗口，不够墙钟可继续后续游戏区间；只读重复查询不能伪装更多模拟业务。长期整组运行候选8h是本实验独立门，不抵扣或替代原M0的8h。

精确不变量：逐账户及对手借贷与税基、产权／库存lot／保管、实际占用、已交付、已耗工料／工程进度、人数／家庭迁移、合法时点、事件覆盖与随机occurrence、原票幂等。误差为0个既定量化单位，舍入余数持续保留；不允许1%总额容差，也不允许不同实际业务靠总现金相等伪装等价。

允许近似指标按系统执行卡输出：行时秒／p95排队人次／v/c峰值、各类需求满足率百分点／短缺量和时数、迁居人/日、产销数量／成本／利润分布、EI/NI场单位和人时积分、服务等待秒。均按区域／群体／时窗及p50/p95/极值，不只全城平均；列相同输入下阈值两侧的决策混淆表、错误批准／错误拒绝及unknown。硬约束不得错误批准；其他决策允许偏差须有独立版本的可接受界。

误差资格条目必含：单位、绝对/相对上界、累计窗及最大漂移、峰值覆盖、最大数据年龄、参考自身误差、阈值安全包络、有效负载／设备／策略与失效条件。当前JSON的数值界为null，**表示未资格、不得控制正式后果**；后续C1用收敛参考和反事实定界，再经领域风险确定可接受误差，不能以测到的最大误差直接宣布“都可接受”。参考与候选区间合并仍跨硬阈值时精算或unknown，禁止擅自判通过。

动态策略对比至少包含固定最细可信、固定最佳静态、动态三组，保持相同操作／外源／随机身份；区分模型偏差和控制器额外偏差。显示可解释的取舍：减少多少重复工作／切换成本／增加多少误差与unknown，不能只报提速百分比。

## 5. 观测、资源和报告格式

每轮固定清单：源码/tag、lock、exe SHA、实际命令、manifest及seed、策略事件日志、设备／存储、输入／结果／oracle来源与完整恢复引用。按业务、layout压力替身、观测器/CPU参考工具三类分层记录及联合峰值；压力记录、内存填充、动画实例不计真实家庭／交易／通勤吞吐。

记录task类别与scope：排队/执行/准备/IPC/GPU排队上传派发等待回读/校验/Store提交wall时间、CPU服务时间及p50/p95/p99（样本数／置信区间／最大值）、任务数／单位业务吞吐、队列长度与最老年龄、事件密度、实际游戏秒/现实秒、目标倍率、暂停／故障／切换损耗。父区间与子区间不能重复加总；不从循环次数推真实任务完成。

资源：同刻全进程角色/PID/birth、owned/reserved、allocator、native/stack、RSS/footprint、共享allocation_id和GPU缓冲／暂存／pipeline、系统pressure/压缩/swap、GPU忙时／排队（接口不可得就not_observed，不用CPU等待反推）。稳态中位、p95、峰值、增长B/游戏日和B/现实h；采样间隔、短命进程遗漏／权限失败单列，观测日志预算有界。存档逻辑／allocated、WAL、快照数、save/recover wall／读写字节及峰内存逐次记录。

可持续资格：误差／硬门／域配额全通过，经过预先声明的长窗队列年龄不持续增长，内存／存档增长有可解释上界或可验证归档周期；冷恢复及故障后可返回稳态。结果为在具体硬件、模型、负载和误差资格下的速度区间；尾速不足就公开支持较低倍率。三次实测只提供区间证据，不能证明所有未来硬件／无限运行。

每行结果记录：`case_id, load_hash, model/policy/error_version, executor, hardware/storage, S/D/A/H_actual, exact_invariants, approximate_metrics, conversion, steady/peak_by_domain, queue_age, actual_speed, save/recover, disk_growth, interference, evidence, D/A/I/V, supported_scope`。空缺写unknown/not_run/blocked，不用0。性能与经济平衡分开判；亏损城市可以是正确仿真，不能强迫所有企业盈利。

轮预算8GiB包含该轮新增世界／双快照／WAL／候选／采样，不是在20GiB世界外再免费加；增长预计超轮预算就分阶段、流式观测或暂停，不丢业务。卷可用空间须同时容纳当前未释放资源、下一恢复峰值、主线保留和安全余量；不按源码卷估算。CPU/GPU输入优先只读引用同一固定数据，不能每轮复制target或全套压力布局。

源码/lock/exe、manifest、命令、结果、原始时轴、错误与验收证据作为发布证据保留；完整恢复原件保留至“替代版本实际冷恢复＋精确下游依赖解除”，不得用hash替代。失败现场终态后先分类：恢复故障所需保留，无关暖场重复件在判因并有完整证据后按允许清单退役，不因失败永久保留一切。临时件7日只是复查期限，不是自动删除授权。

每轮终态（含失败）先登记实增、累计work/target、保留项／下一解除事件、可删精确文件清单，再开下一大轮。删除前重新查进程／cwd/打开句柄／硬链接／引用并核保护原件，不停止其它项目；测量窗口内不执行。报告逻辑、inode去重allocated和卷df变化分别列，不能把APFS共享或其它任务的释放算作本轮回收。
