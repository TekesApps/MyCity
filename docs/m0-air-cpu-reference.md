# T12-A：空气EI的有限CPU参考

发布v0.5.23，实施策略`run36-air-f32-v1`。以下契约在实施前冻结，实测另列。不替换RUN36，不引入真实污染物／健康标准；只做独立纯数值任务，尚不把场写入Engine／Store、城市满意度、财政或许可。

- 使用RUN36的32m环境格：32²／64²／128²，单通道EI；不是16m土地格，也不扩每人／每设备状态。
- 原公式`(1-d)*[(1-4r)*C+r*(N+S+E+W)]+E_interval+d*2`，`r=.02*h,d=.01*h,h=秒数/60`。按N＋S、再E、再W相加，显式各乘加，不使用mul_add／fast-math。正式每步发布f32位；f64同策略公式只作误差对照。
- 固定实验target属于输入身份；本纯任务以0秒为原点，分钟锚点为60k，源start／end及最终target截断，单段≤60秒。尚不从活动世界GameTime装配，未来接T05须显式绑定实际时间原点，不能每批归零当成连续世界。查询／分页／保存不新增截段；不承诺先跑30秒再改目标60秒等于原目标60秒。
- 来源为已经投影到一个32m cell的EI增量率，整数micro-EI／秒，按ID稳定累加；活动区间半开`[start,end)`，先整数乘实际重叠秒，再转f32。最多20000行，每页≤8192。本轮不实现真实道路／设施到格的双线性空间投影，不能把输入投影称已验证。
- 四边各提供明确固定ghost EI及覆盖至target的时间，角格分别读取两个对应边值；缺测／覆盖不足拒绝，不默认零或背景2。常量2是显式合成外部条件，不能代表邻城真实状态。消散背景补给另为RUN36的2。
- 每段先累加全部源页，再按行优先计算全部格；cell页≤1024，所有格读同一旧场。候选未全不得发布。完整后一次交换场，同时累积逐格梯形EI·秒诊断；这不等于真实住户暴露模型。
- old／candidate场用u32保存f32位，累计积分用u64保存f64位；检查点保存输入、固定target、旧场、源工作区／已写tile、段末、phase、游标和诊断。数值位模式保留，避免JSON浮点重新解析改变恢复结果。带校验和、版本与输入身份的checkpoint拒绝损坏／不相容；单任务artifact不是城市存档事务。
- 初始／ghost≤1000000 EI、源率≤1 EI／秒／行、target≤30×86400秒，所有数有限非负；整数积与累计受检。输入上限4MiB、检查点8MiB、单任务owned≤2MiB；当前最大格仅单通道，不冒称8通道联合通过。
- 诊断分列源积分、消散、背景补给、外边交换及舍入余差。EI不是物理质量，不以空气质量守恒验收。规则阈值、家庭满意度、跨图真实边界和GPU累计误差资格均未实现。

验收预设：同输入与同分段策略在不同源／cell分页、半源／半tile保存恢复下，最终f32位、积分位及诊断位精确相同；独立f64对照按同一事件分段，逐格检查`abs(cpu-ref)≤0.001+0.0001*abs(ref)`的有限工程门，报告单步／游戏日／固定30日窗口误差。该门是本原型的工程对照准则，不是GPU误差包络或现实精度证明。另验常量2、无源衰减／非负、脉冲传播、整数源总量、源启停、缺边界、坏checkpoint及超限拒绝。

资源归属：本阶段是尚未接世界的纯任务，单State owned≤2MiB全从A55既有单任务32MiB输入／工作／输出页内划出（余30MiB），包含两f32位场128KiB、逐格f64位积分128KiB、源描述1MiB规划份额、元数据及余量768KiB；不再向模拟域双缓冲或CG39元数据重复领一份。实际Source布局及容量由本轮测量。检查点序列化、恢复及独立f64对照／事件索引从A55单一128MiB高峰作业内规划32MiB，本任务普通页也包含于该高峰份额，不能叠加借用。未来接入世界时必须重新定义共享／私有场所有权并联合计量。布局／allocator、整个CLI父子进程组及16GB仍需实际测量，不把单State owned当RSS。

本轮CLI以`air-probe INPUT NEW_DIR`运行已配置32²场、64²／128²变体、固定30日及2万源五种任务，并在源／tile中段落盘，以新的`air-resume INPUT CHECKPOINT NEW_OUTPUT`进程继续。任务文件带当前源码和输入指纹，仅发布完整不可变文件，拒绝旧源码／错输入／损坏与覆盖已有结果；不替代Store的WAL／CURRENT协议，不宣称物理断电保证或worker池已实现。

独立Python参考采用代数等价f64 stencil与逐格梯形积分；除最终场外，以积分／target得到整窗时间均值，使用相同工程误差门。它不是真实家庭活动轨迹／住户暴露的提交。检查点入口及直接类型解码均验证状态，源／场向量在反序列化过程中限制条数；同策略只承诺完整冻结输入及相同事件分段下的位级重放，跨平台／不同GPU仍未实测。

本版五任务独立复算的最大最终场偏差为2.5545222296585735e-05 EI，最大时间均值偏差为2.461697434126917e-05 EI；均通过本原型工程门。两万源任务owned 662560 B，实际Source为20 B；8 MiB检查点是上限，实际文件更小。命令短测约1.36秒、峰值RSS16285696 B，实验同时有全仓库回归，且未测父子组峰值，不能当成城市吞吐。

JSON报告中的浮点仅用于显示，CLI父进程再次解析子进程报告时可能有末位差异；精确恢复与比较依据检查点中的整数位模式及场／积分hash，不从显示数反向恢复状态。
