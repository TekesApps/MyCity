## 发现与修正

| 缺口／潜在套利 | 修正后的规则 |
| --- | --- |
| 永久要求占用≤容量，与故障后真实超占用冲突 | 不等式用于新接纳／新预约；故障保留actual、overcommitted／缺口，阻止不相容新增并安全退出，不裁人／删责任 |
| 满活动先产生收益、再少扣电费；待机口径不明 | 负荷声明总量或待机＋增量，同区间联合可行后提交活动／输入／交付和合法应付工时；实际待机／失败启动不退耗用，工资不按产出同比砍 |
| 主表、分表、公共负荷或网络损耗双计；小额舍入被改名／拆步清零 | 同边界同区间闭合，物理计量与费用分摊分开；累计／余数唯一迁移，公共支出只分一次、原票尾差守恒 |
| 换一台设备或改装修刷新整套寿命／维护欠账 | 初轮同质成套，仅真实整套工程更换更新对应锚点；局部修理不刷新全龄，异龄状态未支持则拒绝，残余物和旧责任保留 |
| 每个候选店都预测拿到同一批顾客 | 独立情景不可相加，联合预演共用需求／现金／时间来源竞争分配；并发成交再次核同一库存／现金／权利，报价不预留 |
| 估值／自报价／关联方循环交易变成地价和可花收益 | 区分报价／已付有效成交，剔除内部循环／重复样本；估值是有覆盖参考，不自动成为现金／贷款／补贴／税款 |
| 选址来回跳、换价倒改旧约 | 候选每日评估≤8地点，30日同口径前瞻扣搬迁／改造／退出成本，经连续优势／冷却后仅提出合法迁移意图；硬失效即时，不改旧合同 |
| 许可取消、退款、押金、提前关闭或续期重开重复兑现 | 最小完整生命周期区分已用／未用／预付／押金／损害、真实退款与债权，原本金只兑现一次，先结旧区间，清场前不重卖占用 |
| 16版本满后无法保存延期／安全停用；新增事实只说“原1 KiB” | 满额拒新版本不阻旧事实更新；新增宿主／功能／依赖三表0.125 MiB明确域内预留，原宿主只引用，原现金／库存／权利／占用／计量不复制 |

## Advisor复核

按用户要求请advisor独立审查，指出故障超占用矛盾及设备联合可行、异龄更换、竞争需求、许可退出的缺口；主审同步补计量／价格反馈时序和明确扩展预算。修正后再只读复核，无新增状态守恒／预算加总错误；建议将4096计量段限定为新增水电等交付计量，并把迁移阈值明确为同一未来30日窗口，已采纳，避免覆盖既有工资／住房租金应计或缩小阈值。

## 静态案例和算术

- 原设备例7.18 kW安装、42.2 kWh/日和30日633电费仍成立；总量／增量不能混用。另设1 kWh固定待机＋每单位活动2 kWh、当期获电5 kWh，最多2活动单位，不能保留需9 kWh的4单位产出。
- 7个最小计费单位三方确定尾差可分3／2／2，总7；拆时间步／换租户也不能少付或重复兑现。容量100故障降到60而100仍在场，真实缺口40，不把人数裁到60。
- 需求100份且可消费现金1000、单价10，两店联合至多交付100份／收1000；独立情景各100不代表联合200。旧地未来30日运行现金成本10000，主动迁移优势门为1000且需连续窗口／冷却，不是每日成本的10%。
- 许可预付100、押金20，已使用40、依法确定损害5，可退未履行60＋押金余15＝75，责任方保留45；两边现金合计120，重放不能再退75。责任方无可退现金时形成原配对债权而非造钱。

这些是文档规则的静态验算，不是模拟器测试或真实行业结论。主动迁移初值、需求／价格弹性、维护后果及饱和还需实现后的敏感度／平衡测试。

扩展只计新增事实、不在区域或其他域再计一次，禁用可不分配；已有合同、meter、债权／事件、几何、索引、模板正文和存档各按原配额联合准入，不能512功能各自获得免费新许可。记录大小仍是布局目标，0.125 MiB不是全部功能的实际总成本。

**16 GB作为受限目标仍可继续，但未证明实际可运行或最高日历档通过。** 待测风险主要是对象／引用实际布局、设备／价格变化的依赖失效、竞争需求与交通求解、同刻结算／退款、历史写放大、高清资产和单预演／保存峰值；不是128 KiB本身。更多宿主／设备细节或完整新市场须重预算，不为全候选模型背书。
