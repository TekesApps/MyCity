v0.4.42 [LS42](environment-services-and-satisfaction.md)接上本篇实际环境／服务交付到家庭反馈；正常三类基础需要不等疾病、刑案或真实火灾。已有医院支持性留观、服务人员／床位／资源及安全退出仍沿本篇类型化来源，不以满意度替代治疗／工作或生成新能力。

设计修订：v0.4.38，2026-10-19，候选规则包LC38。落实[City清单CD-02](city-design-closure-checklist.md)，承接[DP34规格](first-release-type-definition-pack.md)、[RUN36](minimum-operating-parameters.md)及[27类契约](common-object-contracts.md)。全部数值为游戏规则，不是现实工程安全定额；仅文档，无实现／资产装配／16GB性能证据。

## 1. 范围、继承与不能省略的来源

23类各选原B0基准，不新增建筑型号、行业、资格、AgentKit工具或动态表。LC38冻结此前缺失的生命周期数量／前后置，不热改START35／36或旧案例。实例必须选择一个完整版本；不能取旧低报价、LC38新能力却忽略新残余物／启动成本。价格仍沿真实有限报价／工资税／原账本，不从本包自动产生供应商或现金。

“启动”区分工程竣工、物理调试、合法开业／入住；“退出”区分停止新增、停止生产／服务、实物保全、退役／清场。下列数量只是所需能力和投入，必须绑定真实owner／地点／窗口／通路／计量／资金与供应回执才可交付。外包可简化内部设备，不省略有限资源、时间、实际工作、失败责任或最终接收者。

DP34的面积、户数、工作位、名义产能、K／最低工期不改。水电基础包H／B继承DP34：H底座0.1kW/已装单元＋0.15kW/在住人、0.12m³/人/日；B底座0.005kW/m²＋0.015u kW/m²、卫生水0.003m³/实际员工／客户在场人时。现场外部工人由工单资源包覆盖，不再在B重复加人；运营者不在场时不凭参考FTE生成用水。P01／P03／P04／P08在LC38重新选择的B只覆盖普通照明／环境／终端及普通在场卫生水，不含表中按批次／床时／现场工作／授课时计的专用任务设备与清洁水；这些增量由原D内已安装设备产生，不再次买设备或再叠旧版整包的同设备负荷。这是新版本完整资源曲线，不能声称与DP34原整体曲线能耗等价，也不能用旧曲线承诺LC38新增任务。

家庭消费与G05生成必须在同一接受事务：先核该家庭真实3Qw储位／已有量或已落实的当次接收，不能只看商品现金。无接收余量时阻止可延后新消费并记基础消费／收运未满足，不将基准需求偷偷降为0。已经发生、在途交付约定不能撤销或无法拒绝的废物仍必须按原I实际位置／数量及超容量／安全责任记入；实际stock可超过声明的安全储位上限，但不因此授予合法新空间，不能截断成3或丢入0.9已使用终点。不能可靠保存已发生事实时按原安全边界停止推进，不删垃圾／住户来释放槽。

**水电终点**：kWh是实际用能，已消耗不生成可转售库存；普通生活／工艺／调试用水在终端交付后记“已消耗水量”，网络漏损另列。该抽象不生成污水库存，不预测回流、水质、河道或真实蒸发比例，也不因此许可任意排污。泵输出水仍是网络流，不能同时记终端消耗又再次供给；关泵也不消灭历史交付／水费。
