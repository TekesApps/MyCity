# City首版基线收口包 BC43

设计修订：v0.4.43，2026-10-19。本篇将[CD-04／05／07／08／09](city-design-closure-checklist.md)的既有原则合并成有限输入、拒绝条件和验收向量，接续[IL43制度与用工](institutions-and-labor-execution.md)。目的是推进尚未冻结的主线，不继续扩同一主题的案例或空泛复核。所有数字是设计候选，不是游戏实现、性能、经济均衡或完整资产装配证据。

规则定义D、真实输入装配A、实现I、联合验收V分开：本篇可冻结有限D；A仍需实际数据／几何／金额／权限等来源，I/V均未开始。更大内容、铁路／航空、复杂水文和AgentKit扩展仍按原范围，不借“收口”暗中启用。

## 1. CD-04：高度图与物理资产的同一坐标

沿[空间契约](spatial-contract.md)固定x东／y北／z上、本地米制、西南平面原点、0°东逆时针。提交坐标／高程为i64厘米、角度0.1°；渲染局部浮点和细分不是权威输入。中间面积／叉积／体积须有检溢出／宽位或稳健算法；算法无法证明时拒绝，不以浮点epsilon允许1cm侵入。

首版直接导入候选限定PNG灰度8／16位及显式导入manifest；RGB／调色板／alpha／损坏文件不静默转灰，需先显式转换／补有效掩码再导入。GeoTIFF／其他DEM可外部转换且保留原元数据，原生解码依赖未接入时unsupported，不把“元数据优先”解释成已实现所有格式。单源宽高各2—4097、压缩／解码与全部缓冲实际字节先准入；上限不是允许分配任意解码工作空间。

manifest必需：源内容摘要、位深、样本代表顶点或像元中心、裁剪范围／方向、物理Lx／Ly、z_min／z_max、垂直基准、无效／水域掩码、源分辨率／准确度（未知可null）、变换／处理版本；真实地理数据另含源CRS／目标投影／地理锚点。合成图明确未地理配准，不把经纬度直接当米。

默认PNG样本代表顶点：row0为北，点(i,j)映射x=i×Lx/(N−1)、y=(1−j/(M−1))×Ly；8／16位分别按gray/255或gray/65535线性映射高程。像元中心数据按其明确边界变换，不能混用N和N−1。首版地图范围须为1.024／2.048／4.096km正方形；非方形源只能显式裁剪／指定变换，不悄悄拉伸。黑色可是真实低地，不是默认no-data；有未补齐无效内部样本就阻止首版有效地形发布，不把洞填成0。水域掩码只表达已支持水域，不自动获得水文仿真。

有效源用双线性插值重采样到4m规则顶点，像元中心源的外围半像元须显式授权最近边样本延拓并标来源误差，否则先裁剪到完整覆盖；不默认填0。分别257²／513²／1025²；顶点厘米量化采用最近整数、恰半向远离0，负数规则相同。每小方格固定西南—东北对角线，CPU高程查询用同一两个三角面作重心插值，建筑基底／道路坡度不能与显示网格用不同表面。渲染LOD可近似展示但不改变采样／碰撞权威；处理误差和原数据精度分别报告，30m源重采样4m不增加真实细节。

先在非正式世界工作区完成导入预览和预算／掩码／坐标校验，再发布唯一terrain_revision。修改运行世界的地形必须走原土方／占用／权利／工程流程，不能重新导入抹掉房屋、道路或费用。解码暂存、旧新地形、GPU上传与保存峰值仍按原几何／工作／4GiB警戒准入，不新开“导入专用免费内存”。

每资产装配单必须核对：米制外壳／实际楼面、基底／基础平台、所有者与O、单元布局与真实门、朝向／地形参考、层位／共享子区、道路／水电实际支路、资源／维护及可执行安全退出；逐项来源和版本齐才可投运。16m格只作索引，跨格建筑／曲路不截断；首版最多8门／8共享子区等原限制不因导入模型而放宽。拒绝清单：单位／方向不明、混样本语义、洞／NaN、越界／溢出、门悬空或反向接入、桥隧／悬挑等未支持几何、无合法支路和超内存预算。

## 2. CD-05：有限交通求解与四个固定反例

沿[RUN36](minimum-operating-parameters.md)／[阶段重算](traffic-state-and-recalculation.md)原模式、5分钟发布、4候选／OD、3轮／发布、每轮256脏OD及32768邻接松弛上限。单走廊不造4份路径；候选仅含合法方向／入口／层位／模式的无环路径，所有边成本非负。先取冻结图最小成本路径，再有界枚举不同可行分支，稳定边／来源ID破平；超工作额度unresolved，不称所有替代已搜尽。

入口服务量、边内行驶和等待分别保留；行驶预测仍t=t0×[1+0.15×min(f/C,1)^4]，f只指真实接纳，C=0则禁新进入。未接纳需求仍在原合法等待点，不通过min截掉；原128人／32车入口等待上限按真实共享瓶颈，全OD共用。转向／服务门／装卸亦有独立真实占用，不能一条路的能力复制给每个OD。

路径／份额更新只影响尚未进入受限段的合法后续决策；已在途者保留位置、原行程、实际等待／返程与责任，不因“新最短路”瞬移。迟到只改变真实到岗／已发生工时结果，不直接删雇佣；消费／公服源也不因未收敛重复发起。新边同时检查潜在受益来源，不能只重算旧边使用者。

| 输入夹具 | 固定最小输入 | 必须成立；不要求伪造均衡 |
| --- | --- | --- |
| TR0 单走廊 | 原600m、车辆30km/h、每向600当量/h、同一方向；仅一条合法路 | 自由时72s，满接纳流率行驶预测82.8s；不将队列等待塞进t公式或复制路径 |
| TR1 两支路 | 同源／终点，两条独立合法支路，长600／800m、各600/h；同模式／无额外费 | 两自由时72／96s；完整搜索能看见两条，平成本按稳定ID；路网／门条件失效时不因“候选存在”放行 |
| TR2 过载 | TR0下固定一5min窗60车需求，初始空队，入口服务50车且队上限32 | 实际新接纳≤50，剩余10留待／保留来源，不删成“实际需求50”；跨窗不清队。TR1同样需求允许有界分流，但不强迫3轮必达最优 |
| TR3 硬失效／新边 | 持有合法在途／等候后封原边，随后加入原未用新边 | 新非法进入为0，原占用／责任保留；新边使未使用它的OD也可能失效重算；无路、未知和未处理状态分开 |

成本变化≤1游戏秒、份额变化≤0.01且本次所有必要来源覆盖齐，才可标本次迭代停止；这仍不是全局最优／真实交通均衡证明。队列／路径／在途按原4096OD／409600路径引用／1024边单路径和货运／服务槽联合准入。窗口未解有age／缺口及后续工作游标，实际日历倍率可下降；同刻硬约束与真实到岗事实不被工作额度跳过。

## 3. CD-07：跨图运行、容量、费用与退出验收表

所有已连接地图同一world／branch／clock，current详细与邻图summary只是表示；最多8图不各获全世界额度。实际邻城保留可恢复manifest／对象／账户／摘要映射，有限外部边界另标来源／容量／期限，不假称拥有完整无限城市。不开图继续工资、需求、服务、库存、污染、司法与费用，不推进退出游戏后的现实离线时间。

| 阶段 | 统一权威与必须检查 | 异常／退出结果 |
| --- | --- | --- |
| 源能力 | 设备／人员／水电／库存／维护求当前effective；同一真实资源键单写 | 降容后actual与旧承诺可overcommitted，保留缺口；不裁床上人或在途 |
| 承诺分配 | 原有效保底／已预留与新增按冻结优先级、同池／窗口统一分配；预留→实际只转换一次 | 本地与外售不各发一份能力；不足停新，不能由某线程先完成抢份额 |
| 交付 | 水电按实际流／损耗／连通，商品按转属／装卸／在途，服务按真实到场工作／返回 | 道路或摘要覆盖不足unreachable／unknown；报价／保留容量不是已交付 |
| 收费 | 保留费、实用费、运送及退款逐原来源区分；单一父子计量与尾差 | 同一交付不两端双收；未付保留双边债，不以抵扣／退款造现金 |

跨图公司／个人／住房／股权依ME41、环境及服务需要依LS42、制度及旧合同依IL43；同一法人移库不售出但真实货运仍在，不同法人不能借summary改成内部转移。验收只需一正常与一故障源覆盖：供方断电／通道封闭／合同到期／需方缺现金，分别核实际量、保留容量、收费、债权及可恢复退出；不用扩成逐日新故事。

## 4. CD-08：City保存兼容与原子恢复

City格式候选名city-v1只代表本篇设计，不是已实现文件。文档Git tag与数据格式／规则版本分开。根manifest至少固定world／branch、当前游戏秒／阶段／提交覆盖、各图范围及检查点／摘要映射、随机种子／流、组件必需特性、schema／ruleset／catalog／profile／terrain／geometry／ledger／数值策略与来源版本、文件长度／内容摘要及依赖。LS42、ME40／41、IL43状态是显式必需组件，不能缺了就按新默认值重建。

| 校验域 | 可恢复所需内容 | 失败状态 |
| --- | --- | --- |
| 身份／空间 | 稳定ID／代际、地图框架、地形／掩码／模板、端口／路网／共享权利与索引依据 | 断引用、未知单位／地理变换、旧几何缺失→只读诊断或拒载，不猜位置 |
| 钱／实物／法律 | 原账户／保护、库存及成本、在途／服务、合同／义务／原票／判令、预算与生效源 | 单方余额、重复本金、未结责任来源缺失→拒绝写入，不平摊修正 |
| 行为／数值 | 家庭／雇佣／课程、股份／封账、LS42积分／区间／需要、IL43通知、时钟游标／随机状态 | 不以监测桶、画面或现时地图重算过去；不清冷却／旧需要／已发生暴露 |
| 功能／版本 | 必需策略与schema、规则／profile／资产来源依赖齐全且被支持 | 较新／缺版本不静默降级；可解析部分只读显示不等于可继续模拟 |

保存于一致微提交边界固定所有权威，不要求强制回退整日；未完成同刻阶段须标processing_phase及游标，不能标完整日／完整全城快照。GPU只存CPU完整已提交场／原覆盖，未提交命令丢弃重算；重开递增设备／作业代际并拒旧回调，不序列化设备指针。

候选持久化顺序：写新一代临时检查点／依赖并校验→持久化所需源日志与commit记录→最后原子发布唯一根manifest。单文件rename不等于整个世界原子；发布根前必须保证其所有依赖已可恢复。根发布前崩溃仍用旧完整代及原持久日志，根发布后用新完整代及其后日志；operation_id／原源覆盖确保旧动作只返回旧结果。已宣告成功的City修改必须有可靠持久提交，不能先报成功再等待写盘。尾部未提交损坏不解释为已承诺成功；已提交数据损坏要诊断／拒写，不能吞掉债务。

先校验长度／计数／摘要／特性及预计峰值再分配，按类型上限／实际字节加载，内存／磁盘不足保留旧可恢复世界并停止新修改。保留最新两个一致检查点及被显式固定的依赖，仍入原10GiB世界磁盘预算；峰值按3GiB软／4GiB警戒及进程树／统一内存准入，旧新同时解码不是免费。目录／历史分页不能无限驻留。移动到新路径／设备也先校验完整依赖，不只复制一张图。

首版不自动跨不兼容规则／格式迁移、不合并两个运行世界、不将一张历史地图塞回联动世界复活资金。高度图可作为新世界输入，带现金／人口／债权的运行存档不是一张普通素材。实现恢复器须分别覆盖根发布前／后、必要源缺失、日志尾部、旧回调、满槽与微阶段恢复，不借本篇宣称已通过测试。
