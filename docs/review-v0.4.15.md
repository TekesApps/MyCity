# v0.4.15 垂直空间与空域政策

日期：2026-10-19。按用户要求，地下、地面、空中保持少量分层，同时将居民因噪声推动空域立法纳入规则闭环。本版仅补设计，未实现轨道、飞行、三维声场或相关性能验收。

[独立专题](vertical-space-and-airspace.md) 建议六个用途层：地下0—3／3—10／10—40 m，地面用途，空中AGL 0—120／120—600 m。数值为游戏参数，不是现实规范；层只是分类，真实world-z、连续包络和净距仍决定兼容。不同层不保证无碰撞，超过初轮范围为unsupported，不能把600 m以上或更深处当作免责空间。

明确坡地逐段AGL／深度、地形改变不自动移动设施、法规当前／冻结地形参考、跨层地基／竖井／出入口／施工范围及独立权利。首版管线仍沿路及保守深度槽，不因分层自动升级为任意三维施工；地铁与航空仍需后续完整模块。

空域政策可声明冻结住宅范围、垂直区间、游戏时段、活动类型、管辖及生效／存量过渡。噪声诉求经过现有法案／议会程序，不直接变成禁令；禁穿几何与噪声效果分别验证。新规则使相关旧计划失效，未来在途活动须安全分流／退出，不能瞬移或删掉费用与需求。航空未支持时不能假称已改航／改善暴露，例外须有明确规则，不能由agent自报紧急。

按此前指示咨询advisor，补明地形法规参考、超过显示范围不默认可用、地下地面接入／施工占用及政策表达与实际运输能力分离。规则沿现有256槽／条件上限，几何／索引／正文按原域联合准入，不建立六套地图数组或三维体素；区域载荷36.5078125 MiB、40 MiB额度、应用2.65 GiB目标保持。这不包含未来完整地铁／航空状态预算，实际元数据布局超配需先调整。
