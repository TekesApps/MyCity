# 制度时钟、权限与有限用工执行 IL43

设计修订：v0.4.43，2026-10-19。合并[CD-06](city-design-closure-checklist.md)的既有选举／法案／预算／司法与用工接口，不重写机构故事。全部期限、保障及清偿顺序是候选**虚构游戏宪章／劳动规则**，不代表现实法域。只补City定义，无实现／实际法律合规／经济平衡证据。

本策略需有显式开局宪章／劳动profile并从未来边界启用；不追改冻结案例或把旧欠薪改成新工资。未配置时阻相应用工变更，不默认雇主或市府获胜。[ME41](market-entities-and-equity.md)的股权、[LS42](environment-services-and-satisfaction.md)的生活与迁居继续用原权威。

## 1. 一套时钟与权限交集

所有程序使用游戏整数秒及固定日历／版本，暂停不耗期限；邻图同钟，显示速度不跳程序。下表细化[统一闭环phase](closed-loop-contract.md)，不是另造第二套事件循环。

| 同刻T的阶段 | 必须先完成 | 对后续的约束 |
| --- | --- | --- |
| P0 封旧段 | 封闭[t0,T)实际劳动／合法保底、交付、暴露、维护与应计 | 新条例不能改旧区间工资税率、已排污染或成本 |
| P1 已定法律效力 | 原已通过且到T生效的规则、有效法院限制／解除与过渡条件，按稳定源序核对冲突 | 冲突进入effectuation_blocked，旧有效法保留；未通过的新提案不在这里抢先生效 |
| P2 旧权利到期 | 工资／租金／原合同／判决的确定义务及合法清偿 | 沿原来源的付款方／受款方／劳动地点与保护，不按新地址／总部改旧债 |
| P3 合法身份交接 | 既定资格／居住／雇佣终止与新届议会原子交接等，按既有依赖排序 | 新议会不能重投旧已完成有效表决；旧合同／税／裁判不随换届清零 |
| P4 冻结观察／程序输入 | 选民册／合法观测、LS42前日证据与本日目标、当前会议的提案／议会版本 | 必要页齐后才称完整；不把一半选民或一半工资付款当全城快照 |
| P5 新动作 | 当前届会议表决、行政承诺、企业／居民合法意图、开工／新排班 | 表决后新法仍须公布与生效等待；每动作重查当前版本／现金／权利与授权 |

同T处理产生新的同T必要事件时仅按已定义依赖闭合，不无限递归；全阶段排空前不前进到T以后。8192只是就绪窗口，迟到处理仍固定原到期T，不能按墙钟先后抢资金。

| 动作 | 决定来源 | 不能替代的其他门 |
| --- | --- | --- |
| 普通法案／预算 | 原9席至少5参与且5赞成；公示≥3日、每7日会议、公布后≥1日生效 | 宪章、能力／范围、财政真实钱、产权及玩家授权 |

| 私人排班／消费／认购／迁居 | 有效合同／规则下原企业／居民模拟决策 | 资金、资源、劳动／住房权利及原冷却；市府不能假扮居民签字 |
| 司法限制／已定债权执行 | 真实管辖、有效规则与原证据／裁判 | 不造现金／建筑、不自动扩大预算或撤销私人权利 |

会议日锚点在宪章固定（候选为世界日0起每7日00:00）；最低公示满3日后取下一可用会议，普通公布后最快下一日生效。法案与未来规则槽在进入程序时预留；同级替代关系不明确就不生效。跨年预算、有限留任、历史承诺沿原财政／选举契约，不将同一工程重复批准或重发钱。

## 2. 工资、停工与保底的有限依据

计薪单价／固定月薪与日／周／公历月付款周期继续分开。每劳动关系的冻结条款至少有：真实劳动份额／雇主O及公司、原家庭收款方、资格、参考月约定工时／最低保障工时、排班、计薪／付款锚点、生效区间、法定profile及未来变更来源。原岗位边只引用该来源，不能临时让LLM编条款。

| 事实 | IL43候选处理 | 禁止事项 |
| --- | --- | --- |
| 实际劳动 | 原S03工时按既有条款应计，S08产生同一毛薪债并按期净薪／税同步清偿 | 没销售不免工资；欠薪不是家庭现金；不重复向财政交第二份雇主税 |
| 雇主经营／设备／资金／许可原因不能提供已接受工作 | 已接受排班按100%约定毛薪保底，实际劳动／产出仍为0；不得再将同一时段实际工资与保底相加 | 不虚增到岗、产品、通勤或消费；安全停工不取消已发生费用 |
| 固定月薪不发布排班 | 依冻结最低约定工时／月工资基线按时间应计，不以雇主新发布实际排班数作分母；同时间实际薪与保障只计一次 | 不排班不等免费养着名义员工；不能改分母抹掉原固定工资 |
| 员工未按约提供劳动 | 真实可支付工时及明确保障照原条款；不可用“雇主停工保底”冒充员工自行缺勤全薪 | 堵车不立即删除就业；缺证据不直接认定旷工、罚款或解雇 |
| 新工资／保障修改 | 仅未来生效，须原双方有效同意及法定依据；原已接受窗口／工资债保存 | 本轮不开放奖金、佣金、工资追回、罚款或任意以股息替工资 |

固定月薪仍按原行业规则，以冻结该月约定可付工时为分母，实际劳动＋依法保障的非重叠应付工时为分子；新入职首期只计合法区间。最低工时／工资可明确为0只适用被支持的非固定保障合同，不能把已有固定月薪热改为零保障。常规8h／工作日、40h／周参考和休息／资格约束仍按原实际班次，不增加每人第二份劳动。

## 3. 7日通知与有资金的合法退出

正常雇主或员工单方终止均以可靠游戏送达为起点提前7游戏日；双方依法同意可缩短，但不可放弃已发生工资。通知不依另一方无限同意才能开始，送达证据及终止T写原来源，争议不能由agent自称“已通知”。雇主通知期间按原最低保障及已接受班次计薪；不提供工作仍有原保障。员工主动通知期间须履行合法已接受工作，不自动得到“拒绝劳动也额外7日全薪”。

资金保护采用不重叠并集：已应计未付工资、全部已接受班次、以及从当前时刻启动最早合法终止所需7日保障。固定月薪最低基线也在退出窗口中；已有更长确定承诺不能用新7日截短。工作／保障同一时间只计一次，不能一笔钱担保两份互不相容劳动，也不能把7日后全部不确定未来工资一次冻结。

在接受雇佣／续期／提高基线及每次续补滚动资金窗口前重查。无法补足就停止新招聘／新未接受班次，启动合法通知／停新处置；仍不通知而维持有效合同，最低保障继续应计，不能靠预算不足停止记账。固定期限及超过本策略支持范围的额外保证必须有独立可执行来源，否则签约前unsupported；原已合法承诺继续保留。

工资到期未付，且原账本已核毛薪债／到期／尚未清偿事实成立时，员工可自主请求立即终止，不必先等完整法院判决或雇主承认；未经核实的指控不自动清合同。立即退出不新增离职后7日工资、不追回已发工资，旧债与税源不改。主动正常退出或通知到期，先封旧劳动／保障、固定未清债，再解除主要雇佣匹配并失效未来OD，T前实际劳动／停工保障和欠薪不变；T后依法随劳动关系终止的排班、劳动时间及OD解除，不能继续锁住新就业。依法独立存续的确定工资／补偿保证另保留原付款义务，不再占用员工劳动时间；对应保护只有该义务依法解除／结清才释放，不能把保留钱债当作保留旧岗位。除此之外不再因已终止关系新生普通未来工资。

FB37的10%用工／未来可调整工时上限只是意图节流，不是法律许可；固定保障、已接受班次、7日通知及合法条款变更门同时成立才可执行。合法失业后可求新岗位；旧工资未清不应把人永远锁在旧雇主，但在合法终止T之前不能重复使用同一已承诺劳动时段；T之后按上段释放，不因旧保证款未付阻新就业。终止不需市长逐户批准，也不能由市长代员工提出。

雇佣终止与患者／服务队伍／危险工地的实际安全交接分开：原责任公司须有真实替代人员／返程／保全，未交接不删旧现场；不能借安全之名强迫合法退出员工无限无薪服务。股东、政府或换经营者不自动代偿旧工资；财政援助仍另有资金／法源，不无限兜底。

## 4. 清偿与救济边界

特定来源的工资／托管／安全用途保护仍只服务原合法来源，原S08不重叠记账；原特定补助／判令规定的优先权优先，不能被通用新策略夺走。IL43普通无特别优先权的可用现金清偿候选顺序为：已到期工资毛薪（净薪／税一次拆分）→其他到期确定债按到期时刻／稳定源ID。无到期义务时剩余钱才可接受新承诺；不能先分红／转私人账户再称无钱发薪。工资保留也不是额外现金，优先不使其他债消失。

IL43不新增通用家庭法定生活扣除额（默认额外法律冻结为0）；FB37／ME41的必要生活预算仍是消费／自主资本支出门，不能把它伪装成法院新增免债额。既有专项生活保护、托管或有效裁判仍按其原真实来源执行；缺必要优先权／执行规则则law_unconfigured，不由此默认强制扣款。长期住房、公共援助和司法裁决不得因为雇佣终止失效。

普通权限／程序审查申请候选期限为被诉决定可靠送达后30日，已登记债务本金不因该程序期限自动消灭；工资本金／租金等原履行与清偿按原到期来源继续。已有专项期限（如工资税更正1公历年）优先，不用通用30日缩短。可靠收件固定申请日，不因64案满／排队损失时效；无法可靠持久化按原安全边界暂停，不无状态签发裁决。

普通受理后给7日答辩机会；答辩期满后目标7日规则审查，确有原费用／证据／容量不足可一次有记录延期7日，逾期显示backlog／程序后果，不自动判任何一方胜诉。紧急停止令按原明确范围／证据与8紧急槽处理，不等普通答辩才保护已知硬限制；仍无必要保护容量则按原安全门暂停受限进度。

普通裁决送达后7日内可申请一次复核；未过该窗或已复核未决时保留原活跃案件／必要命令，不能以“纯金钱欠款”提前释槽。最终且只剩已确定款项时，原子关联同一本金到65536义务表并保存裁判来源后可归档；付款人缺钱不应永久占审理槽。同一终局事实／请求不能靠换新案号重走普通审查绕过一次复核和专门期限；真正新事实保留其独立合法请求。申诉／复核不自动撤销既有禁令或暂停工资／原已定债，只有有效范围明确的临时措施才能改变相应未来执行。
