## 1. 有限范围与因果顺序

本策略FB37可在START36后继配置选择，不热改START35／36的历史数字／合同。商品、工资报价、现行租约沿冻结条款；首版反馈不要求动态价格、贷款或完整地产／破产机制。家庭需求、企业预测、意图、实际交易、应计、现金分别保留，任何预测不能直接写收入。

日常消费／班次／交付仍按事件与原时窗运行；每天00:00封闭此前已提交区间后，用同一完整快照生成有限预算和经营意图，最早作用于之后的合法窗口，不追改昨天。每7日（初始日+7k）00:00才做常规用工与自主迁址复核，硬失效／缺资金立即处理，不等周复核。按原同刻阶段，先旧义务与有效限制、再观察、最后接受新动作。

每批最多评估256家庭或128运营者，按稳定ID／持久阶段游标分页；该日必要阶段未完成不得让后续动作读“全城已评估”，实际倍率可下降。记录unresolved与覆盖，不让actor数量成为每帧寻路或模型调用数量；批次不占City Team分析任务槽。

## 2. 家庭预算与真实消费

对家庭h，n是实际居住人数；一般商品基准目标b=0.5n单位/游戏日，收入相关可选量最多0.25n，合计不超过0.75n。不是食品／娱乐的完整生活篮子。每日需求来源以家庭／商品／所属游戏日去重；门／店铺／路线切换不会多生成一份需求，未买到不等于已消费。

| 预算层 | 规则与边界 |
| --- | --- |
| 现金与保护 | 读取真实家庭owner现金；先按现行清偿／最低生活保护／司法冻结规则扣同来源已受保护金额及本窗口须保留的确定义务；未到期全部长期负担、争议请求不能自动冻结全部家庭现金。相关优先权缺规则时停止相应新承诺并标law_unconfigured，不由预算模型改判权利。应计未付租金及已接受的首期费用不得被花掉；同一义务已有保护时不再扣第二份。押金受限、欠薪、房价、未付转移和未来报价不是可用钱 |
| 工资间隔 | H取下一次现行合法工资到账锚点的剩余游戏日、至少1；多个已签收入取最早有资金依据的锚点，明确不保证到账。无此依据／已逾期／失业则采用30日谨慎窗口；允许公历月跨度31日，不统一成7日。H只是规划，不把未来净薪加进现金 |
| 水电／通勤缓冲 | 在H窗口内按已覆盖实际profile／报价估所需金额U_H；它是自己的软预算，非新钱包／法定债。不与硬保护重复，缺必要报价时可选消费关闭、基础消费仅按已有可核条款预算并报告缺测，不假造U_H=0 |
| 本日基础额度 | B=max(0,现金−同源不重叠保护／既有义务−U_H)。本日基础购买预算至多B/max(1,H)，目标仍≤b。给定可达到岸价p>0，实际量还受当日剩余目标、该额度/p、在库、通道、服务／时间约束。保留的B余量仍在原家庭账户，不能每逛一家店重新拿一份额度 |
| 可选消费 | 仅在基础目标和上述保护／缓冲足额有依据时开启。读取近30完整日真实经常净收入I30与必需支出参考E30（含同一基础商品30日、租金水电通勤，各项一次）；可选目标=0.25n×clamp((I30−E30)/(300n),0,1)。n=0无居民需求；缺完整覆盖则可选量暂不启用并标unknown，不反推收入0 |
| 最终成交 | 可选也不得侵占保护、缓冲及H窗口剩余基础预算；不能将I30当现金再花。按原市场从同一真实需求竞争选择可达供方，最多8个候选／次，确定排序含到岸价、合法旅行／服务时长及稳定ID；只从实际成交和交付扣库存／现金，失败保留未满足 |

需求按当前日消费窗口关闭：未满足记入该日指标和原因，不自动堆成明天额外可吃两份；已接受付款／在途取货／退款仍保留原来源直至结清，不能跨日删事实。跨日迟到交付只归原需求，不能同时冲抵新日需求；不支持家庭囤货／保鲜的部分不临时建隐形库存。

FB37在收入历史不足时保留0.5n基准目标；START36的固定访客时点可作为输入，真实成交仍按本预算。可选量增加可能超过原供方672单位/28日的总额度，必须形成真实未满足或另签有限合同，不免费扩大供应。

## 3. 销量、缺货与补货

日评估从原交易／交付／取消／退货／需求来源读取最近7个完整日，不从可淘汰监测桶拿权威。每次查询有范围／版本和覆盖，最多8192条来源或256KiB暂存（两者先到即停，复用原工作区）；超额分页后续处理且标unknown。不能为了算连续窗口承诺每次扫描全部世界历史。正文／原票／索引若不足，停止相关新决策而非假称零需求。

需求预测D只含：真实最终销售＋分配给该供方、因缺货／服务短缺而未满足的**真实有支付能力且可达**需求，除以完整覆盖日数。同一原需求跨店最多归一个分配来源；消费者没钱、已在别店满足或仅路过，不给每店加一次“潜在订单”。缺货压低销售时仍显示未满足，不自动推断无人需要；预测不预占家庭未来现金。

完整7日不足时可用明确开局需求profile做启动预测，并标bootstrap；未配置则不能启动自主补货。不能拿第一天偶然销量线性放大到无限订单。库存周转目标为7D，但不得超过实际相容存放能力；在库、已承诺在途、已接受未发订单分别同源去重。有限供货协议的“最高可买672”不是已购买672。

新采购量≤max(0,目标−在库−预计在目标窗口到达的在途−同窗已接受未发量)，并取真实采购／运费现金、供方剩余额度／库存、装卸／物流和到货时可保证的接收空间等上界。超窗口的既有订单仍有责任且进入将来相应窗口，不能因此重买；接收空间不靠尚未承诺未来销量凭空释放。每次只接受下一有效发运窗，未来不确定量是意图，不把7天预测一次全变不可撤销采购。

制造同样看真实订单／可接收库存与配方瓶颈；缺订单不烧完原料生产到无限库存。待机／保全和合法已接受工资保底继续按原条款付，不能将缺货或低销量直接乘到全部工资。新策略不取消已有不可撤销订单／在途／尾款，取消部分按原条款结算。

## 4. 用工、停业与退出

经营状况用真实应计收入与成本（已售商品取得成本、毛薪、实际水电／物流／维护／场地和适用税）判断；利润与现金分开。未到发薪日的已劳动工资仍计成本，未付销售／尚未交货的订单不冒充已实现利润。收入／成本覆盖不全则unknown，不因现金尚多判断盈利。

| 触发 | 允许形成的有限意图 | 禁止事项 |
| --- | --- | --- |
| 正常／供给缺口 | 每7日复核一次；最近7日中至少3个完整日出现有支付能力的真实未满足，且确由岗位工时不足限制交付，才考虑招聘。每轮最多增加max(1,ceil(现有合法岗位×10%))个岗位，仍受实体容量／必要资格／设备／工资资金约束 | 仓库满／断水／路断的缺口不能靠增加员工消除；不能把招聘名额当已雇佣、把未来销售当工资现金 |
| 持续亏损 | 最近7日应计经营净额<0的完整证据连续14完整日后，形成缩班／不续约／退出调查意图；不能靠一日坏销量立刻删员工。一次自愿用工方案正常调整间隔至少7日，需求受限时幅度≤min(未来7日可调整排班劳动工时,max(1,ceil(未来7日可调整排班劳动工时×10%)))，并保持必要班组，否则选择合法不开业工况 | 意图不是合法解雇；固定工资／已接受班次／保底、通知／补偿和同意条件按现行条款。CD-06未给可执行依据时返回law_unconfigured，不能擅自砍已发生工资或无限拖欠 |
| 现金不足 | 立即停止无资金依据的新招聘／采购／未接受班次，保留已有劳动及确定义务；评估实际合法停运／保全 | 不等14日才守现金门，也不把保护不足转成免费劳动。缺钱不是自动终止合同的法源 |
| 路／网／许可硬失效 | 原系统即时限制新增运行；经营只报告原因、合法保全／退出意图 | 不等周评估才停违法活动，旧员工／居民／在途／库存／债务保留 |

缩班分母固定为本次完整快照中未来7游戏日、尚未接受且依法可调整的已公布排班劳动工时；无此来源则不自动缩班。最小调整单位1劳动小时，不是1班组小时，实际修改须符合可表达班次。原方案世代与7日冷却约束整次方案，不能滚动窗口／拆提交／换operation_id重复获得10%额度。

“10%岗位”与“10%未来工时”分别有单位，不能把人数减1与时数减1混用。必要班组缺一人时，按真实受支持降级工况或停止新增服务，不对安全最低人数做比例折扣。自愿方案生效后的7日冷却不妨碍硬失效／缺钱立即止新，也不保证被停掉的既有工资义务一并停止。

退出顺序：止新→处理真实劳动／工资及合同→清库存／在途和服务占用→落实合法维护／移交／清场／废物／安全→确定尾款沿原债权移交→达到原运营单位释放条件。自有楼体不随O关闭删除，现金不足则保留停业未清算单位及责任；没有破产机制不写自动债务折免，4096O满也不能挤掉旧债单位。

## 5. 择业、培训与迁居

失业劳动份额每日在实际空缺中最多查8候选；每户总候选≤16，超出／路况不明为unresolved，不是岗位不存在。候选须真岗位、资格、合法班次、到岗路径、资金及已公开工资条款；同一劳动份额只接受一个相容岗位，当前真实雇佣与在途仍由原来源约束。

自愿换岗每7日评估，且现行雇佣已满7完整日（从当前条款真实生效时刻推导，无额外换岗计数器）；比较同一未来30日税后工资参考−实际通勤／必要工作成本，优势需>max(原同窗参考净收益的10%,30币)。缺未来条款／费用／通路覆盖不换岗；预测收入不是搬家／消费现金。依法失业不受自愿冷却阻止求职，尚未签新岗位不能提前退出旧岗位或先算新工资。

培训只在原120教学h／最低90日历日等具体课程规则、资格、席位、真实学费与工作＋学习时间预算内形成行动；本策略不每日生成免费培训或新增教育机制。

迁居保持原综合满意度<35持续14日／迁居30日冷却。FB37按**连续14个完全覆盖且可证明满足条件的游戏日区间**保守判定；分段满意度若在任意时刻回到≥35就打断，日均低于35不能替代连续证据。事件中途首次跌破的当天不算完整日，最多延后一个日边界；缺环境／服务／权重等CD-03依据时为unknown，不触发迁居，也不显示满意度合格。

只能调查最多16个真实候选房源；要迁居仍须合法入住锁、真实费用／搬迁交通、原租约退出及新入住原子交接，不重复人口、不消掉欠租。30日冷却从实际合法完成入住变更后、向上取日界线记录，最多保守延后1日；意图／失败调查不重置冷却，不强制一家每30日必须搬一次。

## 6. 生活反馈的有限入口与依赖

本轮可给一般商品满足子项`clamp(实际满足的当日基准量/b,0,1)×100`，只覆盖已支持一般商品，不据此声称营养／健康充分。可选消费没买到不降低该基础子项；基础目标不能在缺钱时被降到0再显示100%满足。

就业／收入安全显示实际雇佣、逾期毛薪／实付及真实现金缓冲，来源不足不合成一个虚构安全分。住房仍同时看真实居住权／费用负担和实际环境／维护，不用房租上涨直接等同房屋质量提高。完整8维目标／偏好权重及环境／服务影响由CD-03关闭，本轮不擅自补零或对缺测维度重新归一成“高满意”。原7日时间平滑保留，不能一日失业就直接改为人口流失。

这使“收入变化→可支付需求→真实销量／库存→采购／岗位意图→实际工作／工资→家庭”具有明确边界；“环境／服务→综合满意度→迁居”仍有CD-03显式依赖。规则依赖开放不等于将原首版迁居／环境玩法延期删除。

## 7. 七类结果与停止门

| 输入类别 | 必须输出的结果／守恒与停止条件 |
| --- | --- |
| 正常 | 只按真实现金／劳动／库存成交，工资净薪＋税＝毛薪，实际供需更新而非预测直接实现 |
| 缺现金 | 基础目标保留，实际购买受限并记录未满足，可选停止；不借另一家庭／财政的钱，已受保护租金不被消费 |
| 缺货 | 有钱但未买到的来源记缺货，补货可参考该有限需求；不在每店复制需求，收到货才能出售 |
| 欠薪 | 工资债保留、净现金不增加；谨慎窗口30日、求职依法进行；雇主不能倒删已工作工时 |
| 硬失效 | 即时阻新，保留在途／旧义务，报告断路／断供／许可原因；预测与自主冷却不豁免硬门 |
| 未知／满额 | 结果unresolved／unknown及缺覆盖，基础已有事实继续记；不把未找到当不存在，不以缓存失效清连续状态 |
| 退出 | 只在真实安全收尾及原债权／责任可追溯后释放O；欠款／居民／资产不随企业消失 |

仅取一个正常输入和一个“有钱缺货／无钱有货”的对照足以核预算与需求区别；其他项列不变量，不继续按下一天／下一次危机扩故事。规则定义不等于已证明稳定，固定价下仍可能长期衰退、失业或财政缺口，不能调指标使其成功。
