# 区域属性与概率决策

设计补充：2026-10-21，发布v0.5.58。用户提出以“一片区域的属性决定概率，再抽随机数”代替大量主体模型调用。本篇定义默认的轻量自主经营意图机制；尚未实现、调参或验证性能，不改变现有M0实验配置。

## 1. 与现有设计的关系

此前已有[群体与表现分离](population-and-presentation.md)、[粗粒度模型与固定随机源](model-granularity-and-convergence.md)、[游戏时间事件过程](game-time.md)，以及[家庭—企业反馈FB37](household-business-feedback.md)的日／周评估、连续条件和冷却。总体设计也已有按可达客群、预算、竞争和租金选址，但没有明确把这些属性转成区域行为概率及抽签流程。

本篇补这一缺口：自主新设／扩张等软意图默认使用本地参数化规则，不要求为每个居民、企业或区域请求Jev等外部决策服务。City Team调查、对话与规划的模型职责沿原契约；既有FB37迁居／用工硬门、确定性交易排序不被随机规则替换。旧profile继续按原版本运行，新增策略须显式配置和迁移。

## 2. 默认计算流程

区域有覆盖的属性快照 → 计算某类行为的概率 → 固定游戏周期抽签 → 形成有限候选意图 → 现有权利／资金／建设流程 → 实际结果反馈区域属性。

区域是已有有界空间分区及可达服务范围的统计口径，不等于一座城市或一个新常驻agent。收入／购买力分布、人口与需求、现有设施容量／竞争、租地成本、交通及供给条件从原家庭、市场和设施来源查询／汇总；不能仅用平均财富把整片区域当成一个钱包。不同服务范围交叠时，需求来源必须去重。

每种行为有独立、版本化的参数profile及概率，不用一个区域随机数同时决定医院、商店和住宅。静态权重共享，快照／评分可复用；不做每帧全城、每人或每地块扫描。

候选的最简形式为 `p = clamp(b + Σ(w_i × x_i), 0, 1)`。所有x为已定义单位与归一化范围的区域指标，b和w为游戏设计参数；缺必要输入则unknown并暂缓该候选，不能当0。p表示“在本评估周期产生一个该类自主意图的概率”，不是盈利概率、模型置信度或现实统计结论。

抽取均匀随机值u∈[0,1)，当u<p时生成候选。p=0不触发，p=1必触发；50%没有统一准入含义。实现时须冻结整数／定点量化、夹取与随机映射规则，不能依平台浮点边界获得不同结果。

## 3. 私人医院示例

沿总体L05的私人合法医疗运营者、医疗需求／服务池和付费规则；这里只说明投资意图，不新增临床模拟或保险金融机制。下列数字仅为说明公式的合成示例，尚非可执行的平衡参数：

| 区域属性 | 本例对周期概率的贡献 |
| --- | ---: |
| 基础倾向 | 0.10 |
| 高购买力客群占比较高 | +0.30 |
| 有覆盖的可达医疗需求缺口 | +0.25 |
| 现有竞争与已批准在建容量 | −0.10 |
| 地价、工资与经营成本压力 | −0.05 |
| 合计 | 0.50 |

同一份其他条件下，购买力贡献由0.10提高到0.30，p由0.30提高到0.50；需求缺口贡献再由0.25提高到0.35，p提高到0.60。富裕提高倾向，但竞争饱和或成本过高仍可能使p低于0.50。人数、价格与支付能力须有真实来源，不能凭“富人区”生成新患者或保证全部床位满负荷。

若p=0.60、u=0.42，则产生一个私人医院投资候选；u=0.81则本周期不产生。候选不是已成立企业或已建医院：仍须选定有资金依据的实际投资主体、合法场地、许可、资金／真实工料与施工、医护资格及运行资源。缺条件保留原因或退出候选，不随机豁免、不自动扣居民的钱、不让市长代私人同意。

同区同类默认每周期最多一个候选；已接受且未完成的同源候选不重复发起。已批准在建容量计入竞争预期，实际医疗容量只在验收及真实可运营后提供；建成后重算需求缺口，从而降低继续投资的倾向。跨区争用同一投资人现金／场地／需求，仍由原事务和唯一writer复核，不各用一份余额。

## 4. 周期、随机与恢复

新增自主投资profile的原型候选周期为每7游戏日一次，锚定世界纪元；这是待验证参数，不等于每周一定投资。属性变化只标记评分待更新，下一个固定评估点读取已提交快照，不因每次查询／属性抖动额外抽签。硬失效即时限制真实动作，不等周评估。

随机键至少绑定世界seed、城市／稳定区域身份及代际、行为类型、策略版本和周期编号；算法版本也随策略冻结，模拟域与视觉域分离。同周期分页、worker重试、读档、画质、相机和现实倍速不改变抽签；分区拆合不得获得额外试次，缺稳定映射时不开放动态重分区。

固定周期跨越时按游戏顺序处理必要评估边界，不能快进一天抽一次、慢速每秒抽一次。未来如改成连续事件率，须另定义时间换算和事件过程，不能直接把周概率当日概率。关闭城依[R54](regional-snapshots-and-interaction-ledger.md)只参与既有交互履约，不抽自主投资；重开不补抽关闭期间的历史周期。

抽样可由稳定键重算，但“该周期已处理”、输入快照／规则版本、已接受意图及其责任必须沿原阶段游标和事务来源可恢复；失败重试不换快照重抽。查询只解释已有结果，不推进随机或提交新意图。

## 5. 计算预算与验证边界

工作量按实际评估的区域×已启用行为类型×有限指标／候选控制，输入优先复用已有汇总，避免每次重新扫全城历史。日周边界用有界批次／持久游标分页，超预算标待评估并降低实际倍率；不把未算当“不投资”，不删除旧义务。不同财富／资格／责任的必要差异保留原来源，不要求建立所有属性的组合群体。

本篇不授予新增内存／队列额度。实现前须明确分区数、行为数、批量大小、共享参数／缓存、阶段游标、意图去重与历史来源的具体存放及字节，纳入[总体运行预算](product-runtime-budget-and-versions.md)；现有记录无法表达时先准入或暂停该profile，不藏入无限区域缓存。规则预计比逐主体远程推理轻，但加速幅度仍待同负载实测。

验证至少覆盖：同条件购买力／缺口增加不降低本profile概率，竞争／成本增加不提高概率；p=0／1及量化边界；固定seed下跨速度／分页／重试／保存恢复一致；不同seed的大量独立试次频率与配置概率相容；审批在建抑制重复候选；资金／场地冲突不重复占用；无资金、有需求但无医护、未知输入和满额均不凭空建成。未实施前以上均是验收要求，不是测试通过记录。
