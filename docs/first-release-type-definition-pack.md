## 1. 范围与完成门

[90类目录](building-types-and-technology-catalog.md) 中首版23类各有下表一个基准规格；66后续与1远期仍按[覆盖矩阵](object-definition-coverage.md)保留机制缺项。这23类包括道路、网络、边界，不全是楼。复用[27物件契约](common-object-contracts.md)、[13结构样例与12经营profile](first-release-object-templates.md)，不另建23套经营系统。

本包补齐每类的规格入口、面积／能力、设备负荷口径、工程费用／维护估算、运行和退出约束。**候选规格已登记，不代表参数全配或资产可投运**：源影响系数、合法几何、服务需求／班次细分、市场与交通参数仍须联合冻结。缺必要值返回template_unconfigured；缺机制返回unsupported；不能将缺项解释成0。GAP-03由“无逐类规格包”推进到“候选包已登记、联合参数／资产待验”，GAP-02标准开局和GAP-11性能不随之关闭。

每个定义包含：CAT版本→原OBJ／O引用→几何及计量基数→人员／能力→资源工况→工程／维护／退出→接入／权益／影响→剩余准入门。以下表和公共规则合起来才是一个包；不允许只复制容量列。

## 3. 几何、设备与水电公共profile

矩形候选楼均有原点、朝向及姿态版本；表内尺寸为本地坐标宽×深，门须落在实际边界。普通楼的初始候选门：南面人行主门、东面服务／货运门（有此角色时）、北侧电口与水口；消防另有西面车辆口。角色可共用真实口，绝不生成相同容量的虚拟门。合计最多5口，未用口不创建；具体坐标、净空、走廊和合法接入仍须资产验证，靠近道路不等于连通。

## 5. 线性、边界与面积守恒

- 道路基准建设＝L×8m×150币/m²；电边＝200L币，水边＝100L币，均含该基准边的铺设／接口，不含新独立站房。候选道路工期max(2,ceil(L/50))日，水电各max(2,ceil(L/100))日；共沟工程须分项一次计土方，未核报价前不给共享折扣。维护与拆除沿K规则，切段后的工程仍有原项目总体阶段／日历下限，不用一米一段并行绕过工期。
- 水电“基准边损1%”指100m参考长度，实际存留系数为0.99^(L/100m)，不是每拓扑段固定扣1%。L=0的合法节点无边长损耗；实数公式中切分后存留系数相乘相同；实际定点实现必须按同一物理线路／固定物理计量区间来源累计，纯拓扑细分不新增量化／舍入边界，计量余数按原来源保留。精度／余数须装进原网络／meter额度并验证，不因本文公式获得免费新表；布局或精度未冻结不得投运。容量仍逐实际资源约束，平行边须真建设／占地／资金，不能复制端点扩容。道路自由时间＝L/30000小时，容量曲线未冻不报实际通行结果。
- T-03的K＝200×150＋20000＝50000，不包括外部通道；同一装卸位若已计入仓库／零售规格，T-03只是该实物的引用，不新收资本／发容量；只有独立新增位才建新对象。内部通道按真实独立路边另计，不能把200m²与通道重叠独占。
- T-10基准只有合同／边界，实物道路按T-01；不收“虚拟楼建设费”。启用前要求真实供方给分方向有限报价／交付窗／返程及失效、资金和通道占用。撤约保留在途、应计与债务，按实际清算条款付费；没有合同条款返回未配置，不用D=0生成免费供应。
- R-02基准是单栋两联排、不是两栋自动共有产权。两栋、共享院落或多产权变体沿[楼体／独立单元／共享设施契约](building-unit-shared-facility-contract.md)逐项准入。表中空余楼面仅公共／结构／未分配，不出租、不容人、不免费改作底商；混合楼仍后续。

## 7. 收敛、内存与准入清单

规格差异只进入冻结定义／profile引用，面积、设备和费率按事件／活动积分；不逐灯、逐树、逐市民每帧计算，不每建筑新建23张表。仍为143通用路径、34P／16C／14S／26M、27OBJ、13结构样例与12O；B0不是新增动态字段。整栋共享profile有工况差异可拆有来源的已支持聚合组，不能用平均数跨产权／资格／独立故障责任抹平。

23个候选定义按每个≤4KiB正文热页准入，最多92KiB；其余基础规则／被引用经营profile、旧冻结版本和组合版本共享原64×4KiB＝256KiB热页，不能23之外再免费加一个256KiB。正文超页分段分页且索引仍入原域；被引用旧版本不能销毁，热页淘汰不解除义务。记录仍受16行业、16商品、8资格／环境通道、每设施8口、4096O、原建筑／H／库存／OD／合同等联合额度约束，先计算真实展开后再接纳。

本轮新增常驻动态状态为0；现行区域29项43.5703125／44MiB、余0.4296875MiB，其他模拟314.025MiB和应用常态2.65／软上限3／峰值警戒4GiB目标不变。定义页数只是上限估算，没有序列化／索引／几何／资源尺寸实测；美术和精确门几何还占原资产域，不能用92KiB声称23类已在16GB跑通。

正式启用逐项检查：完整版本引用、合法几何／权利、面积与容量不重叠、真实班组／供给／需求、资金／合同／全部必要工况与环境参数、唯一writer／跨图同钟、满额联合准入、保存重放、静态不变量和真实运行证据。任何一项不齐保持候选，不通过强行补0进入游戏。
