## 3. 环境：两个明确的游戏通道

空气记EI、噪声记NI，均为无量纲游戏指数，不标μg/m³或dB，不据此声称现实健康或声学达标。初始化A空气场EI=2、噪声背景NI=1，来源为明确的28日预设外部背景条件；B如是真实邻城摘要则必须给对应边界交换值／覆盖，不能用常量背景覆盖真实邻城污染。缺数据返回unknown，不取0。

| 来源 | 空气／噪声profile，均来自实际活动一次 |
| --- | --- |
| 货车 | 行驶每车辆km产生0.20 EI·cell源量；等待每车辆h产生0.02 EI·cell。噪声行驶源20NI、等待8NI，时间区间取真实占用 |
| 公服／维护车辆 | 行驶0.10 EI·cell/车辆km、等待0.01 EI·cell/车辆h；行驶16NI、等待6NI；无此类实际行程则不凭合同生成车辆排放 |
| 本轮普通维护工作 | 每实际班组h产生0.05 EI·cell源量，实际作业源10NI；与运送该班组的车辆分开，车辆尾气不能在工单重复加 |
| 三种公服现场任务 | 医疗／警务检查现场直接EI=0、NI=0（本模型排除人声）；消防演练使用电动便携泵，直接EI=0、运行源12NI；车辆仍按车辆行另计，不把零现场源覆盖去返排放 |

源量EI·cell表示“分配到32m单元指数增量之和”，不当真实质量。行驶源按实际路段／停靠区间映射，其总量按长度／时间守恒，双线性投影至相邻格、权重非负且和为1；跨边界份额进入原摘要交换，不在地图边缘丢掉。只有位置与路径已知时才能做精确投影，摘要位置不详标粗覆盖而不伪造逐点值。

空气只用原场双缓冲。以世界分钟为固定数值格，h为分钟、0<h≤1，扩散r=0.02h、消散d=0.01h，邻域四连通：

`C_next = (1-d) × [(1-4r)C + r×(C北+C南+C东+C西)] + E_interval + d×2`

E_interval为该数值段实际源积分；背景补给d×2、消散、边界交换与活动源分别报告。r／d使非负权重且内区无源常量2保持；不是守恒空气质量模型。事件将一分钟拆段时记录同一数值格／原场锚点，按固定策略重放；不能声称任意粗细步长结果逐位相等。高速仍处理必要数值格或使用另行验证的同策略算子，不把一小时h=60代入；需要超出工作预算时降实际日历倍率。

噪声无滞留／扩散副本，当前NI=1＋各真实源强×`1/[1+(distance/32m)^2]`之和，超过256m的此简化局部贡献定义为0（是游戏核的有限范围，不代表真实声音归零）。按实际活动时段积分；源关闭后停止该源贡献。用于住宅暴露的接收点为真实楼体／接入锚点，32m场只显示近似；近阈值时用源包络到受体最近距离求保守上界，不凭格中心均值批准敏感活动。未能界定源／受体或峰值就返回unknown。

诊断线：住宅EI日均>5、NI夜间[22,07)峰上界>10，标需调查，不直接罚款、强迁或删许可；原S12有效禁行／禁噪／作业时段仍是独立硬门。START36普通维护许可窗08—16，超时阻新作业，旧在途／安全退出依法保留；不把诊断阈值当新法案。噪声是线性NI叠加，不能将其写成分贝再相加。

最多新增使用原128项监测额度内的6个监测引用：住宅EI均值／峰值、NI昼均／夜峰、交通积压与维护缺口；原分钟／小时桶保存覆盖／极值／违例，不从均值倒推峰值，不给每户再开6份。真正市民累计暴露要用其实际居住／工作／活动时段及唯一F来源；本轮只定义住宅受体报告，**不将其充作每个市民完整暴露或自动修改满意度／迁移**，未知B城工作暴露继续未知。
