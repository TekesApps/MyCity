| 工作包 | 实现与完成条件 | 当前记录 |
|---|---|---|
| 事实收件 | 实际交付、约定费用及既有责任同事务入账；同来源重复通知不重复结算；重启及旧凭证重试 | 待接续 |
| 容量背压 | 新承诺拒绝；已有事实有预留空间；必要记录无法持久化则推进不发布，原因可查 | 待接续 |
| 退出及移交 | 正常容量满仍能取消、结算、维护／管理移交、释放已履行容量；债务与真实在途不消失 | 待接续 |
| 持久增长 | 全状态检查点、独立根发布代数、WAL轮转、精确成功／失败旧凭证；实际越过1,024限制 | v0.5.16检查点子阶段；应急磁盘配额仍待接续 |
| 查询 | CLI分页合同、履约、欠费、占用、阻塞、恢复及原始凭证；跨写游标失效 | 待接续 |
| 真实长跑 | 同一实验存档30—60分钟真实墙钟；切图、满容量、故障、进程恢复；记录守恒／RSS／日志与耗时 | 待接续，短测不算通过 |
