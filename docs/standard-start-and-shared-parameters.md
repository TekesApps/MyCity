## 1. 目标、时间与范围

START35固定为游戏公历非闰年Y1，1月1日星期一00:00的期初快照。当前地图为小地图；仅一个详细城市A、一个摘要城市B及有限外部供方，引用原地图容量，不缩小16m土地单元。观察窗为28游戏日，供给和预算到期不自动续订。默认群体／家庭与劳动份额，不另建48个人生agent。

开局包含已合法验收的住宅、商店和道路水电网；不是让尚无工人／水电的空城凭空建成它们。资产的初始来源、成本基准、年龄和维护责任明确登记；后续新建仍走真实工程。不开本地煤电／泵站、不设本地医院／警署／消防站，使用真实有限邻城服务；首版其余类型仍保留在目录内，不为一个开局强塞全部23类。

本轮冻结身份／数量、候选布局、劳动／采购／账期及参考价格；服务工作与维护工料、环境及实际数值布局的缺参门见末节。未过门时只能静态核算／规划，不能把本文快照直接标为可运行存档。
