# 完整产品运行契约、16GB增量预算与实施版本

P53总体运行契约，覆盖R01—R04。原T47的八模块／S00..S13／CPU提交和保存通则继承；本篇显式增加新机制的状态／联合限额及阶段，数值可核投影见[reference-values.json](inputs/product-blueprint/reference-values.json)，与正文冲突须修正后发布，不把原2.65GiB预算自动当作全产品证明。容量和字节为候选设计上限，实际布局／CPU-GPU吞吐／16GB／经济／试玩仍需原型。

## 1. R01：跨图同一世界，不是每种模式一份摘要

| 九项契约 | 总体方案 |
| --- | --- |
| 需求来源 | 全存档跨城发展阶段不同，玩家要求用当前邻城状态、远端机会及实际交互而非强行共同本地年龄 |
| 设施与主体 | 最多8城候选容量、一个活动城；原企业／财政／家庭、实际多式交通及分资源公用网 |
| 资源与容量 | 本地development_elapsed与单调interaction_time分工；快照加已提交覆盖层；每项库存／资金／人数／容量仅一权威，不刷新睡眠产量 |
| 成本收益 | 原钱包／税属／合同清分；已接受工资租金／维修／债务依交互钟发生，不因关城逃债；无来源不新生收入 |
| 交通环境 | 全存档发现近远机会，按实际可达路线／距离／时间／费用接纳；瓶颈共享，履约排放与设备磨损照记，陈旧环境场不填零 |
| 法律流程 | 原产权／管辖／同意／拨款／合同／通知与救济保留；clock_kind事先冻结，不因切城换钟 |
| 失败退出 | 到期不续约、不抹旧债；短缺／故障传播；在途等待／改道／退出保留实际责任，不能重复恢复源人口与目的人口 |
| 玩家观察 | 快照版本／age／覆盖、实际余量与未满足、requested/actual/shortfall、在途和欠款；地方年龄与交互日期分开 |
| 聚合／writer／预算 | 单世界writer与提交根、仅活动城自主发展；全世界共用限额及有界增量，域内预算划分见R54，不复制8套Engine |

现行细节及M0边界以[R54城市快照与交互增量](regional-snapshots-and-interaction-ledger.md)为准。地图开关不重置年龄／库存／污染／义务，打开只对齐已提交事实与水位，不重跑休眠历史。关闭城只有明确启用且有真实投入的有限履约作业继续，不能自动新增班次／订单／招聘或按快照净产量无限输出。迁移统计可2000意向实迁1998，确认的人、家庭权益、钱、货和容量仍准确。

同一世界地图具有不重叠的整数厘米全局包络和origin；相邻需要实际接缝／同投影／高度与管口兼容。非相邻地图通过有长度／行时／能耗／费用／合法中间段的外部通道，不能凭边界坐标相同当作邻接。大型机场／桥梁／港区可为跨图program＋一个facility_root：跑道／站房／连接各有唯一资产ID／home_map／实际全局几何、产权／预算分摊；共享跑道冲突组／机位和经营账只一份。某小图容不下1500m跑道必须选更大图／合法跨图项目，不能缩小尺寸仍沿原额定机型。

外部源是有明确世界截断的有限合约：生产／持有存量、资金、单位／最大流量／窗口、人员／载具／对端、到返／收尾和责任列明，续期需新来源／预算。外界不必细建整个国家，但不能每种投入都声明免费无限。历史初始非现金资本／库存只能在新世界一次性入账，恢复／迁移不重复发。

### 调度与事务

沿共同P0..P5：先排空旧区间／旧到期事实，生效法律／停止令、旧债／到期、身份住所／交接，再形成新快照和新动作；S00..S13仍是逻辑单写系统，拓展功能是其领域作业而非每模式一个世界时钟。硬事件包括起降／到站／到期／故障／储量尽／法定日历／切换等，截断稳定区间；各source冻结clock_kind：活动城自主发展按本地钟，合同／在途／已接受义务按交互钟。到期／到款／到达等按最早边界截段，同刻稳定排序，不倒用未来现金；选举／法定期限另按明确历法锚点，累计不依现实帧率。

联合可行交付用同一prepare/validate/commit：冻结库存／资金／时间／路权／资源版本→提出流量／排班／生产／订单候选→物理／资金／法定门全检查→原子写对应各writer的命名字段和成对原票。任何一项失败全批不产生正式输出或收费；已发生部分按原子微批保留，后续取消只取消未来。不能S05先发电、S07后发现无煤；不能S04送客到门、S08才发现未有合法票而反向删乘客。

CPU为钱／权利／整数物量／随机来源／提交权威；GPU通过wgpu/Metal处理规则网格／场传播／密集候选批，结果带snapshot/profile/job generation及误差，陈旧／超误差候选作废；device lost仅丢弃未提交GPU候选，回到最后完整CPU权威微检查点并按同一冻结数值策略重算未提交区间，若CPU没有同策略实现则安全暂停模拟／保留权威状态，不能把换算法叫无损回退；若确需换算法／精度，须在一致边界提交版本化numeric_strategy变更及误差／兼容记录，绝不重算已提交历史；不因墙钟故障自行切策略，不把f32近似利润直接分红。路径／排班在有界批执行，原BC43的停止／未解age沿用；每发布最多3轮／4候选，重算总工作按共享作业预算而非每模式各给满额。

### 工具与指标双向对齐

所有新增公交线路／停车／能源／复合模块／征收／航班等工具共用授权envelope、世界分支／snapshot／typed目标及revision、operation_id／总额／程序证据。只读有分页／快照租约，接受计划必须当前最终校验；无通用set_property。工具族：query_*只读来源，draft/evaluate_*产生草案／预演，submit_*进入真实程序，apply_plan接受已满足门的有限项目，operate_service在有效经营合同内变排班／报价，control_*请求安全暂停／退出，get_operation恢复查回执。

关键指标均双向指向来源：实际出行／到岗←Need/Trip/S04；售票／利润←实交/票权/S08；服务可用／完成←S09请求/队/时窗；能源满足←S05实际送收/S07源；租金负担←合法H费用/收入/S08；污染／水质←源/场/人时；满意度←LS42观测/覆盖；预算余量←法律授权与钱债；工程完成←S01日历/实际投入；股息←封账利润与现金保护。指标不能反向免费写生产／人口／容量，玩家可追溯每个数的来源／年龄／上下界。

T07子阶段在几何0.30GiB内划21MiB空间资产候选份额（两个10MiB地形＋1MiB场景），运行时0.45GiB内划128MiB导入高峰及128KiB候选上传页；不是新增应用额度，GPU设备字节仍归原渲染／求解域。实际单对象门、调用方旧页及联合准入缺口见[T07说明](m0-spatial-model-and-gpu-layout.md#5-内存划分与实际证据)，不能用CPU打包证明GPU执行或16GB峰值。

预演对共享不可变页只读，修改页／临时图最多192MiB（包含在0.25GiB），超域分阶段预演或明确缩合法草案，不能另拷贝614MiB模拟当免费全世界预演。输入下载／解压／保存与预演峰值联合调度，达到峰值警戒就阻新高峰作业／降画质并背压，不把3.10＋各最大峰值随意叠成承诺。CPU吞吐可能先于内存受限，目标1日/s不能由容量预算推出。

## 6. 两种独立最终检查与原型证据

**覆盖检查**逐条REQ01—56，从玩家／市民／企业／城市四条责任链找是否漏掉整块功能；每个能力的九项证据、必要提供者和边界可定位，不能“名字在目录／实施后期”即通过。**协同检查**独立沿跨域链核对来源、钱物／人数、共享空间／容量、单位／时钟／writer、许可／赔偿／退出、聚合／联合预算／保存。两个结论分别记录；一次审查发现问题就修具体机制，不为了凑次数再扫旧案例。

协同重点链：停车／换乘到最终工作门；游客航班→酒店→商户消费→返程与独立核算；复合住宅／政务／站商的共享设备与租户退出；气电供暖替代→峰值／能源企业→家庭预算／环境法规；教育→招聘→工资→消费→企业需求；污水／残余物→终点→环境及许可；故障／维护不足→队伍／临时供给→司法赔偿／财政接管到期；跨图关开／保存恢复／旧债／同一人住所与股权不重置。

原型验证分离：静态契约／数量算术只证明设计自洽，I验证装配／调度／真实工具／数值与保存，V在真实16GB记录footprint/压缩/交换/CPU-GPU p95p99/实际倍率/帧间隔/磁盘增长及用户任务。经济需税／工资／物价／供需与科技0.5/1/2倍敏感度和至少2游戏年长跑；可玩性用G47新玩家实际完成／理解和全域可解释失败恢复；不以图表或文字断言通过。
