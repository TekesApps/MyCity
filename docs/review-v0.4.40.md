# v0.4.40 市场主体、个人股东与分红审查

基线v0.4.39。本轮仅改设计文档，不写代码，不展开AgentKit。[ME40](market-entities-and-equity.md)落实可查登记公司、独立经营核算、机场／航司分立及有来源的旅行动机；允许个人直接出资与按住所查找，并补财政参股／合法分红／实收后再预算。

## 变更及边界

- 公司、运营地点O、实物建筑、账户及股权分开；一公司多O、同楼多公司不复制库存／现金／交通。
- 个人可直接持股，有稀疏金融身份与真实自有账户；住所从实际成员／F／H／楼体单元查询，搬家不洗股份或债务，不依赖逐人位置／生活模拟。
- 现金、应计收入、库存／自有资产成本、资本与留存分别核算；库存成本用同法人相容商品池的固定取得锚点及累计出库差额，拆单／搬仓不能重置成本余数。
- 首版候选仅有限非上市现金实缴普通股。政府投资需授权／预算／现金；分红须抵亏、核算完整、无逾期及维护缺口，并通过现金和资本维护门。仅实际收到才进入股东／财政现金，之后支出仍需授权。
- 不可分配补助独立权益来源，不能通过公司分红把财政补贴循环算成新收益；股份票与市民选举／议会票分开。
- 机场／航司、航空燃油及观光／商务／工业活动客运和货运只补后续契约，未改变CAT-T-08后续B、12经营profile／16上限及LC38的9商品／16上限。

## Advisor反馈与补正

初审建议分清五层身份、实缴与利润、股息声明／应付／实付、财政独立授权、有限股权图和机场的供需来源，均已纳入。

草稿审查指出三项必须补正：旧公式可能把未付股息扣两遍；补助缺少不可分配权益落点；仅存库存成本余额会因拆单取整改变期间利润。已改为声明即减留存、不重复扣；资本／留存R／不可分配权益N明确分列并列32B锚点；成本池增加Q0／C0／X及稳定取得epoch，真实新取得才重设、内部调货不重设。为这些必要状态重划预算，不藏进旧I64B。advisor再次只读复核确认三项阻断解除、无新增必须修项，可冻结本版定义；该确认仅限定义与静态算术。
