# 建筑出入口、朝向与真实交通接入

v0.4.45 [SP45](start45-spatial-input-pack.md)给START45的8口、单元组和合法服务链路：东门仅人员／手推车，车辆路边停靠与受控过街，回转场明确新增费用；完整机动轨迹和楼内接入缺项仍阻投运，不用接近建筑代替到正确口。

设计补充：v0.4.16，2026-10-19。建筑靠近道路或与道路处于同格，不等于能够合理进出。实际出入口、合法连接及运行条件是通勤、访客、货运和公共服务的起终点依据；不能只从建筑中心寻找最近道路。

v0.4.28 [单元接入组](building-unit-shared-facility-contract.md#3-单元接入组有宿主不等于能走所有门) 要求冻结资产布局最多8组，由H布局槽／O合法使用范围解析可用外部门、内部公共通路／必要时长、模式／权限及管网／隔离依赖。只简化内部寻路，不自动接所有门；公共楼梯／支管失效精确作用于实际依赖者，正文与实例必要绑定／反查仍计原预算。

v0.4.25现行粒度与预算以 [整体分配审查](granularity-allocation-audit.md) 为准：34属性／14系统／27物件逐项区分保留、聚合、延后；新增基础本地供应计费绑定使用原区域余量4 MiB，现为27项43.0078125／44 MiB、余0.9921875 MiB，应用目标不增。下文39.0078125／26项是此前基线，不作本版准入；未验证布局／索引与16 GB实机性能。

## 1. 模板必须定义哪些门和端口

每个建筑／独立设施首轮最多8个对外端口，交通口及水电等接口合计准入，不为每个住宅室内门新建交通节点。一个物理入口可允许多个角色，但引用同一真实宽度／容量；两次声明“员工入口”“顾客入口”不能把同一扇门容量翻倍。

每端口最多一个物理外接锚点，进出方向分别编码；确有两条不同外接链路时使用两个端口记录并关联同一开口／瓶颈。角色采用固定受支持类型及位集合，权限／开放规则使用有界模板引用，不允许每门无限挂道路或权限数组；水电同样各接自己的类型网络。

| 字段／能力 | 含义 |
| --- | --- |
| 稳定port_id与宿主 | 模板局部编号、建筑／设施身份和版本；改模型不能将旧口偷偷映射到另一位置 |
| 局部位置及几何 | 外部口坐标、开口／接入范围、宽度、必要高度／净空、地面或明确高程 |
| 朝向与接近范围 | 门的向外法向、允许接近方向／连接候选范围；不是只写东南西北 |
| 用途与模式 | 居民／员工／访客步行、车辆、货运装卸、急救／消防／维护等适用角色及模式 |
| 进出与时段 | 双向／仅进／仅出、开放时段、访客或员工权限、停用和施工条件 |
| 能力与限制 | 开口吞吐、装卸／停车接收能力、实际占用及共享瓶颈引用；不同单位不混加 |
| 连接与权利 | 允许连接的道路／人行／服务网络、具体锚点、连接走廊和使用许可 |
| 状态与证据 | 规划／施工／可用／受阻、网络／几何／规则版本、失效原因与数据年龄 |

水电接头只接自己的管网，不能当作市民入口或证明消防可达。应急角色不是万能车辆模式，仍需真实接入和对应服务模型。首版不模拟门扇开合动画、楼内房间通行或真实建筑消防规范，但模板声明的外部门位、方向与必要接入必须约束规划和交通。

建筑旋转时对局部门位、朝向、连接候选区和开口包络应用同一刚性变换，再量化和验证；模板禁止镜像时不能只翻入口来迁就道路。允许镜像的模板也要同步变换装卸侧、进出方向和依赖，不能仅改外观。门不因附近多了一条路就自动换墙，改门属于有权限、有成本／工期的受支持改造。

平面算术例：局部门位(0,−6 m)、朝南法向(0,−1)，建筑中心放在(100,100 m)并逆时针旋转90°，门位变为(106,100 m)、法向朝东(1,0)。此后必须验证东侧的实际接近／连接，不能仍按原模板南侧接路；坐标例不是具体建筑规范。

## 2. 从门口到道路需要完整链路

真实链路为：有效使用单元／经营者→获准使用的建筑外部口→门前／院内连接→合法共享通道或车道→正确侧／高程的道路锚点→有向网络。每段均有几何、模式、权利、容量及开放状态；首版单元到外部门采用明确模板分配，不展开室内寻路。

道路锚点不是随便吸附到最近线条：须说明道路边／位置、接入侧、实际高程、允许进出方向及相关转向。门口不能穿过墙、花坛、别人的地、隔离带或不可穿行建筑才能到路；水平方向临街但隔着高差／无支持坡道，仍不可达。跨越车道的人行路径需受支持的合法过街节点；没有则不能直接穿马路到对侧人行道。

门朝北不意味着只能走到北方目的地，而是首先要能从合法北侧接近范围离开；连接走廊可以在模板允许范围内转弯，再进入路网。侧门、后门或多面出入口只有模板／合法改造明确存在才可用，不能因为地块四面临路就自动生成四个入口。

入口默认只作为该建筑相关需求的起终点，不允许其他道路出行借入口免费掉头或穿楼。确实可穿行的公共通道须独立声明合法连接、方向、权利和共享容量，进入正常路网／通道校验，不由“建筑有两个门”自动推出通路。

地块临街比例可以作为开发条件，但不替代实际入口。高架／地下道路投影紧邻建筑，也不能当作地面入口，除非已有合法且受支持的跨层接入。路权内可铺支路／人行连接的范围按模板、权限与共享规则判断，不隐式取得全段路权。

## 3. 车辆、步行与货运分别接入

| 关系 | 需要检查 |
| --- | --- |
| 居民／员工通勤 | 真实住宅及工作入口、方式、时段、可达网络、可用劳动／到岗 |
| 顾客／访客 | 对公众开放的口、步行／车辆接入与实际接待能力，不能借员工专用门进入 |
| 商品收发 | 货运口、车辆限制、装卸时段、可接收库存和处理能力；到建筑旁不等于交货 |
| 急救／消防／维护 | 对应服务能到达的接入点与允许安全范围，不拿一条窄人行小道当全部车辆服务入口 |
| 公用管网 | 独立的水电端口与网络容量，不参与交通进出判断 |

住宅步行入口不要求每户都有私人车道；若模板支持步行型接入，可以通过真实共享人行道满足相应用途。需要机动车维护／应急服务的设施必须另有受支持接入，不能因顾客可步行抵达就宣布货车也可抵达。

单行路、出入方向和既有转向限制分别校验。从某方向可驶入不保证可以沿原路返回；货车不能无条件跨隔离带掉头或逆行。首版采用聚合道路／转向规则，不承诺逐车车道变换或精细驾驶物理；无法表达的专用互通／转弯方案返回unsupported，而不是默认允许。

车辆／装卸入口的排队、通过或接收能力按真实瓶颈计量，可按模板把受阻需求留在内部等候或反馈到对应路段。没有空间的队列不能无上限藏在门内，也不为每车创建agent。停车仅使用受支持的接收／容量模板，未完成的全城停车市场不因新增入口自动实现。

## 4. 多门怎样参与交通而不双算

同一建筑可以有多个合法入口，也可以通过共享庭院通向两条不同道路。需求根据实际使用者／经营单元、角色、开放时间、总行程与容量选择可用口，不能都从几何上最近的那一侧瞬移上路。

入口选择是路径／接入分配的一部分，不是新增居民或第二次出行。同一份员工通勤或一批货物最多分配一次；某入口受阻后可重查其他适用入口，保留已行进／在途和等待状态，不删除人口、雇佣、订单或债务。两个入口通向同一窄通道时，通道容量仍是一份，不能每个门各拿一次。

封门先停止新的受限通行；已在连接走廊内的聚合行人／货运／服务批次按其位置和权利安全等待、退出或合法改道，不能直接搬到另一门口。不存在合法退出／继续方案时保留受阻和必要安全状态，不假设维修人员或紧急车辆可穿过物理障碍。门口吞吐、道路通过和建筑接待／装卸能力是不同约束，同一实际通过量只计一次，不用增加门容量生成岗位。

岗位匹配来源、交通OD、到岗工时、消费和交货读取同一门／接入状态。某人到了城市边界或建筑所在格，不代表已到正确工作入口；营业楼正门开放而卸货门断联时，不能继续按全部原料已送达计算产出。

OD可以聚合，但保留真实接入组、方向、模式与时段约束；不能把墙两侧或道路隔离带两侧不连通的口平均成可通达。超过候选／OD／计算预算返回unresolved并保留需求；只有限定范围完整证据才认定无路。稳定时复用接入和路径结果，依赖变化时按有界工作重新分配，不每口每帧全城寻路。

## 5. 改道路、围墙或入口后的闭环

道路单行／转向改变、施工占道、共享通道闭门、出入口移动、树干／围墙侵入、地形改造和法规变化都会使相关接入失效。施工方案先核查关联建筑、阶段净空和必要替代通路；旧评估凭据不能保证改完后仍通。

必要接入缺失时，未投运设施不能绕过投运门；已经存在的建筑保留实物、住户、产权、工资和服务缺口，按模式显示受阻／降载等真实后果。已有居民不能因为封门当步删除，企业也不能靠入口断开取消既有用工义务。恢复后按当前版本重新验证，不随机重新挂到另一条路。

新道路可能改善未曾使用它的入口，不能只查旧道路的现有使用者。反向依赖缓存满时允许有界扫描和分批发布，标记数据年龄；未完成重查不能宣称新路已改善全部交通。邻城摘要保留真实入口身份、模式、网络／开放引用，切图不自动补齐入口或重置队列。

## 6. 工具要让agent看清接在哪里

catalog返回最多8个模板端口的坐标／朝向、角色、进出、接近范围及兼容条件；get_object返回变换后真实口和当前连接。query_objects／inspect可按无合法步行入口、货运口受阻、单行无法离开等条件分页定位问题。

propose_layout／find_sites需给出朝向及入口连接方案，不能只返回建筑中心。connection.build明确端口、网络锚点／方向、实际连接走廊及共享空间依据；evaluate_plan返回门口到网络的完整链路、净空／过街／高差／权限及容量依据、未解决原因。修改仍走原计划／工程／授权，不能用直接写connected=true替代施工。

验收／投运按模板列出的必要用途分别检查：步行通、货运不通应显示两项不同结果，不能只给一个“有路”布尔值。只读工具使用冻结快照／分页、数据年龄与证据，不能把人行连接和水电端口混在同一连通结果里。

## 7. 规模与预算

新增全世界65536个建筑／设施对外端口与紧凑连接状态，每条目标32 B，合计2 MiB；一栋／独立设施最多8个，所有参与城市和端口类型共享。住宅单元、员工、租约、多个经营者引用同一真实建筑端口，不各建一套。通用端口与512个跨地图边界端口是不同类别，不混用限额；同一真实边界连接仅引用对应记录，不再计一次道路容量。

按模板实际端口数准入，不给每栋预分配8条。大图8000栋若均8口即64000条，只剩1536条给其余设施／邻图，不能再保证7邻城满载；一般工作负载必须选择联合可接纳的端口向量，不能把建筑上限与每楼最多8口同时默认为无条件保证。

32 B目标主要保存模板／宿主、连接锚点、几何／许可和时段／容量状态的紧凑引用及有界运行状态；静态局部门位／方向／宽高在模板共享，实例世界位置由模板与冻结建筑姿态解析，变长走廊几何归原几何域。排队／在途身份由原OD／货运／服务保留，独立共享占用由新增8192×64 B资源组保存，端口只作引用与状态投影，不在32 B之外暗建门内队列，详见 [空间运行一致性](spatial-runtime-contract.md)；实际装不下32 B就重新算账，不能省略已发生事实。旧建筑1 KiB状态与摘要仅引用该表，不再存第二份端口权威。

端口加入后的旧载荷38.5078125 MiB，再加v0.4.18空间占用组0.5 MiB，现为39.0078125 MiB；区域额度从40升44 MiB，余4.9921875 MiB；仍在原0.35 GiB模拟域，应用常态2.65 GiB目标不变。该2 MiB不是全部新增CPU／几何／索引成本，现有4 MiB索引、0.25 GiB几何、4096 OD、求解／预演及事件配额继续联合准入，不能另放无限门到路路径缓存。

接入锚点可作为指向有向路段及其位置的有界外接引用，在道路节点／路段求解时按合法方向与代价接入；不要求每扇门复制一个完整道路拓扑节点或把每个曲线采样点加进路网。必要转向／冲突不能由“虚拟连接”跳过，算法不能表达时返回unsupported／unresolved。新增建筑／端口及地图接入前预留状态和必要索引／收尾，满额拒绝新承诺，旧口失效／恢复原位更新。

路段内位置必须进入真实距离和方向代价，不能把锚点视为可在整条边任意上下路。必要临时拆段／虚拟节点及入口候选工作区计入原求解／索引预算，不通过少存永久节点掩盖无界临时展开。现行区域余量为4.9921875 MiB，几何、共享瓶颈、权限、队列和目录须按实际布局复核，现阶段只确认设计重划成立，不承诺最坏负载已可运行。

## 8. 待实现验收

- 同模板旋转／允许镜像后门位与方向正确；朝路背面且无合法通道时不能自动接最近道路。
- 墙、绿化、隔离带、高差／高架及无过街节点不能穿越；共享庭院有合法通道时可接入，容量仍只一份。
- 人行可达、货运不可达、单行可进不可出分别体现；水电连接不能满足人的出入口。
- 多门需求分配不双算，封一门后按当前实际路径重分配，货物不到装卸口不交货，到错误格子不算到岗。
- 道路／围墙／树木／地形和开放时段改变触发依赖更新；新路潜在受益组不漏查，预算耗尽不伪报无路。
- 存档／摘要恢复保留同一端口、队列／在途、资金及法律状态；65536端口与既有混合负载叠加测真实字段、索引、求解及16 GB峰值。以上为设计要求，尚无游戏运行证据。

## v0.4.18来源与容量的闭合

[空间运行契约](spatial-runtime-contract.md) 指定OD／需求保留去程、在场及返程，货运／服务保留原批次；新增8192×64 B组只补原道路／服务未表达的物理瓶颈。4释放桶是兼容占用摘要，不删除独立来源或二次释放，第5个不兼容批次进入前背压。32 B端口只引用，不另建门内人群数组。

法规／法院、开放／权利和硬几何变化立即阻止新的受限进入，不等例行重算。缓存绑定接入、资格／模式、规则／地形、锚点／方向及有效时间；预计到达改变就重查，通用路径不授予通用权限。成本软陈旧可显示年龄，硬权限／容量不可沿旧缓存放行。路段内距离真实计算，在途仍引用的旧门／边几何保留到合法退出／移交。

## 两楼共享通道的切换案例

[共享设施演算](worked-example-two-buildings-shared-facilities.md) 中，两楼共享一条40 m受限走廊；拆除一楼不能删除另一楼的权利。新60 m旁路验收后才可接入，同一单元粗步行代价由70秒变86秒，触发实际路径／响应更新。共同步行吞吐、维护车行吞吐与庭院并发分别计量；新旧并存占原D／X／U等额度，切换不迁移旧在途，实际退出后才释放。住宅迁空后仍需施工车路至最后清运。
