## 1. 当前判断与阅读方式

现有设计已覆盖物件／空间／交通／经济／居民／制度／工程／跨图／Agent工具及存档的大部分边界。主要风险已经从“有没有想到一种建筑”转向：**多个规则是否用同一套参数、同一开局、同一时间和同一资金／资源来源共同运行，玩家能否理解与控制结果。** 更多单独对账正确的案例不能替代这件事。

以下“待冻结”不表示此前完全没设计，而是还不能从一个确定的参数／配置版本构造完整首版输入；“待测”表示原则或默认值已有，但没有原型证据。目录的首版／后续状态仍沿 [原覆盖矩阵](object-definition-coverage.md)，本台账不重新定义A／B，也不把已登记契约称为已实现。

## 3. 本轮补齐的有限援助／管理交接通则

公共支出必须同时具备有效依据、真实付款主体、金额上限、适用对象／成本、开始／结束边界和退出检查；现金余额不是继续支出的授权，倒计时归零也不是自动解除产权／安全责任。

1. **到期前准备**：在原有限窗口内安排有资金的核查／通知与交接工作，明确下一期付款人、管理主责、实际作业方、权限、费用规则、服务标准、起止及失败安全动作；不把下一期运行资金重复担保交接／安置。没有实际资金与有效依据就标未落实。
2. **到期同刻结旧再接新**：先封闭原实际交付／费用／余数与仍未结义务，再生效新授权／责任／合同；不得两方付同一服务，也不因换管理方清旧欠费。原绑定的代付结束只影响未来付款，过去未付不改债务人。
3. **任务移交不等于全部责任移交**：委托维护可以交付巡检／作业／报告，不能自动转移产权、追偿权或全部法定管理责任；不可委托的职责继续由原主体承担。新方不能随意涨租、封路或取用家庭资金。
4. **财政不自动续期**：新增公共采购须另有合法授权和真实钱；援助用途、金额或期限变化依原程序处理，必要安全亦不能凭空突破预算。新一轮若获批，应如实显示仍在公共出资，不用换项目名宣称财政退出。
5. **失败不伪报完成**：无人续付时，公共采购可以依法结清，但后续维护／安全义务不因财政退出而消失。报告缺口、限制不相容新增、执行已有权限和资金可支持的安全事项；真实停运／替代接入／安置仍要资源与程序。不得承诺物理上永不影响住户，也不得为催收惩罚守约方。
6. **回款与损失核重**：旧债回到原债权人，不自动变成财政返还或自愿出资者退款。赠与、采购、代付、合法债权移交和追偿依据各自明确，同一成本只承担／收回一次；不能把无追偿救助倒改为贷款。

这些是有限状态／权限／账本的统一门，不实现复杂物业治理、税制、托管、强制拍卖／破产或无限应急调度。新的数值例子只有在上述门仍无法决定正常／失败结果时才有必要。

## 4. 先冻结什么，停止扩展什么

暂冻结三条已经深入的设计线：①Root／有限能力、共享空间／出入口与产权责任；②欠费、司法金钱执行、风险不免债；③故障、有限应急资金、实际旁路、赔偿核重与恢复。冻结指暂不新增故事分支，**不是代码完成或取消待验收边界**。

仍冻结原规模与粒度：固定16 m土地格、三档地图、一张详细图＋有界摘要、家庭事实／聚合求解／视觉样本分开、23首版／66后续／1远期目录状态、27类契约、143通用路径、13结构模板／12经营profile。风光／核电／燃气、复合商业、高层、轨道、储水／水商品、复杂金融等不因为案例可写就提前开放；也不因收敛而删除玩家已经要求的首版制度／生活等范围。

下一步按依赖顺序补定义：**财政口径＋标准开局 → 最小模板参数＋交通／经济反馈 → 纯输入流程／接入合同 → 兼容和资产验收 → 原型联合验证**。这不是现在开始写代码；先把能输入同一个原型的资料冻结。原型实现顺序仍见 [roadmap](roadmap.md)，该顺序不强迫图形原型等待全部玩法实现。

每个缺口只交必要的最小定义、来源／唯一writer、时间／失败与资源边界及验收条件。默认最多选择一个正常与一个反例输入，足以区分规则后停止；发现新的独立机制矛盾再追加，不接连模拟同一事件的下一天／下一届／下一次救助。

## 5. 审查停止条件与证据边界

每项后续关闭记录至少包含原权威文档、尚缺决定、首版最小裁定、明确延期项、验收证据与关闭条件；有理由的拒绝／延期也是有效关闭，不强迫每个缺口变成新机制。

模型离线时，暂停世界、停止待提交动作与读取权威状态必须有不依赖LLM理解的明确控制入口或有类型命令；不能一边承诺离线可操作，一边仍让离线模型负责解析这些操作。自由施政语言等待模型恢复，已授权模拟与确定性控制按原规则运行。

完成一轮准备评审的条件：首版必需事项都已定位到已有规则或明确待办；高优先缺项有具体产物／依赖；没有把未支持能力靠参数0、免费主体或叙事补上；同一术语、单位、时间与现金／状态权威可对齐。达到这些条件就进入下一项定义，不追求预先写尽所有城市事件。

本轮只识别／排序缺口并补通则，**没有声称GAP-01至11全部冻结或验证完成**。不增动态状态，区域仍27项43.0078125／44 MiB，余0.9921875 MiB；其他模拟314.025 MiB、应用2.65／3／4 GiB仍待测。静态文档／案例算术不能替代全局参数校准、真实AgentKit、完整家庭资金链或16 GB Mac混合实测。
