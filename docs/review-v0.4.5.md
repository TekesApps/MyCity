# v0.4.5 City Team编制、财政与知识

日期：2026-10-18。文档版本；没有游戏实现或性能基准。

## 设计变更

[团队编制与知识](team-staffing-and-knowledge.md) 落实市政团队随城市需求与财力发展：小中大开局默认2／4／6人，七个职能可兼任；地图不永久锁定编制，富裕小城也能扩到首轮每城16席位。全世界名册128槽独立准入，地图数不等于财政主体数。

专家提供专业方法、检查清单和工作量，本城项目经验归档积累。更多人不保证每次方案更好；基础规则、安全检查、权限和建设精度对所有配置一致。个人兼任不复制工时，更多成员不等于更多常驻模型。

游戏工资与真实模型费用分别准入。首版人员是抽象行政专业服务，收款账户参与既有资金账本，不重复当作居民收入／消费／通勤。30日工资窗口预留、区间支付，续期失败停止新劳动；任务不得越过已落实工资窗口硬预留。离任保留工程和城市经验，撤销后续授权，回执与补偿可追溯。

全世界一个活动模型请求、一个完整预演，人工任务最多32项，事件触发而非逐日调用。摘要继续付薪和保存名册，等待分析不伪造完成；基本告警与模拟不因缩编停止。

同步团队架构、地图容量、工具目录、跨图运行、性能预算、总览和roadmap。编制工具是MyCity拟议接口，不宣称AgentKit已提供或已接通。

## 审查与验证

依用户此前要求请advisor只读审查，明确名册总槽独立于地图数，以及工时预留不能越过工资窗口。检查相对链接、Markdown围栏、已有JSON、工资与内存算术、diff空白和版本一致性。
