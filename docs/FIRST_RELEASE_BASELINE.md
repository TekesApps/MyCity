# MyCity首版设计基线

冻结发布：v0.5.0，2026-10-19。D／A_doc首版设计冻结，I／V未完成；最终审查结论见末节。这里是**唯一首选阅读与生效入口**，设计修订号G47/C48等用于定位专题，不是互相竞争的发布版本。仓库只有设计、配置／合成输入，没有Rust游戏实现；D＝规则已定义，A_doc＝值或确定构造已交付，I＝实现证据，V＝原型／试玩／实机验收。本次冻结的对象是D与A_doc，绝不把I/V写成通过。

## 1. 玩什么、玩家能控制什么

玩家是市长，以Agent**文本输入**向City Team提出目标／硬限制／有限授权，未来语音走同一路径。地图用于观察、逐栋／道路桩号／区域选择和预览，不要求手工拖道路放房屋。市长不直接控制居民、业主、企业、议会或法院；团队将意图变成调查、比选、沟通、补偿／安置、许可／拨款／资金和分阶段工程，所有受理需求进入可查看的事项工作台。

人口互动／真实交通后果是核心：门、道路方向、路口、装卸、资源与时窗决定实际到岗／货运／公服，继而影响工资、消费、利润、财政、暴露、满意度与迁居。没有逐人日程或每房间设备常驻模拟；画面人车是实际活动的有界展示，不是权威账本。关闭邻城画面仍计算其真实跨图需求、供给／占用和钱债。

速度只改变现实时间与游戏日历的比率。公示14游戏日、养护或工程90游戏日仍经过相应日历与实际投入；审批不是施工百分比，工程完成不是投运，投运不是施政目标达成。待办显示参与方／下一步／缺项及具体回执，不伪造确定完工日期。

## 3. 范围与明确延期

首版：macOS单人、2.5D／全屏Retina、地图64/128/256格（均16m，256是待实测扩展目标）、连续曲线地面道路／W8/W16、沿路水电、23类基础设施／物件、8图共享有界世界、聚合交通经济／市民／环境／治理、Agent文本City Team。首版最小视听为原创程序几何／状态色／字标／有限声源，不等最终商业美术才可做原型。

[90类目录](building-types-and-technology-catalog.md)仍是23首版、66后续、1远期；不能把整个目录称已可投运。桥隧／铁路／航空及机场航司、完整自由3D、真实语音识别／唤醒、燃气设施／家庭燃气路线、任意复合建筑／摆摊运营、自由加层／房间编辑、成熟土地金融／商租／贷款债券／股市交易、完整灾害／病理／刑案及多人联网均延期到相应能力／资源／法规／外部供给实现后。旧燃气／复合楼／摊位／共享事故案例保留为后续机制的约束参考，不把算术样例当首版承诺。

议会有两年选举；不做市长选举／输选举强制结束。能力不存在时可登记意向／查询边界，不能承诺可施工；是否愿意付钱不能解锁未实现物理机制。后续扩展必须同时补定义、唯一writer、权利／输入输出／成本／退出、预算和运行验收，不能只新增一个模板名字。

## 4. 16GB与计算边界

预算是候选上限，不是实机结果：应用常态2.65 GiB、软上限3、峰值警戒4。分域为模拟0.35、几何0.25、资产0.85、渲染0.25、UI/工具0.35、求解／单预演0.20、运行时／快照0.40 GiB。统一内存不能把GPU再算一块免费显存；GPU计算16 MiB在求解域内，CPU提交／精度／回读失败沿CG39。

模拟358.4 MiB内：区域31项43.8828125／44 MiB；模板热页0.25、后续组合预留0.125、市场身份3.375、LS42 9.5、IL43 1、其他300.15 MiB。44 MiB域保留0.1171875，不能把358.4−43.8828的差再全给新功能；详细31行与归属沿BC43／专题增量，不重复额外分配。W50未受理索引128 KiB从UI/工具原域扣。

全世界联合上限仍为F/H/现金账户/劳动等原表各自32768，O4096、合法主体4096、股权8192且每公司≤8股东、库存／未清义务各65536、OD4096／路径引用409600、货运10000、服务池64／当前请求2048、工程／筹备共享128、单模型／32分析／单完整预演；每类定义不各获一整份额度。中图U51是同一输入根，不能按不同测试各自腾空预算。活跃资料／正文按有界查询分页，超额拒绝／排队／降速并保留已成立责任，不以漏算／降低居民数量通过。

世界磁盘10 GiB、8 GiB警告、1 GiB保存安全余量；两个自动恢复点连同钉住的检查点／日志闭包保留，不能只留根后删依赖。长档案归档仍计磁盘。必须在真实16GB Mac记录芯片、系统、显示／渲染比例、内存压力／压缩／交换、CPU/GPU峰值及最低实际倍率；现有开发机／纸面字段合计不替代它。

## 5. 实施路线与待验证假设

T47分期：I1核心输入／账本／共同钟与恢复→I2地图／精确选择／空间门→I3资源交通／经营与工程→I4生活／制度→I5完整玩家交互／视听→I6真实AgentKit适配与模型；V1中图联合16GB、V2完整引导／长期试玩及包装。依赖顺序允许图形与CPU原型并行，不要求先写AgentKit内部架构。最小可玩片段是小镇一次真实查询→诊断→受限授权→工程／等待→运行观察；它不是完整首版验收替代品。
