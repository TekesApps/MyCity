# 模型粒度、聚合与复杂度收敛

设计契约：v0.4.24，2026-10-19。本文先规定细化到哪里，再约束 [能力字段字典](capability-field-dictionary.md)、[常用物件契约](common-object-contracts.md) 和 [覆盖矩阵](object-definition-coverage.md)。目标是足够解释玩法的最小模型，不是把现实每件设备、每个人都做成独立模拟对象。语义字段数不等于实例字段数，不等于更新次数，也不等于动画实例数。

v0.4.25逐项落地见 [34属性／14系统／27物件分配](granularity-allocation-audit.md)。收敛不是所有预算冻结不动：不可合并的本地水电付费事实新增明确4 MiB绑定、使用原区域余量，不能为了节省而取消单元产权或混合付款方；其余细节仍走最小模型准入。

## 1. 四层表示，分别承担职责

| 层 | 保留什么 | 怎样控制资源 |
| --- | --- | --- |
| 权威事实 | 身份、权利、资金／债务、库存／所有者、真实占用、交付／工时、合法时点和必要状态来源 | 按游戏单位准确、有界记录／事务，不每显示帧更新，不复制权威 |
| 有界运行模型 | 模板／设备类别计数、实际活动、班次、少量条件／安装锚点、路径／服务来源 | 共享profile＋聚合来源＋事件驱动／稳定区间积分；需要额外状态先证明用途 |
| 推导／预测 | 额定到有效能力、成本估计、地价参考、路径成本、指标／覆盖和误差 | 按需计算、有界缓存／候选和一个预演，可陈旧／近似但必须披露，不直接写事实 |
| 视觉表现 | 灯光／人车／植被外观、动画和可见细节 | 视口采样、LOD、独立视觉随机种子；关闭动画不改变前三层结果 |

“准确”是在声明的游戏单位、规则和表示内准确，不声称完整物理世界的测量精度。厘米几何不意味着厘米环境模拟；额定W精确也不意味着已有真实室内热力模型。款项不能因误差预算随意少付，游戏污染指数也不能假称真实浓度。

## 2. 新细节的统一准入卡

每个新增字段、设备类型或机制都要提交下表，未通过的细节不进入可执行首版。纯目录候选可以列出缺项，不把缺项配置成0。

| 项目 | 必须回答的问题／拒绝条件 |
| --- | --- |
| 决策用途 | 改变哪个玩家／市民／经营决策、硬约束或M指标？只是换外观则留视觉，不新增运行状态 |
| 最小充分状态 | 能否由冻结模板、原来源和时间推导？能推导则不另存一份；不能推导的关键事实明确持久落点 |
| 聚合键 | 所有者／权限／条款／阶段／接入／资格／工况／安装状态哪些须相容？不能合并的差异不能平均掉 |
| 时间契约 | 唯一writer、触发事件、稳定区间、耗尽／法律／班次／容量阈值、舍入余数／随机源怎样保存？ |
| 误差契约 | 误差对象、单位、范围、累计和峰值如何评估？硬权限、账本和真实占用不接受近似豁免 |
| 资源契约 | 全世界条数、字段／变长页／索引字节、依赖扇出、最坏求解／写入及退出记录是否有额度？仅写“引用”不算完成 |
| 升降级 | 何时需要分组或更细计算，如何守恒映射？不能恢复的历史细节怎样标unknown，满额怎样安全退化？ |
| 验收 | 分段／合并积分、阈值、并发／资金、保存恢复、跨图和实际硬件对照是否可构造？未实现不标已通过 |

同一功能可有很多定义字段，但一栋普通住宅只解析适用分面、保存实际单元／家庭引用和已选择profile，不能为它分配制造配方、消防车队和全部设备数组。

## 3. 默认选择最粗的可用模型

| 对象／机制 | 首选表示 | 何时才需要更细／不得掩盖的差异 |
| --- | --- | --- |
| 照明、固定工况电器 | 冻结类别×数量＋时段／工况曲线，不逐灯存开关 | 若真实玩法需要不同控制／条件，则有界分组；异龄／动态温控无字段时unsupported，不仅靠改外观启用 |
| 制造、零售、公共服务 | 必要设备／班组／输入取联合可行瓶颈，交付由唯一adapter | 关键资格、库存权属、床位／队伍、实际接入不平均；不默认生产线／每个患者完整微观模拟 |
| 人口与劳动 | 家庭必要事实、真实劳动份额／岗位关系、兼容需求群体 | 不合并家庭钱包、资格或选票；群体是求解／统计表示，不取代个人权利来源 |
| 道路交通 | 曲线／真实门与方向、稀疏OD和代表流量、在途／积压 | 不能全日平均消掉高峰、封门、不连通、实际返程；逐车仅视觉或独立预算实验 |
| 环境 | 原32 m场、最多8通道、真实活动源和时间积分 | 数值稳定性需要子步；关键告警／夜间峰值须有来源／上界，没细声学就unsupported |
| 自然／绿化 | 有界植被斑块／重要树状态＋最大增长包络 | 外观树不逐棵驻留；跨权利、管理／成长条件不同先分已有有界斑块，不平均保护义务 |
| 空间／网络 | 厘米量化几何及稀疏边／节点／锚点 | 不密铺厘米网格或格子两两表；相交位置不自动产生道路／水电连通 |
| 估值／商户选址 | 冻结有覆盖快照、有限候选、版本化价格／需求模型 | 参考报价不当成交／资金保证，联合预演共享需求；无成熟土地市场不造一个逐地块金融循环 |

粗模型有自己的规则边界，不把未知细节用随机数补成真实事实。所有细化先检查是否可以只增加共享参数或查询解释，而不增加实例状态。

跨系统的统计倾向计算按[属性驱动的概率机制通则](regional-probabilistic-decisions.md)选择相关主体／上下文属性及最粗可用粒度，区分发生概率、选择分布与群体转变；不要求逐行业枚举或只取区域均值。自主行为产生候选，类型化事件沿原契约处理；不补造未知事实、不替代独立钱包／许可／实际容量。此前聚合与固定seed原则保留，新策略尚未实现。

## 4. 聚合、拆分与身份保持

相容状态可以按人数／流量／类别汇总，但每个需追责的来源仍可解析。合并键至少覆盖实际所有者和资金／库存、有效规则／到期／优先级、接入与可达性、资格／工种、正在进行的阶段，以及影响磨损／安全的安装和条件；只按“同一种楼”合并不够。

共享静态参数可无限多次引用但实例数、正文／缓存仍有限；现金、库存、债权、实际队列／占用和已承诺工时不能因同模板而合并丢对手方。合法合并必须同时保留总量、必要分布／来源与旧责任；不同条款不能用加权平均变成新条款。

拆分先联合准入目标记录和索引，再在一次提交中移交来源／数量／占用／权利／条件和依赖；失败保留原状。对既有人口或法定损害的变化不能仅因“分组无槽”拒绝事实，先原位保留来源、记录未解并退化求解；无处可靠保存才按原安全边界处理。满额先拒新承诺，不删旧事实。

## 5. 时间收敛：积分到事件，不是每帧扫全城

沿 [游戏日历](game-time.md) 采用整数游戏秒、[t0,T)半开区间、最多1游戏小时候选稳定跨度，并被最早法律／班次、阶段／养护、资金／库存耗尽、容量、维护／工况阈值或到期进一步截断。未知事件使用固定游戏随机源／种子，不随显示帧或现实倍速重复抽签。

对声称等价的稳定积分，应满足“先推进a再推进b”与“推进a＋b”的可组合性：同一profile、来源、精度和随机轨迹，累计／余数／必要锚点守恒。常量功率能解析积分；非线性衰减、磨损或拥堵不能默认大步乘一次，须有解析状态更新、稳定数值子步或受验证的误差口径。

**同一策略与同一模型轨迹**的账务重放要求一致；不同代表窗口／算法策略可能产生不同活动／路径／环境结果，不能把这些差异藏成“只改速度”。依 [游戏日历](game-time.md) 保存策略日志并披露近似，实际发生的每份活动仍必须守恒且依法结算；不能要求两套近似路径逐值一样，也不能借近似少扣已发生费用。

## 6. 平均值与误差不能越过硬门

| 量 | 允许的收敛／误差 | 不允许的替代 |
| --- | --- | --- |
| 现金／库存／债权／产权／实际占用 | 在冻结游戏量化与来源内守恒，尾差持续累计且可追溯 | 统一允许1%误差、删小额债、平均家庭现金或故障后裁实际占用 |
| 权限／边界／法律时点 | 按原量化几何与健壮判定，不允许受保护范围侵入 | 用粗格中心、缓存可达性、低分辨率容差授予进入／施工许可 |
| 峰值容量／启动条件 | 显式峰段或经验证保守上界；不足就unresolved／缩区间 | 日电量够就声称峰时可启动、平均床位空就接新患者 |
| 路径／经营预测 | 声明候选／迭代／误差、窗口、覆盖、年龄与未解量，按需更细 | 搜索没发现就证明无路／无房源；各店独立满销相加 |
| 环境／满意度 | 明确游戏单位、稳定性、积分／峰值与阈值误差；触及行为／法规门须验证 | 事后从日均量恢复未存峰值，或把游戏分数当真实医学结果 |
| 视觉 | 按世界快照采样，在视觉预算内自由降级 | 每一可视人车再生成一份消费／流量，或离开镜头停止维护 |

不给所有子模型统一误差百分比。误差上界／精度未配置时，相关新模型或达标判断不通过；可以返回估计和缺测，不能把不确定性当作允许违法／超售的额度。

## 7. 何时提高精细度，何时安全退化

触及硬阈值、合并键不再相容、模型误差影响决策、已承诺责任需要更多来源或观察请求无法由摘要回答时，先局部缩短区间／精算／查持久来源；需要新状态必须先有准入。不能仅因玩家放大相机就升级全城人口仿真。

预算紧张的顺序：减少视觉密度／资产质量与可丢缓存→减少预测候选／并发和预演范围→延迟非关键软重算并标年龄→降低实际日历倍率→停止新增承诺或安全处理无法持久化的状态。法律硬失效、旧债／到期、真实占用／安全退出及已发生变化不能为保FPS而丢弃。

详细↔摘要只在已提交边界变换，沿原唯一库存／账户／计量与持久来源保留必要身份、进度、余数和规则依据。摘要没有的精细历史在重开时标unknown，不能随机重建家庭财产、设备年龄或队列。转换不支持就不开放该实验／粒度切换，不能伪称可逆。

## 8. 字典和预算怎样真正收敛

字段字典是有限schema目录，不是每物件一份字段字典。读取通过原记录或共享profile解析；按类型有界绑定，只缓存需要的热页，能力仍16类／属性34组／逻辑系统14类／指标26族。已有8门／8子区、行业／商品／资格、OD／合同／meter等限额不因本轮补文档增长。

原模拟域0.35 GiB，扣44 MiB区域、0.25 MiB模板页和0.125 MiB后续组合预留，其他用途314.025 MiB不变；新增语义若需要新持久字段、目录／索引／队列或高频计算，必须具体列位置和字节，装不下先收窄支持或重预算，不在表外存“临时永远缓存”。峰值／误差摘要也计原监测／模型域，不能每个源默认新增整段历史。

每个常用物件契约都须标出：静态共享什么、实例保留什么、推导／缓存什么、何时更新、何种阈值不可近似、满额／缺参怎样处理。覆盖矩阵同时区分“结构／契约已定义、参数待配、表示待验、机制缺失、实现未有”，不靠继续堆字段提高完成度。

## 9. 必须构造的收敛测试

1. 20盏同类灯与一个计数20的类别，在相同工况／来源下累计能耗相等，不产生20个调度器；单台异龄更换没有状态表示时明确拒绝。
2. 两家商店共同需求100份／现金1000，聚合预测不能各卖100；家庭余额／库存分布仍可追责，不以总量够用替每户付费。
3. 1小时均电量与5分钟峰值、白天／夜间噪声对照；总量一致但峰值证据不足时不宣称硬门通过。
4. 在资金／煤耗尽、法规生效、关门和设备条件阈值前后分别分段推进；大步不能跨过失效，故障超占用保留真实actual。
5. 同一稳定策略分段／合并、保存恢复和详细↔摘要，比较来源／余数／计量／义务；不同近似策略另列结果偏差与覆盖，不能混成同一保证。
6. 满OD／群体／索引／监测／版本额度，丢视觉而不丢债务或旧流量来源；性能不足降实际倍率，所有变化有解释。

此为设计准入与测试要求，不是已证明误差或16 GB吞吐。三份配套文档必须服从这些收敛门，而不是先把字段无限拆细再寻找内存来装。

## v0.4.32文档工作的收敛与停止门

[全局覆盖台账](global-design-coverage-and-freeze.md) 将准备工作也纳入收敛：优先补跨系统共用的财政／开局／参数／操作／兼容定义，不顺着一个异常故事连续写下一天。每项明确原权威、缺失决定、首版最小裁定、延后与验收关闭条件，允许有意拒绝／延期；默认一个正常及一个反例能区别规则后即停。只有发现新的独立机制矛盾才重开案例，不能用增加字段／案例替代联合参数与真实验证。

现有Root／产权接入、欠费司法、有限应急恢复暂冻结设计扩展，保留全部未验边界；冻结不是已实现，也不撤回原首版范围。数值变化仍须原粒度准入卡、唯一来源和预算门，不通过文档细节免费增状态。

## BUDGET-1系统执行卡

2026-10-23设计补充，控制与代表负载见[城市规模与自适应预算](city-scale-and-adaptive-budget.md)，校准见[实验计划](simulation-budget-calibration-plan.md)。本节是待实现／待校准的执行合同，不更改原M0参数。资源总额继承P53/A55，本文第8节旧314.025MiB是历史值，不可再次分配。执行卡按S00—S13既有字段writer落地，不新增系统调度器。

### 所有执行卡共同必填

- 权威状态：typed身份／来源、单位、时间覆盖、profile/rule/model版本；分组只存来源引用／数量，独立钱包／权属／硬条件不合并。
- 时间：候选稳定区间≤1游戏小时，遇最近due／耗尽／班次／法律／容量／阈值截段；空间依既有分区／网络／32m场，不因预算改变厘米权利判定。
- 计算：候选K、迭代I、工作单位和cache_key/失效版本/TTL上限均需配置；未配置不启用近似。一次发布最多3轮／4方案是P53上限，域内更小门优先；交通来源16目的候选属搜索前置，不能与4方案混为一个额度。
- 等价合批：固定源／策略／顺序／舍入／随机轨迹，验证分段和合并的状态与关键决策；非线性场保留既定数值切点，只合dispatch，不擅自合数值步。
- 误差：精确权益误差为0个既定量化单位（整数尾差按原余数累计）；近似字段分别给绝对单位、相对量、峰值／累计窗、最大数据年龄、参考误差及阈值包络。epsilon未校准则candidate-only／unknown。累计偏差以独立参考重算跟踪，超限后从可信检查点和完整源窗口纠正未来判断，不改写已发生业务。
- 转换：在完整提交边界保留本卡所有最小状态和来源映射，预留旧新页、索引／缓存重建和持久字节；转换失败不发布。缺失历史标unknown。不可恢复信息不能参与后续硬门；没有转换实现就禁止该切换。

表内Δ是游戏时间，TTL是上限而非过期前永远可信；依赖版本变化立即失效。K/I起点只是实验候选，参数未测不能当支持范围。

### 策略分类与最低可信边界

“最低可信”是每个模型在声明业务范围内必须满足的事实覆盖、时效和误差底线；不是一个可以删减业务的低画质档。它可以使用已经验证的等价优化，或对允许近似字段使用已有误差资格的算法。某些精确事务域没有近似档。其它可选策略按本地ID登记，没有跨模型通用的“第三档一定比第二档更好”。

目录中的每个策略必须标：model/policy/numeric版本、适用scope／负载、最低可信资格、等价类或近似类别、输入和输出单位／精度／最大年龄／覆盖窗／峰值证据、K/I／更新触发、误差资格、成本估计与CPU/GPU路径、必要后果集合、兼容依赖及转换契约。等价策略要求在同源／同随机轨迹和数值切点下关键状态、权益、事件覆盖和决策一致；近似策略只对明示字段允许有界偏差，不对已发生事实统一加容差。未经资格的近似条目仅能用于候选／对照，不被控制器选作正式后果路径。

“升档”可能只增加局部工作额度、缩短更新周期或扩大有界候选，并不必然换模型；“降档”优先等价优化，再考虑已资格近似。两者都要保留已发生源、余数、随机结果、积压年龄和工程进度。精细策略不是重造摘要缺失历史的许可。

### 模型间的兼容约束

可以声明“交通策略T3要求供给策略U2”，但T3/U2只是各自目录里的本地ID；**权威条件是输入输出契约**，不能只比较档号。每条依赖以consumer策略／scope→producer允许策略集合或能力谓词定义，包含字段及单位、model/numeric/schema版本、空间接入／范围、覆盖区间、最大年龄、误差包络、峰值和来源证明、失效事件及不满足时的动作。没有合格producer则consumer不可准入。数据年龄和计算频率不是同一件事：未变更且有证据的缓存仍可有效。

| 消费侧及典型依赖 | 必须满足的兼容条件 | 不满足时的处理 |
| --- | --- | --- |
| 交通／货运细算→空间／权利／路网 | 对应窗口合法接入、方向、封路、图版本和容量来源有效 | 使旧路线失效，重查／等待；不能拿高精度路径配过期通行权 |
| 经营生产→交通到岗／配送＋公用供给 | 同一业务区间的实际可用投入／到达证据与容量，预测只作候选 | 协调上游覆盖，或依法短缺／停工；不把销量预测当已生产 |
| 暴露／安全判断→环境＋活动源 | 覆盖判断窗口、受体与必要峰值，累计误差区间不跨硬门 | 细算对应源窗／受体，证据缺失则unknown／等待，不用末场代替累计暴露 |
| 满意度／迁居候选→服务／交通／经营／暴露 | 适用时窗、age、单位及误差合成有资格；临界决策需保护区间 | 升级必要上游或降低候选策略要求但仍达最低可信；无法兼容不提交该候选 |
| 财务结算→实际交付／劳动／工程量 | 已提交来源及原票、区间和余数，而不是某个“高档预测” | 等必要来源／按真实短缺留义务；不能通过提升财务档位补造交付 |
| 任一提交→跨城／Timeline／恢复 | 同一因果边界、clock_kind、增量水位、任务代际与可恢复状态 | 维持屏障／原续做责任；地图关闭或模型降档都不绕过 |

这些是跨系统数据契约，不假设所有消费必须在同一事务重算。可以使用仍有效的旧计算结果，但接纳时必须匹配当前冻结读集／覆盖要求。误差沿依赖组合传播，不因每个子模型单独达标就默认联合达标；没有传播界时细算或unknown。

### 兼容组合选择与预算让路

1. 每个scope先列出已实现且有资格的策略和不可撤销必要工作。以现有依赖／失效索引收集相关scope，按实际读集、时间和空间扩展影响闭包；不把局部升档扩成全城同档。
2. 选择满足最低可信及兼容条件的组合，计算**整组**CPU/GPU、工作页、转换／双活、校验／提交及恢复成本；共享上游按唯一任务身份只计一次。无成本依据时不认证支持范围，先限量校准。
3. 升档可能要求上游增加覆盖或时效，下游也可能需要重新判定；降档同样先检查消费者是否仍兼容。不能让出别人仍依赖的有效状态或页租约，不能只降producer而保留不满足输入的consumer细档。
4. 含循环的依赖组按阶段／已提交状态区分：既有因果反馈使用原阶段顺序；同一窗口需联合求解的循环先在冻结输入上生成有界联合候选，停止条件／迭代额度／误差传播须显式配置。不得等彼此“先升级完成”形成死锁，不得为收敛无限重算。无可行解或迭代耗尽则保留未解／短缺并在必要屏障减速或暂停，不能拿未来现金／产出启动循环。
5. 总额内先用已预留突发和收缩可选工作；必要时选择另一组兼容策略，而非各模型独立贪心升降。只有所有相关最低可信策略仍兼容且必要义务保全时，才允许它们让额。玩家关注不越过法定／维护／已接受业务优先级。
6. 新组合及转换意图在完整边界、新续做票前接受；仅在相关依赖组全部转换校验完成时发布新的兼容策略绑定，失败保留旧绑定。可分多页准备但不把半套组合交给消费者；不要求复制全世界。已提交业务不回滚，进行中必要段按原绑定完成或按代际安全重算。保存恢复保留组合版本、依赖读集、转换进度及原来源，不凭实时负载重选历史策略。
7. 组合放不进总额：停止可选升级，寻找满足同一最低可信契约的低成本兼容组合；仍不足就降低实际推进速度／限制新承诺／安全背压，不丢人口、钱债、维护、交付或其它必要后果。防抖／最短保持和成本回本沿BUDGET-1/2，恢复时也检查整组兼容。

所谓“让路不影响数值”，只对已证明等价的策略承诺关键结果一致；允许误差策略必须明确可能改变哪些合法经营／交通／迁居路径。每次运行内部守恒、权利、必要时点和后果覆盖始终成立，不能用小模型近似误差掩盖整条业务链遗漏。
